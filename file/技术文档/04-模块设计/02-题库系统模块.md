## 1. 题目数据模型

### 核心模型

```go
// internal/model/question.go
// 表名：qb_questions

type Question struct {
    ID                   uint           `gorm:"primaryKey;autoIncrement" json:"id"`
    Title                string         `gorm:"type:varchar(500);not null" json:"title"`
    QuestionType         string         `gorm:"type:varchar(50);not null;index" json:"questionType"`
    Stem                 string         `gorm:"type:json;not null" json:"stem"`           // 题干（富媒体内容块）
    Content              string         `gorm:"type:json" json:"content"`                  // 题目类型特定结构
    Answer               string         `gorm:"type:json" json:"answer"`                   // 编辑器态答案
    Analysis             string         `gorm:"type:json" json:"analysis"`                 // 解析（富媒体内容块）
    Materials            string         `gorm:"type:json" json:"materials"`                // 材料
    ScoreRule            string         `gorm:"type:json" json:"scoreRule"`                // 评分规则
    ExamID               uint           `gorm:"index" json:"examId"`                       // 考试ID
    SubjectID            uint           `gorm:"index" json:"subjectId"`                    // 科目ID
    CategoryID           uint           `gorm:"index" json:"categoryId"`                   // 分类ID
    SourceID             uint           `json:"sourceId"`                                  // 来源ID
    Difficulty           int            `gorm:"type:tinyint;default:1" json:"difficulty"`  // 1=简单, 2=中等, 3=困难
    ResourceType         string         `gorm:"type:varchar(20);default:private" json:"resourceType"` // private/public/group/user
    Status               string         `gorm:"type:varchar(20);default:draft;index" json:"status"`
    CurrentVersionID     uint           `json:"currentVersionId"`                          // 当前版本ID
    SourceImportTaskID   uint           `json:"sourceImportTaskId"`                        // 来源导入任务ID
    ParentID             uint           `gorm:"index" json:"parentId"`                     // 父题目ID（组合题）
    IsGroup              int            `gorm:"type:tinyint;default:0" json:"isGroup"`     // 是否为组合题
    SubIndex             int            `json:"subIndex"`                                  // 子题排序
    StemHash             string         `gorm:"type:varchar(64)" json:"stemHash"`          // 内容指纹（去重）
    ContentHash          string         `gorm:"type:varchar(64)" json:"contentHash"`
    AnswerHash           string         `gorm:"type:varchar(64)" json:"answerHash"`
    AnalysisVisiblePolicy string        `gorm:"type:varchar(30);default:after_answer" json:"analysisVisiblePolicy"`
    AnswerVisiblePolicy  string         `gorm:"type:varchar(30);default:after_answer" json:"answerVisiblePolicy"`
    CreatedBy            uint           `gorm:"not null;index" json:"createdBy"`
    UpdatedBy            uint           `gorm:"index" json:"updatedBy"`
    ReviewedBy           uint           `json:"reviewedBy"`
    ReviewedAt           *time.Time     `json:"reviewedAt"`
    RejectReason         string         `gorm:"type:varchar(500)" json:"rejectReason"`
    PublishedAt          *time.Time     `json:"publishedAt"`
    DeletedBy            uint           `json:"deletedBy"`
    RecycleExpireAt      *time.Time     `json:"recycleExpireAt"`
    CreatedAt            time.Time      `json:"createdAt"`
    UpdatedAt            time.Time      `json:"updatedAt"`
    DeletedAt            gorm.DeletedAt `gorm:"index" json:"deletedAt,omitempty"`
}
```

### JSON 字段设计

题目使用 JSON 字段存储复杂结构，支持富媒体内容：

#### Stem（题干）

```json
{
  "blocks": [
    {
      "type": "text",
      "content": "下列关于 Go 语言的说法，正确的是："
    },
    {
      "type": "image",
      "url": "/uploads/2026/06/18/abc123.png",
      "alt": "示例图片"
    }
  ]
}
```

#### Content（题目内容）

根据题目类型有不同的结构：

**选择题：**
```json
{
  "options": [
    {"key": "A", "value": "Go 是静态类型语言"},
    {"key": "B", "value": "Go 不支持并发"},
    {"key": "C", "value": "Go 是解释型语言"},
    {"key": "D", "value": "Go 没有垃圾回收"}
  ]
}
```

**填空题：**
```json
{
  "blanks": [
    {"index": 0, "placeholder": "____"},
    {"index": 1, "placeholder": "____"}
  ]
}
```

**编程题：**
```json
{
  "language": "go",
  "template": "package main\n\nfunc solution() {\n    // 在此编写代码\n}",
  "testCases": [
    {"input": "1 2", "expected": "3"},
    {"input": "3 4", "expected": "7"}
  ]
}
```

#### Answer（答案）

```json
{
  "type": "choice",
  "value": ["A"]
}
```

```json
{
  "type": "blank",
  "value": ["Go", "静态"]
}
```

#### ScoreRule（评分规则）

```json
{
  "totalScore": 10,
  "partialScore": true,
  "rules": [
    {"blank": 0, "score": 5, "keywords": ["Go", "golang"]},
    {"blank": 1, "score": 5, "keywords": ["静态", "static"]}
  ]
}
```

## 3. 题目状态机

### 状态定义

| 状态 | 标识 | 说明 |
|------|------|------|
| 草稿 | `draft` | 新建或撤回后的状态 |
| 待审核 | `pending` | 已提交审核 |
| 已通过 | `approved` | 审核通过 |
| 已驳回 | `rejected` | 审核驳回 |
| 已发布 | `published` | 已发布可用 |
| 已归档 | `archived` | 已归档（软删除） |

### 状态转换规则

| 转换 | 操作 | 条件 | 执行者 |
|------|------|------|--------|
| → `draft` | 创建 | 新建题目 | 创建者 |
| `draft` → `pending` | 提交审核 | 题目完整 | 创建者 |
| `rejected` → `pending` | 重新提交 | 修改后重新提交 | 创建者 |
| `pending` → `approved` | 审核通过 | 内容合规 | 审核者（非创建者） |
| `pending` → `rejected` | 审核驳回 | 内容不合规 | 审核者 |
| `draft` → `published` | 直接发布 | 私有资源，stem 非空 | 创建者 |
| `approved` → `published` | 发布 | 非私有资源，stem 非空 | 创建者 |
| `published` → `archived` | 归档 | - | 创建者 |
| `archived` → `published` | 重新激活 | - | 创建者 |
| `pending`/`approved`/`published` → `draft` | 撤回 | - | 创建者 |
| `draft`/`rejected`/`archived` → 删除 | 删除 | - | 创建者 |

### 状态转换代码

```go
// internal/service/question_service.go

func (s *QuestionService) SubmitAudit(ctx context.Context, id uint) error {
    question, err := s.repo.GetByID(id)
    if err != nil {
        return ErrQuestionNotFound
    }

    // 权限检查：只有创建者可以提交
    userID := middleware.GetCurrentUserID(ctx)
    if question.CreatedBy != userID {
        return ErrNotCreator
    }

    // 状态检查：只有 draft 或 rejected 可以提交
    if question.Status != "draft" && question.Status != "rejected" {
        return ErrInvalidStatusTransition
    }

    question.Status = "pending"
    return s.repo.Update(question)
}

func (s *QuestionService) Approve(ctx context.Context, id uint) error {
    question, err := s.repo.GetByID(id)
    if err != nil {
        return ErrQuestionNotFound
    }

    // 权限检查：审核者不能审核自己的题目
    userID := middleware.GetCurrentUserID(ctx)
    if question.CreatedBy == userID {
        return ErrCannotReviewOwnQuestion
    }

    // 状态检查：只有 pending 可以审核
    if question.Status != "pending" {
        return ErrInvalidStatusTransition
    }

    question.Status = "approved"
    question.ReviewedBy = userID
    question.ReviewedAt = &time.Time{}
    *question.ReviewedAt = time.Now()

    return s.repo.Update(question)
}
```

### 分享码生成

```go
// 使用 crypto/rand 生成 16 字节随机数，转为 32 字符十六进制
func generateShareCode() string {
    bytes := make([]byte, 16)
    rand.Read(bytes)
    return hex.EncodeToString(bytes)
}
```

| 类型 | 说明 | TargetID |
|------|------|---------|

| `user` | 用户分享 | UserID |
| `role` | 角色分享 | RoleID |

- **启用/禁用**：切换分享状态
- **续期**：延长过期时间
- **访问记录**：递增 AccessCount，更新 AccessedAt
