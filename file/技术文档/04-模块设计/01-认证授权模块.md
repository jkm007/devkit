## 1. JWT 双令牌设计

### 令牌结构

系统采用 Access Token + Refresh Token 双令牌机制：

```
┌─────────────────────────────────────────────────────────────┐
│                    JWT 双令牌设计                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Access Token (访问令牌)                                     │
│  ├── 签名算法：HS256                                         │
│  ├── 有效期：168h (7天)                                      │
│  ├── 载荷：                                                  │
│  │   ├── user_id: uint      用户ID                          │
│  │   ├── username: string   用户名                           │
│  │   ├── roles: []string    角色列表                         │
│  │   ├── iss: "devkit"      签发者                           │
│  │   ├── iat: timestamp     签发时间                         │
│  │   └── exp: timestamp     过期时间                         │
│  └── 用途：API 请求认证                                      │
│                                                             │
│  Refresh Token (刷新令牌)                                    │
│  ├── 签名算法：HS256                                         │
│  ├── 有效期：720h (30天)                                     │
│  ├── 载荷：                                                  │
│  │   ├── user_id: uint      用户ID（仅此字段）               │
│  │   ├── iss: "devkit"      签发者                           │
│  │   ├── iat: timestamp     签发时间                         │
│  │   └── exp: timestamp     过期时间                         │
│  └── 用途：刷新 Access Token                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### Claims 结构体

```go
// pkg/jwt/jwt.go

type Claims struct {
    UserID   uint     `json:"user_id"`
    Username string   `json:"username"`
    Roles    []string `json:"roles"`
    jwt.RegisteredClaims
}

type TokenPair struct {
    AccessToken  string `json:"access_token"`
    RefreshToken string `json:"refresh_token"`
}
```

### 设计决策

| 决策 | 原因 |
|------|------|
| Access Token 包含用户信息 | 减少数据库查询，提高认证性能 |
| Refresh Token 仅含 UserID | 最小权限原则，减少泄露风险 |
| Access Token 7天有效期 | 平衡安全性和用户体验 |
| Refresh Token 30天有效期 | 支持长期登录，减少频繁登录 |
| 使用 HS256 算法 | 对称加密，性能好，适合单体应用 |
| 显式验证签名方法 | 防止 `alg:none` 攻击 |

### Token 生成

```go
// pkg/jwt/jwt.go

func Generate(userID uint, username string, roles []string) (*TokenPair, error) {
    cfg := config.Get().JWT

    // Access Token - 包含完整用户信息
    accessClaims := Claims{
        UserID:   userID,
        Username: username,
        Roles:    roles,
        RegisteredClaims: jwt.RegisteredClaims{
            ExpiresAt: jwt.NewNumericDate(time.Now().Add(cfg.AccessTokenTTL)),
            IssuedAt:  jwt.NewNumericDate(time.Now()),
            Issuer:    cfg.Issuer,
        },
    }
    accessToken := jwt.NewWithClaims(jwt.SigningMethodHS256, accessClaims)
    accessTokenStr, err := accessToken.SignedString([]byte(cfg.Secret))
    if err != nil {
        return nil, err
    }

    // Refresh Token - 仅包含 UserID
    refreshClaims := Claims{
        UserID: userID,
        RegisteredClaims: jwt.RegisteredClaims{
            ExpiresAt: jwt.NewNumericDate(time.Now().Add(cfg.RefreshTokenTTL)),
            IssuedAt:  jwt.NewNumericDate(time.Now()),
            Issuer:    cfg.Issuer,
        },
    }
    refreshToken := jwt.NewWithClaims(jwt.SigningMethodHS256, refreshClaims)
    refreshTokenStr, err := refreshToken.SignedString([]byte(cfg.Secret))
    if err != nil {
        return nil, err
    }

    return &TokenPair{
        AccessToken:  accessTokenStr,
        RefreshToken: refreshTokenStr,
    }, nil
}
```

### Token 解析

```go
// pkg/jwt/jwt.go

func Parse(tokenString string) (*Claims, error) {
    cfg := config.Get().JWT

    token, err := jwt.ParseWithClaims(tokenString, &Claims{}, func(token *jwt.Token) (interface{}, error) {
        // 显式验证签名方法，防止 alg:none 攻击
        if token.Method != jwt.SigningMethodHS256 {
            return nil, errors.New("unexpected signing method")
        }
        return []byte(cfg.Secret), nil
    })

    if err != nil {
        return nil, err
    }

    if claims, ok := token.Claims.(*Claims); ok && token.Valid {
        return claims, nil
    }

    return nil, errors.New("invalid token")
}
```

## 2. Token 轮换机制

### 刷新流程

```
┌──────────┐     POST /api/v1/auth/refresh      ┌──────────────┐
│  Client  │ ──────────────────────────────────→ │ Auth Service │
│          │   { refresh_token: "..." }          └──────┬───────┘
│          │                                            │
│          │                                    ┌───────┴───────┐
│          │                                    │               │
│          │                                    ▼               ▼
│          │                            ┌──────────────┐ ┌──────────────┐
│          │                            │ Redis Lua    │ │ 验证结果      │
│          │                            │ 原子脚本      │ │              │
│          │                            └──────┬───────┘ └──────┬───────┘
│          │                                   │               │
│          │                                   ▼               │
│          │                            ┌──────────────┐       │
│          │                            │ -1: Token    │       │
│          │                            │    不存在     │       │
│          │                            │              │       │
│          │                            │  0: Token    │       │
│          │                            │    不匹配     │       │
│          │                            │              │       │
│          │                            │  1: 刷新成功  │       │
│          │                            └──────────────┘       │
│          │                                                  │
│          │ ←─── 新 TokenPair / 错误 ────────────────────────│
└──────────┘
```

### Lua 原子脚本

```go
// internal/service/auth_service.go

var refreshTokenLuaScript = redis.NewScript(`
-- KEYS[1]: refresh_token:{hash}
-- ARGV[1]: 旧 refresh token（SHA-256 哈希）
-- ARGV[2]: 新 refresh token（SHA-256 哈希）
-- ARGV[3]: TTL（秒）

local stored = redis.call('GET', KEYS[1])
if not stored then
    return -1  -- Token 不存在（已过期或已使用）
end
if stored ~= ARGV[1] then
    return 0  -- Token 不匹配（重放攻击）
end
-- 原子替换：删除旧 Token，写入新 Token
redis.call('SETEX', KEYS[1], tonumber(ARGV[3]), ARGV[2])
return 1  -- 刷新成功
`)
```

### 防重放机制

1. **SHA-256 哈希存储**：Redis 中存储的是 Refresh Token 的 SHA-256 哈希，而非原始 Token
2. **原子替换**：Lua 脚本保证"验证+替换"的原子性，防止 TOCTOU 竞态条件
3. **一次性使用**：每次刷新都会生成新的 Refresh Token，旧 Token 立即失效
4. **并发安全**：多个并发刷新请求中，只有一个能成功（返回 1），其他都会失败（返回 0）

### 刷新实现

```go
// internal/service/auth_service.go

func (s *AuthService) RefreshToken(refreshToken string) (*jwt.TokenPair, error) {
    // 1. 解析 Refresh Token
    claims, err := jwt.Parse(refreshToken)
    if err != nil {
        return nil, ErrInvalidRefreshToken
    }

    // 2. 计算哈希
    oldHash := sha256Hash(refreshToken)
    cacheKey := fmt.Sprintf("refresh_token:%d", claims.UserID)

    // 3. 生成新 Token
    user, err := s.userRepo.GetByID(claims.UserID)
    if err != nil {
        return nil, ErrUserNotFound
    }

    newPair, err := jwt.Generate(user.ID, user.Username, user.Roles)
    if err != nil {
        return nil, err
    }

    newHash := sha256Hash(newPair.RefreshToken)
    ttl := int(config.Get().JWT.RefreshTokenTTL.Seconds())

    // 4. 原子替换
    result, err := refreshTokenLuaScript.Run(ctx, rdb,
        []string{cacheKey}, oldHash, newHash, ttl,
    ).Int()

    switch result {
    case -1:
        return nil, ErrRefreshTokenExpired
    case 0:
        return nil, ErrRefreshTokenReplay
    case 1:
        return newPair, nil
    }

    return nil, ErrRefreshFailed
}
```

## 3. Token 黑名单

### 实现原理

```
┌─────────────────────────────────────────────────────────────┐
│                    Token 黑名单机制                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  登出时：                                                    │
│  1. 计算 Token 的 SHA-256 哈希                               │
│  2. 以 hash 为 Key 写入 Redis                                │
│  3. TTL 设置为 Token 剩余有效期                               │
│                                                             │
│  认证时：                                                    │
│  1. 解析 Token 获取 Claims                                   │
│  2. 计算 Token 的 SHA-256 哈希                               │
│  3. 检查 Redis 中是否存在该 Key                               │
│  4. 存在 → 拒绝访问                                          │
│  5. 不存在 → 允许访问                                         │
│                                                             │
│  Fail-Closed 策略：                                          │
│  - Redis 不可用时，拒绝所有请求                                │
│  - 宁可误杀，不可放过                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 黑名单 Key 生成

```go
// internal/middleware/auth.go

func tokenBlacklistKey(token string) string {
    h := sha256.Sum256([]byte(token))
    return fmt.Sprintf("token_blacklist:%s", hex.EncodeToString(h[:]))
}
```

### 黑名单检查（Fail-Closed）

```go
// internal/middleware/auth.go

func JWTAuth() gin.HandlerFunc {
    return func(c *gin.Context) {
        tokenString := extractToken(c)
        if tokenString == "" {
            response.Unauthorized(c, "未提供认证令牌")
            c.Abort()
            return
        }

        // 解析 Token
        claims, err := jwt.Parse(tokenString)
        if err != nil {
            response.Unauthorized(c, "无效的认证令牌")
            c.Abort()
            return
        }

        // 检查黑名单（Fail-Closed）
        blacklistKey := tokenBlacklistKey(tokenString)
        exists, err := rdb.Exists(ctx, blacklistKey).Result()
        if err != nil {
            // Redis 不可用时拒绝访问
            logger.Error("Redis 连接失败，拒绝访问", zap.Error(err))
            response.InternalError(c, "服务暂时不可用")
            c.Abort()
            return
        }
        if exists > 0 {
            response.Unauthorized(c, "令牌已失效")
            c.Abort()
            return
        }

        // 将用户信息写入 Context
        c.Set("user_id", claims.UserID)
        c.Set("username", claims.Username)
        c.Set("roles", claims.Roles)

        c.Next()
    }
}
```

### 登出时加入黑名单

```go
// internal/service/auth_service.go

func (s *AuthService) Logout(accessToken string, refreshToken string) error {
    // 1. 将 Access Token 加入黑名单
    accessHash := sha256Hash(accessToken)
    accessClaims, _ := jwt.Parse(accessToken)
    accessTTL := time.Until(accessClaims.ExpiresAt.Time)
    if accessTTL > 0 {
        rdb.Set(ctx, "token_blacklist:"+accessHash, "1", accessTTL)
    }

    // 2. 删除 Refresh Token
    refreshHash := sha256Hash(refreshToken)
    rdb.Del(ctx, fmt.Sprintf("refresh_token:%d", accessClaims.UserID))

    return nil
}
```

```go
func (s *PasswordHistoryService) CheckRepeated(userID uint, newPassword string) (bool, error) {
    histories, err := s.repo.GetRecent(userID, 5)
    if err != nil {
        return false, err
    }

    for _, h := range histories {
        if err := bcrypt.CompareHashAndPassword([]byte(h.Password), []byte(newPassword)); err == nil {
```

### 答案加密（AES-GCM）

```go
// pkg/captcha/captcha.go

// 加密答案
func encryptAnswer(answer string, secret []byte) (string, error) {
    block, err := aes.NewCipher(secret)
    if err != nil {
        return "", err
    }

    gcm, err := cipher.NewGCM(block)
    if err != nil {
        return "", err
    }

    nonce := make([]byte, gcm.NonceSize())
    io.ReadFull(rand.Reader, nonce)

    ciphertext := gcm.Seal(nonce, nonce, []byte(answer), nil)
    return base64.StdEncoding.EncodeToString(ciphertext), nil
}
```

### 验证流程

```go
// pkg/captcha/captcha.go

func Verify(captchaID, answer, token string, startTime int64) (bool, string) {
    // 1. 从 Redis 获取验证码数据
    store, err := getCaptchaStore(captchaID)
    if err != nil {
        return false, "验证码已过期"
    }

    // 2. 检查失败次数
    if store.FailCount >= config.MaxFail {
        return false, "验证码错误次数过多"
    }

    // 3. 检查操作时长（防机器人）
    if startTime > 0 && config.MinDuration > 0 {
        elapsed := startTime - store.StartTime
        if elapsed < int64(config.MinDuration) {
            return false, "操作过于迅速，请重试"
        }
    }

    // 4. 解密并验证答案
    decryptedAnswer, err := decryptAnswer(store.EncryptedAnswer, secret)
    if err != nil {
        return false, "验证码解析失败"
    }

    if answer != decryptedAnswer {
        // 增加失败计数
        incrementFailCount(captchaID)
        return false, "验证码错误"
    }

    // 5. 验证成功，原子删除（一次性使用）
    rdb.GetDel(ctx, captchaID)

    return true, "验证成功"
}
```

## 6. 风险评分系统

### 评分规则

| 规则 | 检测内容 | 默认加分 | 说明 |
|------|---------|---------|------|
| `frequency` | 60秒内请求超过30次 | +30 | 基于 IP 的请求频率 |
| `no_referer` | 缺少 Referer 头 | +20 | 浏览器正常请求都会有 Referer |
| `no_lang` | 缺少 Accept-Language 头 | +15 | 浏览器正常请求都会有语言偏好 |
| `ua` | User-Agent 包含机器人关键词 | +25 | curl/python/java/go-http/postman/scrapy |
| `interval` | 10秒滑动窗口超过50次请求 | +20 | 使用 Redis Sorted Set 精确统计 |

### 风险等级

| 分数范围 | 等级 | 处理方式 |
|---------|------|---------|
| 0 - 49 | 正常 | 放行 |
| 50 - 79 | 高风险 | 触发验证码 |
| 80+ | 极高风险 | 阻止访问 |

### 风险评分累加

```go
// internal/middleware/captcha_guard.go

func evaluateRiskScore(c *gin.Context, config *RiskConfig) int {
    ip := c.ClientIP()
    totalScore := 0

    for _, rule := range config.Rules {
        if !rule.Enabled {
            continue
        }

        var score int
        switch rule.Key {
        case "frequency":
            score = checkFrequency(ip, rule.Config)
        case "no_referer":
            score = checkNoReferer(c)
        case "no_lang":
            score = checkNoLanguage(c)
        case "ua":
            score = checkUserAgent(c)
        case "interval":
            score = checkInterval(ip, rule.Config)
        }

        if score > 0 {
            totalScore += score
            // 原子累加到 Redis
            incrRiskScore(ip, score, config.DecayMinutes*60)
        }
    }

    return totalScore
}
```

### 权限解析流程

```go
// internal/service/auth_service.go

func (s *AuthService) GetPermissionCodes(userID uint) ([]string, error) {
    cacheKey := fmt.Sprintf("perm:%d", userID)

    // 1. 读缓存
    cached, err := s.cache.Get(cacheKey)
    if err == nil {
        var codes []string
        json.Unmarshal([]byte(cached), &codes)
        return codes, nil
    }

    // 2. 从数据库加载
    codes, err := s.loadPermissionCodesFromDB(userID)
    if err != nil {
        return nil, err
    }

    // 3. 写入缓存（10分钟）
    data, _ := json.Marshal(codes)
    s.cache.Set(cacheKey, string(data), 10*time.Minute)

    return codes, nil
}

func (s *AuthService) loadPermissionCodesFromDB(userID uint) ([]string, error) {
    codeSet := make(map[string]bool)

    // 1. 获取用户直接角色
    directRoleIDs, _ := s.userRoleRepo.GetRoleIDsByUserID(userID)
    for _, roleID := range directRoleIDs {
        permissions := s.getRolePermissions(roleID)
        for _, p := range permissions {
            codeSet[p] = true
        }
    }

    // 2. 获取用户分组（递归继承）
    user, _ := s.userRepo.GetByID(userID)
    if user.GroupID > 0 {
        groupRoleIDs := s.groupRepo.GetGroupRoleIDsRecursive(user.GroupID)
        for _, roleID := range groupRoleIDs {
            permissions := s.getRolePermissions(roleID)
            for _, p := range permissions {
                codeSet[p] = true
            }
        }
    }

    // 3. 转换为切片
    codes := make([]string, 0, len(codeSet))
    for code := range codeSet {
        codes = append(codes, code)
    }

    return codes, nil
}
```

```go
// internal/middleware/security_log.go

func SecurityLogMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        // 1. 只拦截写操作
        if c.Request.Method == "GET" || c.Request.Method == "HEAD" || c.Request.Method == "OPTIONS" {
            c.Next()
            return
        }

        // 2. 跳过特定路径
        path := c.Request.URL.Path
        if strings.HasPrefix(path, "/api/v1/auth/") || path == "/api/v1/files/upload" {
            c.Next()
            return
        }

        // 3. 包装 ResponseWriter 以捕获状态码
        writer := &responseWriter{ResponseWriter: c.Writer, status: 200}
        c.Writer = writer

        // 4. 读取并缓冲请求体（最大 64KB）
        body, _ := io.ReadAll(io.LimitReader(c.Request.Body, 64*1024))
        c.Request.Body = io.NopCloser(bytes.NewBuffer(body))

        // 5. 执行后续处理器
        c.Next()

        // 6. 异步记录日志
        go func() {
            userID := GetCurrentUserID(c)
            if userID == 0 {
                return
            }

            eventType, eventDetail := PathToEventType(c.Request.Method, path)
            status := 1
            if writer.status >= 400 {
                status = 0
            }

            securityLogService.Record(&model.SecurityLog{
                UserID:      userID,
                EventType:   eventType,
                EventDetail: eventDetail,
                IP:          c.ClientIP(),
                UserAgent:   c.Request.UserAgent(),
                Status:      status,
            })
        }()
    }
}
```

### Token 来源优先级

JWT Auth 中间件支持三种 Token 来源，按优先级：

1. `Authorization: Bearer <token>` 头（标准方式）
2. `access_token` Cookie（浏览器图片/视频请求）
3. `?token=` 查询参数（`<img>`/`<video>` 标签加载）

```go
func extractToken(c *gin.Context) string {
    // 1. Authorization 头
    auth := c.GetHeader("Authorization")
    if strings.HasPrefix(auth, "Bearer ") {
        return strings.TrimPrefix(auth, "Bearer ")
    }

    // 2. Cookie
    if token, err := c.Cookie("access_token"); err == nil && token != "" {
        return token
    }

    // 3. 查询参数
    return c.Query("token")
}
```
