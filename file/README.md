# DevKit 后台管理系统 - 技术文档中心

> 本文档中心汇集了 DevKit 后台管理系统的全部技术与产品文档，供团队成员查阅参考。

---

## 系统简介

DevKit 是基于 **Go + Vue 3** 的全栈后台管理系统，面向教育考试领域，提供题库管理、在线学习、文件管理等核心能力。系统采用前后端分离架构，包含以下子项目：

| 子项目 | 技术栈 | 说明 |
|--------|--------|------|
| `backend-server` | Go / Gin / GORM / MySQL / Redis | 后端服务，提供 RESTful API 和 WebSocket 实时推送 |
| `frontend-admin` | Vue 3 / Ant Design Vue / Vben Admin | Web 管理后台，供管理员和出题人使用 |
| `frontend-app` | UniApp | 移动端应用，供学员进行题目浏览、练习和学习 |
