## 1. 用户名密码登录

使用用户名和密码进行登录，需携带图形验证码。

### 请求

```
POST /auth/login
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码（前端加密后传输） |
| captchaId | string | 是 | 验证码 ID（从获取验证码接口获取） |
| captchaCode | string | 是 | 验证码答案 |
| captchaType | string | 是 | 验证码类型 |
| points | array | 否 | 点选验证码坐标（点选类验证码必填） |
| startTime | number | 否 | 验证开始时间戳（用于行为验证） |

### 请求示例

```json
{
  "username": "admin",
  "password": "e10adc3949ba59abbe56e057f20f883e",
  "captchaId": "captcha_abc123",
  "captchaCode": "1234",
  "captchaType": "numeric",
  "points": [],
  "startTime": 1718640000000
}
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "id": 1,
    "username": "admin",
    "nickname": "管理员",
    "email": "admin@example.com",
    "avatar": "https://cdn.example.com/avatar/admin.png",
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "roles": ["admin"],
    "homePath": "/dashboard",
    "registerSource": "local"
  },
  "error": "",
  "message": ""
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 用户 ID |
| username | string | 用户名 |
| nickname | string | 昵称 |
| email | string | 邮箱 |
| avatar | string | 头像 URL |
| accessToken | string | 访问令牌（短期有效） |
| refreshToken | string | 刷新令牌（长期有效） |
| roles | array | 角色列表 |
| homePath | string | 首页路径 |
| registerSource | string | 注册来源（local/email/phone/wechat） |

### 错误码

| code | 说明 |
|------|------|
| 400 | 用户名或密码为空 |
| 401 | 用户名或密码错误 |
| 403001 | 需要验证码（频繁登录触发） |
| 429 | 登录尝试过于频繁 |

## 3. 刷新 Token

使用 Refresh Token 获取新的 Access Token。支持多种方式传递 Refresh Token。

### 请求

```
POST /auth/refresh
```

### 传递方式（按优先级）

| 方式 | 说明 |
|------|------|
| Cookie | 服务端读取 Cookie 中的 `refresh_token` |
| Header | `X-Refresh-Token: {refreshToken}` |
| Body | JSON 请求体中传递 `refreshToken` 字段 |

### 请求示例（Body 方式）

```json
{
  "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  },
  "error": "",
  "message": ""
}
```

### 错误码

| code | 说明 |
|------|------|
| 401 | Refresh Token 无效或已过期 |

## 4. 获取验证码

获取图形验证码，支持多种验证码类型。

### 请求

```
GET /auth/captcha?type={type}
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | string | 否 | 验证码类型，默认 `numeric` |

### 支持的验证码类型

| 类型 | 说明 |
|------|------|
| `numeric` | 数字验证码 |
| `slider` | 滑块验证码 |
| `puzzle` | 拼图验证码 |
| `rotation` | 旋转验证码 |
| `point` | 点选验证码 |

### 请求示例

```
GET /auth/captcha?type=slider
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "captchaId": "captcha_abc123",
    "captchaType": "slider",
    "image": "data:image/png;base64,iVBORw0KGgo...",
    "thumbImage": "data:image/png;base64,iVBORw0KGgo...",
    "height": 200,
    "width": 300
  },
  "error": "",
  "message": ""
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| captchaId | string | 验证码 ID，提交答案时需回传 |
| captchaType | string | 验证码类型 |
| image | string | 验证码图片（Base64） |
| thumbImage | string | 缩略图（滑块/拼图类型） |
| height | number | 图片高度 |
| width | number | 图片宽度 |

## 9. 发送邮箱验证码

发送邮箱验证码，用于注册、重置密码等场景。需先通过图形验证码验证。

### 请求

```
POST /auth/send-code
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| email | string | 是 | 邮箱地址 |
| purpose | string | 是 | 用途：`register` / `reset_password` / `login` |
| captchaId | string | 是 | 图形验证码 ID |
| captchaCode | string | 是 | 图形验证码答案 |
| startTime | number | 否 | 验证开始时间戳 |

### 请求示例

```json
{
  "email": "user@example.com",
  "purpose": "register",
  "captchaId": "captcha_abc123",
  "captchaCode": "5678",
  "startTime": 1718640000000
}
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "expireSeconds": 300
  },
  "error": "",
  "message": "验证码已发送"
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| expireSeconds | number | 验证码有效期（秒） |

### 错误码

| code | 说明 |
|------|------|
| 400 | 参数校验失败 |
| 429 | 发送过于频繁（60秒内不可重复发送） |
| 403001 | 图形验证码错误 |

## 16. 获取权限版本

获取当前用户的权限版本 hash，用于前端判断权限是否变更（变更时需重新加载路由）。

### 请求

```
GET /auth/permission-version
Authorization: Bearer {token}
```

### 请求参数

无。

### 响应示例

```json
{
  "code": 0,
  "data": {
    "version": "a1b2c3d4e5f6"
  },
  "error": "",
  "message": ""
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| version | string | 权限版本 hash，权限变更后会改变 |

### 使用场景

前端在每次路由切换或定时轮询时调用此接口，对比本地缓存的版本号。如果版本号发生变化，说明用户权限已被管理员修改，需要重新获取权限码和动态路由。
