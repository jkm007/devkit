## 用户管理

### 获取用户列表

```
GET /system/user/list
Authorization: Bearer {token}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | number | 否 | 页码 |
| pageSize | number | 否 | 每页条数 |
| keyword | string | 否 | 搜索（用户名/昵称/邮箱） |
| status | number | 否 | 状态：0禁用 1正常 |
| roleId | number | 否 | 角色筛选 |

### 响应示例

```json
{
  "code": 0,
  "data": {
    "items": [
      {
        "id": 1,
        "username": "admin",
        "nickname": "管理员",
        "email": "admin@example.com",
        "phone": "13800138000",
        "status": 1,
        "roles": [
          {"id": 1, "name": "admin", "label": "管理员"}
        ],
        "lastLoginAt": "2026-06-18T10:00:00Z",
        "createdAt": "2024-01-01T00:00:00Z"
      }
    ],
    "total": 1250
  },
  "error": "",
  "message": ""
}
```

### 创建用户

```
POST /system/user
Authorization: Bearer {token}
```

```json
{
  "username": "newuser",
  "password": "123456",
  "nickname": "新用户",
  "email": "newuser@example.com",
  "phone": "13900139000",
  "roleIds": [2],
  "groupIds": [1],
  "status": 1
}
```

### 更新用户

```
PUT /system/user/:id
Authorization: Bearer {token}
```

```json
{
  "nickname": "更新昵称",
  "email": "updated@example.com",
  "roleIds": [2, 3],
  "status": 1
}
```

### 删除用户

```
DELETE /system/user/:id
Authorization: Bearer {token}
```

## 角色管理

### 获取角色列表

```
GET /system/role/list
Authorization: Bearer {token}
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "items": [
      {
        "id": 1,
        "name": "admin",
        "label": "管理员",
        "description": "系统管理员",
        "permissions": ["user:read", "user:write", "system:admin"],
        "userCount": 3,
        "createdAt": "2024-01-01T00:00:00Z"
      }
    ],
    "total": 5
  },
  "error": "",
  "message": ""
}
```

### 创建角色

```
POST /system/role
Authorization: Bearer {token}
```

```json
{
  "name": "editor",
  "label": "编辑",
  "description": "内容编辑角色",
  "permissionIds": [1, 2, 3, 10, 11]
}
```

### 更新角色

```
PUT /system/role/:id
Authorization: Bearer {token}
```

```json
{
  "label": "高级编辑",
  "description": "高级内容编辑角色",

}
```

### 删除角色

```
DELETE /system/role/:id
Authorization: Bearer {token}
```

### 错误码

| code | 说明 |
|------|------|
| 400 | 不能删除系统内置角色 |
| 409 | 角色下仍有用户 |

| 参数 | 类型 | 必填 | 说明 |

| action | string | 否 | 操作类型 |
| userId | number | 否 | 用户 ID |
| startDate | string | 否 | 开始日期 |
| endDate | string | 否 | 结束日期 |

### 响应示例

```json
{
  "code": 0,
  "data": {
    "items": [
      {
        "id": 1,
        "action": "user.login",
        "description": "用户登录",
        "userId": 1,

  },
  "error": "",
  "message": ""
}
```

### 操作类型

| 类型 | 说明 |
|------|------|
| user.login | 用户登录 |
| user.logout | 用户登出 |
| user.register | 用户注册 |

## 题目管理

### 获取题目列表

```
GET /system/questions
Authorization: Bearer {token}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | number | 否 | 页码 |
| pageSize | number | 否 | 每页条数 |
| keyword | string | 否 | 搜索 |
| questionType | string | 否 | 题目类型 |
| categoryId | number | 否 | 分类 ID |
| subjectId | number | 否 | 科目 ID |
| difficulty | number | 否 | 难度 |
| status | string | 否 | 状态：draft/published/archived |
| auditStatus | string | 否 | 审核状态：pending/approved/rejected |

### 响应示例

```json
{
  "code": 0,
  "data": {
    "items": [
      {
        "id": 101,
        "title": "以下哪个是JavaScript的基本数据类型？",
        "questionType": "single_choice",
        "difficulty": 1,
        "categoryId": 5,
        "categoryName": "前端基础",
        "subjectId": 1,
        "subjectName": "Web开发",
        "status": "published",
        "auditStatus": "approved",
        "usageCount": 150,
        "correctRate": 85.5,
        "createdBy": {"id": 1, "username": "admin"},
        "createdAt": "2026-01-15T10:00:00Z"
      }
    ],
    "total": 8500
  },
  "error": "",
  "message": ""
}
```

### 创建题目

```
POST /system/questions
Authorization: Bearer {token}
```

```json
{
  "title": "新题目",
  "content": "题目内容",
  "questionType": "single_choice",
  "difficulty": 2,
  "categoryId": 5,
  "subjectId": 1,
  "options": [
    {"key": "A", "value": "选项A"},
    {"key": "B", "value": "选项B"},
    {"key": "C", "value": "选项C"},
    {"key": "D", "value": "选项D"}
  ],
  "answer": "B",
  "analysis": "解析内容",
  "knowledgePoints": ["知识点1"],
  "sourceId": 1,
  "status": "draft"
}
```

### 更新题目

```
PUT /system/questions/:id
Authorization: Bearer {token}
```

### 删除题目

```
DELETE /system/questions/:id
Authorization: Bearer {token}
```

### 发布题目

```
POST /system/questions/:id/publish
Authorization: Bearer {token}
```

### 提交审核

```
POST /system/questions/:id/submit-audit
Authorization: Bearer {token}
```

### 审核通过

```
POST /system/questions/:id/approve
Authorization: Bearer {token}
```

### 审核驳回

```
POST /system/questions/:id/reject
Authorization: Bearer {token}
```

```json
{
  "comment": "驳回原因"
}
```

### 归档题目

```

```

### 撤回题目

```

Authorization: Bearer {token}
```

### 重新激活题目

```
POST /system/questions/:id/reactivate
Authorization: Bearer {token}
```

### 删除我的分享

```
DELETE /shares/:id
Authorization: Bearer {token}
```

### 获取文件分享列表（管理端）

```
GET /files/shares
Authorization: Bearer {token}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | number | 否 | 页码 |
| pageSize | number | 否 | 每页条数 |
| status | string | 否 | 状态：active/expired/disabled |

### 更新分享有效期

```
PUT /files/shares/:id/renew
Authorization: Bearer {token}
```

```json
{
  "expireDays": 30
}
```

### 过期分享

```
PUT /files/shares/:id/expire
Authorization: Bearer {token}
```

### 设置分享过期时间

```
PUT /files/shares/:id/expiry
Authorization: Bearer {token}
```

```json
{
  "expireAt": "2026-08-01T00:00:00Z"
}
```

### 禁用分享

```
PUT /files/shares/:id/disable
Authorization: Bearer {token}
```

### 启用分享

```
PUT /files/shares/:id/enable
Authorization: Bearer {token}
```

### 创建文件夹分享

```
POST /folders/:id/share
Authorization: Bearer {token}
```

```json
{
  "expireDays": 7,
  "password": "optional_password"
}
```
