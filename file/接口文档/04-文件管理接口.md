## 分片上传

### 上传流程

```
秒传检测 → 初始化上传 → 上传分片 → 完成上传
         ↓
    (已存在) 直接返回文件信息
```

### 1. 秒传检测

检测文件是否已存在（基于文件哈希），实现秒传。

### 请求

```
POST /files/upload/check
Authorization: Bearer {token}
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| fileHash | string | 是 | 文件 MD5 哈希值 |
| fileSize | number | 是 | 文件大小（字节） |
| folderId | number | 否 | 目标文件夹 ID |

### 请求示例

```json
{
  "fileHash": "d41d8cd98f00b204e9800998ecf8427e",
  "fileSize": 10485760,
  "folderId": 5
}
```

### 响应示例（文件已存在，秒传成功）

```json
{
  "code": 0,
  "data": {
    "existed": true,
    "file": {
      "id": 100,
      "name": "document.pdf",
      "size": 10485760,
      "url": "/api/v1/files/100/view",
      "contentType": "application/pdf",
      "createdAt": "2026-06-01T10:00:00Z"
    }
  },
  "error": "",
  "message": "文件已存在，秒传成功"
}
```

### 响应示例（文件不存在，需正常上传）

```json
{
  "code": 0,
  "data": {
    "existed": false,
    "file": null
  },
  "error": "",
  "message": ""
}
```

### 2. 初始化分片上传

初始化一个分片上传任务。

### 请求

```
POST /files/upload/init
Authorization: Bearer {token}
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| fileName | string | 是 | 文件名 |
| fileSize | number | 是 | 文件大小（字节） |
| fileHash | string | 是 | 文件 MD5 哈希值 |
| contentType | string | 是 | 文件 MIME 类型 |
| totalParts | number | 是 | 总分片数 |
| folderId | number | 否 | 目标文件夹 ID |

### 请求示例

```json
{
  "fileName": "video.mp4",
  "fileSize": 104857600,
  "fileHash": "abc123def456",
  "contentType": "video/mp4",
  "totalParts": 10,
  "folderId": 5
}
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "uploadId": "upload_xyz789",
    "fileName": "video.mp4",
    "fileSize": 104857600,
    "totalParts": 10,
    "partSize": 10485760,
    "uploadedParts": []
  },
  "error": "",
  "message": "上传任务已创建"
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| uploadId | string | 上传任务 ID |
| partSize | number | 每个分片大小（字节） |
| uploadedParts | array | 已上传的分片编号（用于断点续传） |

### 3. 上传分片

上传单个分片。

### 请求

```
POST /files/upload/part
Authorization: Bearer {token}
Content-Type: multipart/form-data
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| uploadId | string | 是 | 上传任务 ID |
| partNumber | number | 是 | 分片编号（从 1 开始） |
| file | file | 是 | 分片文件数据 |

### 请求示例（multipart/form-data）

```
------WebKitFormBoundary
Content-Disposition: form-data; name="uploadId"

upload_xyz789
------WebKitFormBoundary
Content-Disposition: form-data; name="partNumber"

1
------WebKitFormBoundary
Content-Disposition: form-data; name="file"; filename="part1"
Content-Type: application/octet-stream

(二进制数据)
------WebKitFormBoundary--
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "partNumber": 1,
    "etag": "etag_abc123",
    "size": 10485760
  },
  "error": "",
  "message": "分片上传成功"
}
```

查询上传任务的当前状态。

### 请求

```
GET /files/upload/status?uploadId=upload_xyz789
Authorization: Bearer {token}
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| uploadId | string | 是 | 上传任务 ID |

### 响应示例

```json
{
  "code": 0,
  "data": {
    "uploadId": "upload_xyz789",
    "status": "uploading",
    "fileName": "video.mp4",
    "fileSize": 104857600,
    "totalParts": 10,
    "uploadedParts": [1, 2, 3, 4, 5],
    "progress": 50,
    "createdAt": "2026-06-18T10:00:00Z"
  },
  "error": "",
  "message": ""
}
```

### 上传状态

| 状态 | 说明 |
|------|------|
| uploading | 上传中 |
| completing | 合并中 |
| completed | 已完成 |
| failed | 上传失败 |
| aborted | 已取消 |

## 文件夹管理

### 8. 创建文件夹

创建新文件夹。

### 请求

```
POST /files/folder
Authorization: Bearer {token}
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 文件夹名称（最长 255 字符） |
| parentId | number | 否 | 父文件夹 ID，不传则创建在根目录 |

### 请求示例

```json
{
  "name": "项目文档",
  "parentId": 5
}
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "id": 30,
    "name": "项目文档",
    "parentId": 5,
    "path": "/根目录/子目录/项目文档",
    "createdAt": "2026-06-18T10:00:00Z"
  },
  "error": "",
  "message": "创建成功"
}
```

### 错误码

| code | 说明 |
|------|------|
| 400 | 文件夹名称为空或超出长度限制 |
| 404 | 父文件夹不存在 |
| 409 | 同级目录下已存在同名文件夹 |

### 11. 删除文件夹

删除指定文件夹及其内容。

### 请求

```
DELETE /files/folder/:id
Authorization: Bearer {token}
```

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | number | 是 | 文件夹 ID |

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| force | boolean | 否 | 是否强制删除非空文件夹，默认 false |

### 响应示例

```json
{
  "code": 0,
  "data": {
    "deletedFiles": 8,
    "deletedFolders": 2
  },
  "error": "",
  "message": "删除成功"
}
```

### 错误码

| code | 说明 |
|------|------|
| 400 | 文件夹非空且未设置 force |
| 403 | 无权操作 |
| 404 | 文件夹不存在 |

分页获取文件列表。

### 请求

```
GET /files/list
Authorization: Bearer {token}
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| folderId | number | 否 | 文件夹 ID，不传则获取根目录 |
| page | number | 否 | 页码，默认 1 |
| pageSize | number | 否 | 每页条数，默认 20 |
| keyword | string | 否 | 文件名关键词搜索 |
| contentType | string | 否 | 文件类型筛选 |
| scope | string | 否 | 范围：`my` / `shared` / `all`，默认 `my` |

### 请求示例

```
GET /files/list?folderId=5&page=1&pageSize=20&keyword=报告
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "items": [
      {
        "id": 100,
        "name": "document.pdf",
        "size": 10485760,
        "contentType": "application/pdf",
        "folderId": 5,
        "url": "/api/v1/files/100/view",
        "thumbnail": "/api/v1/files/100/view?thumb=true",
        "owner": {
          "id": 1,
          "username": "admin",
          "nickname": "管理员"
        },
        "isShared": false,
        "tags": ["重要", "文档"],
        "createdAt": "2026-06-01T10:00:00Z",
        "updatedAt": "2026-06-15T08:00:00Z"
      }
    ],
    "total": 35
  },
  "error": "",
  "message": ""
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 文件 ID |
| name | string | 文件名 |
| size | number | 文件大小（字节） |
| contentType | string | MIME 类型 |
| folderId | number | 所属文件夹 ID |
| url | string | 文件访问地址 |
| thumbnail | string | 缩略图地址 |
| isShared | boolean | 是否已分享 |
| tags | array | 标签列表 |
