## 题目管理

### 1. 获取题目列表

分页获取题目列表，支持多条件筛选。

### 请求

```
GET /study/questions
Authorization: Bearer {token}
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | number | 否 | 页码，默认 1 |
| pageSize | number | 否 | 每页条数，默认 20 |
| questionType | string | 否 | 题目类型：single_choice/multiple_choice/true_false/fill_blank/short_answer |
| categoryId | number | 否 | 分类 ID |
| subjectId | number | 否 | 科目 ID |
| difficulty | number | 否 | 难度：1简单 2中等 3困难 |
| keyword | string | 否 | 关键词搜索 |
| knowledgePoint | string | 否 | 知识点筛选 |

### 请求示例

```
GET /study/questions?page=1&pageSize=20&difficulty=2&categoryId=5
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "items": [
      {
        "id": 101,
        "title": "以下哪个是JavaScript的基本数据类型？",
        "questionType": "single_choice",
        "difficulty": 1,
        "categoryId": 5,
        "categoryName": "前端基础",
        "subjectId": 1,
        "subjectName": "Web开发",
        "options": [
          {"key": "A", "value": "Array"},
          {"key": "B", "value": "Object"},
          {"key": "C", "value": "String"},
          {"key": "D", "value": "Map"}
        ],
        "answer": "C",
        "analysis": "String是JavaScript的基本数据类型，Array、Object、Map是引用类型。",
        "knowledgePoints": ["数据类型", "基础语法"],
        "isFavorited": false,
        "createdAt": "2026-01-15T10:00:00Z"
      }
    ],
    "total": 156
  },
  "error": "",
  "message": ""
}
```

## 笔记管理

### 6. 创建笔记

为指定题目创建学习笔记。

### 请求

```
POST /user/notes
Authorization: Bearer {token}
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| questionId | number | 是 | 题目 ID |
| content | string | 是 | 笔记内容（最长 5000 字） |

### 请求示例

```json
{
  "questionId": 101,
  "content": "JavaScript有7种基本数据类型：String、Number、BigInt、Boolean、undefined、null、Symbol。"
}
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "id": 50,
    "questionId": 101,
    "content": "JavaScript有7种基本数据类型...",
    "createdAt": "2026-06-18T10:00:00Z"
  },
  "error": "",
  "message": "笔记创建成功"
}
```

### 错误码

| code | 说明 |
|------|------|
| 400 | 内容为空或超出长度限制 |
| 404 | 题目不存在 |

## 练习功能

### 10. 获取练习题目

根据条件获取练习题目集。

### 请求

```
POST /study/practice/questions
Authorization: Bearer {token}
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| categoryId | number | 否 | 分类 ID |
| subjectId | number | 否 | 科目 ID |
| difficulty | number | 否 | 难度：1简单 2中等 3困难 |
| count | number | 否 | 题目数量，默认 10，最大 50 |
| questionTypes | array | 否 | 题目类型数组 |

### 请求示例

```json
{
  "categoryId": 5,
  "difficulty": 2,
  "count": 10,
  "questionTypes": ["single_choice", "multiple_choice"]
}
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "practiceId": "practice_abc123",
    "questions": [
      {
        "id": 101,
        "index": 1,
        "title": "以下哪个是JavaScript的基本数据类型？",
        "questionType": "single_choice",
        "difficulty": 1,
        "options": [
          {"key": "A", "value": "Array"},
          {"key": "B", "value": "Object"},
          {"key": "C", "value": "String"},
          {"key": "D", "value": "Map"}
        ]
      }
    ],
    "total": 10
  },
  "error": "",
  "message": ""
}
```

### 响应字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| practiceId | string | 练习会话 ID，提交结果时需回传 |
| questions | array | 题目列表（不含答案） |
| total | number | 题目总数 |

---

### 11. 提交练习结果

提交练习完成后的结果。

### 请求

```
POST /study/practice/submit
Authorization: Bearer {token}
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| practiceId | string | 是 | 练习会话 ID |
| total | number | 是 | 总题数 |
| answered | number | 是 | 已答题数 |
| correct | number | 是 | 正确题数 |
| elapsed | number | 是 | 耗时（秒） |
| answers | array | 是 | 答题详情 |

### answers 数组元素

| 字段 | 类型 | 说明 |
|------|------|------|
| questionId | number | 题目 ID |
| answer | string | 用户答案 |
| isCorrect | boolean | 是否正确 |
| elapsed | number | 该题耗时（秒） |

### 请求示例

```json
{
  "practiceId": "practice_abc123",
  "total": 10,
  "answered": 10,
  "correct": 8,
  "elapsed": 360,
  "answers": [
    {
      "questionId": 101,
      "answer": "C",
      "isCorrect": true,
      "elapsed": 30
    },
    {
      "questionId": 102,
      "answer": "A",
      "isCorrect": false,
      "elapsed": 45
    }
  ]
}
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "practiceId": "practice_abc123",
    "total": 10,
    "answered": 10,
    "correct": 8,
    "correctRate": 80,
    "elapsed": 360,
    "rank": "超过60%的用户"
  },
  "error": "",
  "message": "提交成功"
}
```

```
POST /study/wrong/batch
Authorization: Bearer {token}
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| items | array | 是 | 错题列表 |

| 字段 | 类型 | 必填 | 说明 |

```json
}
```

### 29. 题目纠错反馈

### 请求

```
POST /study/feedback
Authorization: Bearer {token}
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| questionId | number | 是 | 题目 ID |
| type | string | 是 | 反馈类型：answer_error/content_error/analysis_error/other |

```json
}
```

### 响应示例

```json
{
  "code": 0,
  "data": {
    "id": 10,
    "status": "pending"
  },
  "error": "",
  "message": "反馈提交成功"
}
```

### 30. 我的反馈列表

分页获取当前用户的反馈列表。

### 请求

```
GET /study/feedback
Authorization: Bearer {token}
```

### 请求参数

| 参数 | 类型 | 必填 | 说明 |

```json
  "error": "",
  "message": ""
}
```

| 状态 | 说明 |
