## 1. qb_exam_categories 考试大类表

**说明**：考试分类的顶层目录，支持树形结构，如"公务员考试"、"职业资格考试"等大类。

**软删除**：是（`deleted_at`）

### 字段定义

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INT UNSIGNED | PRIMARY KEY, AUTO_INCREMENT | 考试大类ID |
| parent_id | INT UNSIGNED | DEFAULT 0, INDEX | 父级ID，0表示顶级 |
| name | VARCHAR(100) | NOT NULL | 考试大类名称 |
| code | VARCHAR(50) | DEFAULT '' | 分类编码 |
| path | VARCHAR(1000) | DEFAULT '' | 物化路径（如 /1/5/12） |
| level | INT | DEFAULT 1 | 层级深度 |
| sort_order | INT | DEFAULT 0 | 排序值（越小越靠前） |
| status | TINYINT | DEFAULT 1 | 状态：1启用 0禁用 |
| created_by | INT UNSIGNED | NOT NULL | 创建人用户ID |
| created_at | DATETIME | NOT NULL | 创建时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |
| deleted_at | DATETIME | NULL, INDEX | 软删除时间 |

### 索引

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| PRIMARY | 主键 | id | - |
| idx_qb_exam_categories_parent_id | 普通 | parent_id | 按父级查询子分类 |
| idx_qb_exam_categories_deleted_at | 普通 | deleted_at | 软删除查询 |

### 关系

- 自引用：通过 `parent_id` 字段形成树形结构
- 一对多：`qb_exams`（具体考试）

## 7. qb_questions 题目主表

**说明**：题库核心表，存储所有题目的内容、答案、解析及元数据。支持单选、多选、判断、填空、简答、组合题等多种题型。

**软删除**：是（`deleted_at`）

### 字段定义

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INT UNSIGNED | PRIMARY KEY, AUTO_INCREMENT | 题目ID |
| title | VARCHAR(500) | NOT NULL | 题目标题/摘要（用于列表展示） |
| question_type | VARCHAR(50) | NOT NULL, INDEX | 题型：single_choice / multiple_choice / true_false / fill_blank / short_answer / essay / combination |
| stem | JSON | NOT NULL | 题干内容（富媒体内容块数组） |
| content | JSON | - | 题型结构内容（选项列表、填空位等） |
| answer | JSON | - | 编辑态标准答案 |
| analysis | JSON | - | 解析内容（富媒体内容块数组） |
| materials | JSON | - | 附加材料（案例材料、阅读材料等） |
| score_rule | JSON | - | 判分规则（分值、部分得分策略等） |
| exam_id | INT UNSIGNED | DEFAULT 0, INDEX | 所属考试ID |
| subject_id | INT UNSIGNED | DEFAULT 0, INDEX | 所属科目ID |
| category_id | INT UNSIGNED | DEFAULT 0, INDEX | 所属章节分类ID |
| source_id | INT UNSIGNED | DEFAULT 0 | 题目来源ID |
| difficulty | TINYINT | DEFAULT 1 | 难度等级：1简单 2中等 3困难 |
| resource_type | VARCHAR(20) | DEFAULT 'private' | 资源类型：public公开 / private私有 / group分组 / user用户 |
| status | VARCHAR(20) | DEFAULT 'draft', INDEX | 状态：draft草稿 / pending_review待审 / published已发布 / archived已归档 |
| current_version_id | INT UNSIGNED | DEFAULT 0 | 当前生效版本ID |
| source_import_task_id | INT UNSIGNED | DEFAULT 0 | 来源导入任务ID（批量导入时记录） |
| parent_id | INT UNSIGNED | DEFAULT 0, INDEX | 父题ID（组合题场景） |
| is_group | TINYINT | DEFAULT 0 | 是否为组合题父题：0否 1是 |
| sub_index | INT | DEFAULT 0 | 子题在组合题中的排序位置 |
| stem_hash | VARCHAR(64) | DEFAULT '' | 题干内容指纹（用于去重） |
| content_hash | VARCHAR(64) | DEFAULT '' | 内容指纹 |
| answer_hash | VARCHAR(64) | DEFAULT '' | 答案指纹 |
| analysis_visible_policy | VARCHAR(30) | DEFAULT 'after_answer' | 解析可见策略：always始终 / after_answer答题后 / after_submit提交后 / never不显示 |
| answer_visible_policy | VARCHAR(30) | DEFAULT 'after_answer' | 答案可见策略：always / after_answer / after_submit / never |
| created_by | INT UNSIGNED | NOT NULL, INDEX | 创建人用户ID |
| updated_by | INT UNSIGNED | DEFAULT 0, INDEX | 最后修改人用户ID |
| reviewed_by | INT UNSIGNED | DEFAULT 0 | 审核人用户ID |
| reviewed_at | DATETIME | NULL | 审核时间 |
| reject_reason | VARCHAR(500) | DEFAULT '' | 审核驳回原因 |
| published_at | DATETIME | NULL | 首次发布时间 |
| deleted_by | INT UNSIGNED | DEFAULT 0 | 删除人用户ID（记录谁执行了删除） |
| recycle_expire_at | DATETIME | NULL | 回收站过期时间（过期后物理删除） |
| created_at | DATETIME | NOT NULL | 创建时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |
| deleted_at | DATETIME | NULL, INDEX | 软删除时间 |

### JSON 字段结构示例

**stem（题干）**：
```json
[
  {"type": "text", "content": "下列关于MySQL的说法，正确的是"},
  {"type": "image", "url": "/files/diagram.png", "width": 400, "height": 300}
]
```

**content（选项 - 单选题）**：
```json
[
  {"key": "A", "content": [{"type": "text", "content": "InnoDB支持事务"}]},
  {"key": "B", "content": [{"type": "text", "content": "MyISAM支持事务"}]},
  {"key": "C", "content": [{"type": "text", "content": "Memory不支持索引"}]},
  {"key": "D", "content": [{"type": "text", "content": "CSV支持外键"}]}
]
```

**answer（答案）**：
```json
{"keys": ["A"], "content": [{"type": "text", "content": "A"}]}
```
