## 1. sys_users 用户表

**说明**：系统用户主表，存储所有注册用户的基本信息、认证信息和账户状态。

**软删除**：是（`deleted_at`）

### 字段定义

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INT UNSIGNED | PRIMARY KEY, AUTO_INCREMENT | 用户ID |
| name | VARCHAR(50) | NOT NULL | 用户名（登录账号） |
| nickname | VARCHAR(50) | DEFAULT '' | 昵称 |
| email | VARCHAR(100) | DEFAULT '' | 邮箱 |
| phone | VARCHAR(20) | DEFAULT '' | 手机号 |
| avatar | VARCHAR(1000) | DEFAULT '' | 头像URL |
| gender | TINYINT | DEFAULT 0 | 性别：0未知 1男 2女 |
| birthday | DATETIME | NULL | 生日 |
| bio | VARCHAR(500) | DEFAULT '' | 个人简介 |
| password | VARCHAR(255) | NOT NULL | 密码（bcrypt加密） |
| status | TINYINT | DEFAULT 1 | 状态：1启用 0禁用 |
| group_id | INT UNSIGNED | - | 所属分组ID |
| real_name | VARCHAR(50) | DEFAULT '' | 真实姓名 |
| id_card | VARCHAR(255) | DEFAULT '' | 身份证号（AES加密存储） |
| is_real | TINYINT | DEFAULT 0 | 是否已实名：0否 1是 |
| register_source | VARCHAR(20) | DEFAULT 'web' | 注册来源：web/h5/app/miniapp |
| last_login_at | DATETIME | NULL | 最后登录时间 |
| last_login_ip | VARCHAR(50) | DEFAULT '' | 最后登录IP |
| last_login_device | VARCHAR(200) | DEFAULT '' | 最后登录设备信息 |
| login_fail_count | INT | DEFAULT 0 | 连续登录失败次数 |
| lock_until | DATETIME | NULL | 账户锁定截止时间 |
| password_changed_at | DATETIME | NULL | 密码最后修改时间 |
| must_change_password | TINYINT(1) | DEFAULT FALSE | 是否需要强制修改密码 |
| storage_quota | BIGINT | DEFAULT 0 | 用户覆盖存储配额（字节），0表示使用角色配额 |
| storage_used | BIGINT | DEFAULT 0 | 已使用存储空间（字节） |
| remark | VARCHAR(500) | - | 备注 |
| created_at | DATETIME | NOT NULL | 创建时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |
| deleted_at | DATETIME | NULL, INDEX | 软删除时间 |

### 索引

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| PRIMARY | 主键 | id | - |
| idx_sys_users_deleted_at | 普通 | deleted_at | 软删除查询 |

### 关系

- 一对多：`sys_user_roles`（用户-角色关联）
- 一对多：`sys_security_logs`（安全日志）
- 一对多：`sys_login_devices`（登录设备）
- 一对一：`sys_oauth_users`（OAuth绑定）
- 一对一：`sys_user_privacy`（隐私设置）
- 一对多：`sys_password_history`（密码历史）
- 一对一：`sys_user_real_names`（实名认证）
- 一对多：`sys_role_applications`（角色申请）
- 多对一：`sys_groups`（所属分组）

## 3. sys_user_roles 用户角色关联表

### 字段定义

| 字段名 | 类型 | 约束 | 说明 |

## 4. sys_menus 菜单表

**说明**：系统菜单和权限资源定义表，支持目录、菜单、嵌入页面、链接、按钮五种类型。

**软删除**：是（`deleted_at`）

### 字段定义

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INT UNSIGNED | PRIMARY KEY, AUTO_INCREMENT | 菜单ID |
| pid | INT UNSIGNED | DEFAULT 0 | 父菜单ID，0表示顶级 |
| name | VARCHAR(100) | NOT NULL | 菜单名称 |
| path | VARCHAR(200) | - | 路由地址 |
| component | VARCHAR(200) | - | 前端组件路径 |
| type | VARCHAR(20) | NOT NULL | 类型：catalog目录 / menu菜单 / embedded嵌入 / link链接 / button按钮 |
| status | TINYINT | DEFAULT 1 | 状态：1启用 0禁用 |
| auth_code | VARCHAR(100) | - | 权限码（用于按钮级权限控制） |
| icon | VARCHAR(100) | - | 图标标识 |
| sort | INT | DEFAULT 0 | 排序值（越小越靠前） |
| meta | TEXT | - | 元数据（JSON，包含 title、hideInMenu、keepAlive、badge 等） |
| created_at | DATETIME | NOT NULL | 创建时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |
| deleted_at | DATETIME | NULL, INDEX | 软删除时间 |

### 索引

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| PRIMARY | 主键 | id | - |
| idx_sys_menus_deleted_at | 普通 | deleted_at | 软删除查询 |

### 关系

- 自引用：通过 `pid` 字段形成菜单树结构

### Meta 字段结构

```json
{
  "title": "页面标题",
  "icon": "图标",
  "order": 1,
  "hideInMenu": false,
  "keepAlive": true,
  "affixTab": false,
  "hideInTab": false,
  "hideChildrenInMenu": false,
  "badge": "new",
  "badgeType": "text",
  "iframeSrc": "",
  "link": ""
}
```

| deleted_at | DATETIME | NULL, INDEX | 软删除时间 |

### 索引

| 索引名 | 类型 | 字段 | 说明 |

| PRIMARY | 主键 | id | - |
