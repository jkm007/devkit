# 系统管理模块

> 本文档描述 DevKit 系统中系统管理相关的全部功能，包括仪表盘、用户管理、角色管理、菜单管理、分组管理、系统设置、安全日志、通知公告、定时任务、限流规则、风险评分、轮播图管理和移动端配置。

---

## 1. 仪表盘

### 系统统计

仪表盘提供系统运行状态的概览视图。

| 统计项 | 说明 |
|--------|------|
| 用户总数 | 系统注册用户数量 |
| 今日新增 | 今日新注册用户数 |
| 在线用户 | 当前在线用户数 |
| 题目总数 | 题库中的题目总数 |
| 今日练习 | 今日练习次数 |
| 文件总数 | 系统中的文件总数 |
| 存储用量 | 已使用的存储空间 |

### 数据图表

- 用户增长趋势（折线图）
- 题目增长趋势（折线图）
- 题型分布（饼图）
- 练习活跃度（柱状图）
- 系统资源使用（CPU / 内存 / 磁盘）

## 3. 角色管理

### 角色 CRUD

| 操作 | 说明 |
|------|------|
| 查看角色列表 | 展示所有角色及关联用户数 |
| 创建角色 | 创建新角色，填写名称、编码、描述 |
| 编辑角色 | 修改角色信息 |
| 删除角色 | 删除角色（需先解除所有用户关联） |

### 权限码配置

- 为角色分配权限码（permission code）
- 权限码对应菜单和按钮级别的操作权限
- 支持全选/取消全选
- 支持按模块分组展示权限

### 存储配额

- 为角色设置默认存储配额
- 配额类型：不限制 / 按容量限制 / 按文件数量限制
- 配额值：具体的容量或数量上限

## 6. 系统设置

### 设置分组

系统设置按功能分组管理：

| 分组 | 包含设置 |
|------|----------|
| **基本设置** | 系统名称、Logo、版权信息、备案号 |
| **邮件设置** | SMTP 服务器、端口、账号、密码、发件人名称 |
| **短信设置** | 短信服务商、Access Key、短信模板 |
| **验证码设置** | 验证码类型、有效期、长度、干扰度 |
| **存储设置** | 默认存储后端、文件大小限制、允许的文件类型 |
| **微信设置** | 小程序 AppID/Secret、公众号 AppID/Secret、网页应用 AppID/Secret |
| **安全设置** | 密码策略、登录失败锁定、会话超时、IP 白名单 |

### 设置管理

- 分组展示所有设置项
- 支持批量保存
- 修改即时生效（部分设置需重启服务）
- 敏感配置（密码、密钥）加密存储

## 9. 定时任务

### 任务管理

| 操作 | 说明 |
|------|------|
| 创建任务 | 创建定时任务，配置 Cron 表达式 |
| 编辑任务 | 修改任务配置 |
| 删除任务 | 删除定时任务 |
| 启用/禁用 | 控制任务是否自动执行 |
| 手动执行 | 立即执行一次任务 |
| 查看日志 | 查看任务执行历史 |

### Cron 表达式

标准 Cron 格式：`秒 分 时 日 月 周`

| 示例 | 说明 |
|------|------|
| `0 0 2 * * ?` | 每天凌晨 2 点执行 |
| `0 */5 * * * ?` | 每 5 分钟执行一次 |
| `0 0 0 1 * ?` | 每月 1 号零点执行 |
| `0 0 9 ? * MON-FRI` | 工作日上午 9 点执行 |

### 任务类型

| 类型 | 说明 |
|------|------|
| 回收站清理 | 自动清理过期的回收站文件 |
| Token 黑名单清理 | 清理过期的 Token 黑名单记录 |
| 日志清理 | 清理过期的操作日志 |
| 统计数据生成 | 定期生成统计数据 |
| 数据备份 | 定时备份数据库 |

## 10. 限流规则

### 规则配置

| 配置项 | 说明 |
|--------|------|
| 规则名称 | 规则标识名称 |
| 路径匹配 | API 路径匹配模式（支持通配符） |
| 方法匹配 | HTTP 方法（GET/POST/PUT/DELETE/ALL） |
| 令牌桶容量 | 桶中最大令牌数 |
| 令牌填充速率 | 每秒填充的令牌数 |
| 违规积分 | 每次违规扣除的积分 |
| 积分阈值 | 触发限制的积分阈值 |

### 令牌桶算法

```
请求到达
  │
  ▼
检查令牌桶
  ├── 有令牌 → 消耗令牌，放行请求
  └── 无令牌 → 拒绝请求，记录违规
                    │
                    ▼
              累加违规积分
                    │
                    ▼
              积分超过阈值？
              ├── 是 → 封禁 IP
              └── 否 → 等待令牌填充
```

### 规则管理

- 创建/编辑/删除限流规则
- 启用/禁用规则
- 规则优先级排序
- 测试规则效果

## 11. 风险评分

### IP 风险评分

系统对 IP 地址进行风险评分，用于安全防护。

| 评分 | 风险等级 | 说明 |
|------|----------|------|
| 0-30 | 低风险 | 正常访问 |
| 31-60 | 中风险 | 需要关注 |
| 61-80 | 高风险 | 可能存在恶意行为 |
| 81-100 | 极高风险 | 建议封禁 |

### 评分因素

| 因素 | 说明 |
|------|------|
| 登录失败次数 | 短时间内多次登录失败 |
| 请求频率 | 请求频率异常高 |
| 异常路径访问 | 访问不存在的路径（扫描行为） |
| 已知恶意 IP | 命中黑名单的 IP |
| 地理位置异常 | 异地登录 |

### 管理功能

| 功能 | 说明 |
|------|------|
| 查看评分列表 | 展示所有 IP 的风险评分 |
| 清除评分 | 重置某个 IP 的风险评分 |
| 评分统计 | 风险等级分布统计 |
| 手动封禁 | 手动将 IP 加入黑名单 |
| 白名单 | 将 IP 加入白名单，跳过风险检查 |
