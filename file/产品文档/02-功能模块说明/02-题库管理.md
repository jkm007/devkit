# 题库管理模块

> 本文档描述 DevKit 系统中题库管理相关的全部功能，包括考试分类体系、知识考点管理、来源标签管理、题目管理、题目状态流转、版本管理、导入导出、分享、纠错和统计。

---

## 1. 考试分类体系

系统采用 **4 级分类体系** 组织题目，结构清晰，便于检索和管理。

### 分类层级

```
考试大类（一级）
└── 具体考试（二级）
    └── 科目（三级）
        └── 章节分类（四级）
```

### 示例

```
计算机考试（一级）
└── 软考（二级）
    └── 软件设计师（三级）
        └── 数据结构与算法（四级）
        └── 操作系统（四级）
        └── 数据库系统（四级）
└── 计算机等级考试（二级）
    └── 二级 Python（三级）
        └── 基础语法（四级）
        └── 函数与模块（四级）
```

### 分类管理功能

| 功能 | 说明 |
|------|------|
| 新增分类 | 创建任意层级的分类节点 |
| 编辑分类 | 修改分类名称、排序、描述 |
| 删除分类 | 仅允许删除无子分类且无关联题目的分类 |
| 拖拽排序 | 支持拖拽调整同级分类顺序 |
| 移动分类 | 将分类移动到其他父级下 |

## 2. 知识考点管理

### 考点结构

知识考点采用**树形结构**管理，与科目和分类关联。

| 字段 | 说明 |
|------|------|
| 考点名称 | 知识点的名称 |
| 父级考点 | 上级知识点（支持多级） |
| 关联科目 | 该考点所属的科目 |
| 关联分类 | 该考点所属的章节分类 |
| 排序号 | 同级考点的显示顺序 |
| 描述 | 考点的详细说明 |

### 考点管理功能

- 创建/编辑/删除考点
- 树形结构展示，支持展开/折叠
- 关联题目查看（查看包含该考点的所有题目）
- 考点统计（关联题目数量、使用频率）

## 3. 来源标签管理

### 题目来源类型

| 来源 | 说明 |
|------|------|
| 真题 | 历年考试真题 |
| 模拟题 | 模拟考试题目 |
| 练习题 | 日常练习题目 |

## 4. 题目管理

### 4.1 题型支持

系统支持 **27 种题型**，覆盖教育考试领域的主流题型：

| 类别 | 值（value） | 题型 | 说明 |
|------|-------------|------|------|
| **基础客观题** | single_choice | 单选题 | 从多个选项中选择一个正确答案 |
| | multiple_choice | 多选题 | 从多个选项中选择多个正确答案 |
| | indefinite_choice | 不定项选择题 | 选项数量不定，可能有一个或多个正确答案 |
| | true_false | 判断题 | 判断陈述是否正确 |
| **填写类题** | fill_blank | 填空题 | 填写空白处的正确内容 |
| | cloze | 完形填空 | 在文章空白处填写正确内容 |
| | term_explanation | 名词解释 | 解释专业术语的含义 |
| **主观题** | short_answer | 简答题 | 简短文字回答 |
| | essay_question | 论述题 | 较长文字阐述 |
| | composition | 作文题 | 按要求撰写文章 |
| **组合题** | material | 材料题 | 基于材料进行分析 |
| | case_analysis | 案例分析题 | 基于案例进行分析 |
| | reading | 阅读理解题 | 阅读文章后回答问题 |
| | matching | 匹配题 | 将左右两列内容匹配 |
| **排序归类题** | ordering | 排序题 | 将内容按正确顺序排列 |
| | classification | 分类题 | 将内容按类别归类 |
| **音视频题** | listening | 听力题 | 听音频后作答 |
| | speaking | 口语题 | 口语表达类题目 |
| | video | 视频题 | 观看视频后作答 |
| **文档材料题** | document | 文档题 | 基于文档材料作答 |
| **计算实操题** | calculation | 计算题 | 需要计算过程和结果 |
| | proof | 证明题 | 需要推导证明过程 |
| | operation | 操作题 | 描述操作步骤 |
| **技术类题** | programming | 编程题 | 编写代码解决问题 |
| | sql | SQL题 | 编写 SQL 查询语句 |
| | code_reading | 代码阅读题 | 阅读代码写出结果 |
| | debugging | 调试改错题 | 找出并修正代码错误 |

### 4.2 题目 CRUD

**创建题目：**

| 字段 | 说明 |
|------|------|
| 题目类型 | 选择 27 种题型之一 |
| 题干内容 | 支持富文本，可包含图片、音频、视频、代码块 |
| 选项 | 选择题的选项列表（支持富文本） |
| 正确答案 | 标准答案 |
| 解析 | 答案解析（支持富文本） |
| 难度 | 简单 / 中等 / 困难 |
| 分值 | 题目分值 |
| 考试分类 | 关联 4 级分类 |
| 知识考点 | 关联知识点（可多个） |
| 来源标签 | 题目来源 |
| 标签 | 自定义标签 |

**编辑题目：**

- 支持修改所有字段
- 修改后自动创建版本记录
- 已发布题目修改后需重新审核

**删除题目：**

- 草稿状态可直接删除
- 已发布题目需先归档再删除
- 删除操作需二次确认

### 4.3 题目内容格式

题干和选项采用 **JSON 结构化内容** 格式，支持富媒体：

```json
{
  "blocks": [
    {
      "type": "text",
      "content": "以下哪个是 Go 语言的特点？"
    },
    {
      "type": "image",
      "url": "/uploads/go-features.png",
      "alt": "Go 语言特点示意图"
    },
    {
      "type": "code",
      "language": "go",
      "content": "func main() {\n    fmt.Println(\"Hello, Go!\")\n}"
    }
  ]
}
```

支持的内容块类型：

| 类型 | 说明 |
|------|------|
| text | 纯文本或富文本 |
| image | 图片 |
| audio | 音频 |
| video | 视频 |
| code | 代码块（支持语法高亮） |
| formula | 数学公式（LaTeX） |
| table | 表格 |

## 5. 题目状态流转

### 状态定义

```
                    ┌──────────┐
                    │   草稿    │
                    └────┬─────┘
                         │ 提交审核
                         ▼
                    ┌──────────┐
          ┌────────│  待审核   │────────┐
          │        └──────────┘        │
       通过│                        驳回│
          ▼                            ▼
    ┌──────────┐                 ┌──────────┐
    │  已发布   │                 │  已驳回   │
    └────┬─────┘                 └────┬─────┘
         │                            │
     归档│                        重新编辑│
         ▼                            │
    ┌──────────┐                      │
    │  已归档   │                      │
    └──────────┘                      │
         │                            │
     重新激活│                         │
         │                            │
         └────────────┬───────────────┘
                      │
                      ▼
                 ┌──────────┐
                 │   草稿    │
                 └──────────┘
```

### 状态说明

| 状态 | 说明 | 可执行操作 |
|------|------|-----------|
| 草稿 | 题目创建后的初始状态 | 编辑、提交审核、删除 |
| 待审核 | 已提交审核，等待审核员处理 | 审核通过、审核驳回（审核员）；撤回（出题人） |
| 已发布 | 审核通过，对用户可见 | 编辑（需重新审核）、归档 |
| 已驳回 | 审核未通过 | 编辑、重新提交审核 |
| 已归档 | 题目已下线，不再展示 | 重新激活（回到草稿） |

### 状态操作说明

| 操作 | 说明 |
|------|------|
| 提交审核 | 出题人将草稿/已驳回的题目提交审核 |
| 审核通过 | 审核员将题目状态改为已发布 |
| 审核驳回 | 审核员驳回题目并填写驳回原因 |
| 撤回 | 出题人撤回待审核的题目 |
| 归档 | 将已发布题目下线 |
| 重新激活 | 将已归档题目重新激活为草稿 |

## 6. 题目版本管理

### 版本记录

每次编辑已发布题目时，系统自动创建版本记录：

| 字段 | 说明 |
|------|------|
| 版本号 | 自动递增 |
| 修改时间 | 版本创建时间 |
| 修改人 | 执行修改的用户 |
| 修改内容 | 字段级别的变更记录（diff） |
| 题目快照 | 该版本的完整题目数据 |

### 版本功能

- 查看版本历史列表
- 对比任意两个版本的差异
- 回滚到指定历史版本
- 查看某次修改的详细变更

## 7. 题目导入

### 批量导入

支持通过 Excel 文件批量导入题目。

**导入流程：**

1. 下载导入模板（Excel）
2. 按模板格式填写题目数据
3. 上传文件，创建导入任务
4. 系统异步处理导入任务
5. 查看导入结果（成功/失败/跳过数量）

**导入任务管理：**

| 字段 | 说明 |
|------|------|
| 任务名称 | 导入任务的标识 |
| 文件名 | 上传的文件名 |
| 状态 | 待处理 / 处理中 / 已完成 / 失败 |
| 总数 | 文件中的题目总数 |
| 成功数 | 成功导入的数量 |
| 失败数 | 导入失败的数量 |
| 错误详情 | 失败题目的错误原因 |
| 创建时间 | 任务创建时间 |

### 导入项管理

- 查看每次导入的题目列表
- 按导入批次筛选题目
- 批量修改导入题目的分类/标签
- 删除整批导入的题目

## 8. 题目分享

### 分享功能

- 选择题目生成分享链接
- 可设置分享有效期（1 小时 / 1 天 / 7 天 / 30 天 / 永久）
- 可设置最大访问次数
- 被分享者无需登录即可查看题目

### 分享管理

| 功能 | 说明 |
|------|------|
| 生成分享 | 创建分享链接和二维码 |
| 启用/禁用 | 控制分享链接是否生效 |
| 查看统计 | 访问次数、访问人数 |
| 删除分享 | 删除分享链接 |

## 9. 题目纠错

### 纠错流程

1. 用户在练习/浏览时发现题目错误
2. 提交纠错反馈（选择错误类型、描述问题、可附截图）
3. 管理员在后台查看纠错列表
4. 管理员处理纠错（确认并修改 / 标记为无效）
5. 处理结果通知提交用户

### 错误类型

| 类型 | 说明 |
|------|------|
| 答案错误 | 正确答案标注有误 |
| 题干错误 | 题目描述有误 |
| 选项错误 | 选项内容有误 |
| 解析错误 | 答案解析有误 |
| 格式错误 | 排版、图片等格式问题 |
| 其他 | 其他类型错误 |

## 10. 题目统计

### 统计维度

| 维度 | 统计内容 |
|------|----------|
| 按题型 | 各题型的题目数量和占比 |
| 按难度 | 简单/中等/困难的题目数量和占比 |
| 按状态 | 各状态的题目数量和占比 |
| 按分类 | 各分类下的题目数量 |
| 按来源 | 各来源标签的题目数量 |
| 按时间 | 按日/周/月统计新增题目数量 |

### 统计展示

- 仪表盘数据卡片
- 柱状图 / 饼图 / 折线图
- 支持按时间范围筛选
- 支持导出统计报表
