> 本文档描述 DevKit 系统中文件管理相关的全部功能，包括文件上传、文件夹管理、文件操作、回收站、文件分享、媒体文件、存储后端、存储桶管理、标签系统、路由引擎、文件类型规则和文件安全。

## 1. 文件上传

### 上传方式

| 方式 | 说明 |
|------|------|
| 普通上传 | 单次请求上传完整文件，适用于小文件（< 50MB） |
| 分片上传 | 将大文件切分为多个分片逐个上传，适用于大文件 |
| 秒传检测 | 上传前检查文件哈希，若已存在则直接返回文件记录，无需重复上传 |
| 断点续传 | 分片上传中断后，从已上传的分片继续上传 |

### 分片上传流程

```
1. 客户端计算文件 MD5/SHA256 哈希
2. 调用秒传检测接口
   ├── 文件已存在 → 直接返回文件记录
   └── 文件不存在 → 继续上传
3. 初始化分片上传任务
   └── 服务端返回 upload_id
4. 逐个上传分片
   └── 每个分片上传成功后记录进度
5. 所有分片上传完成后，调用合并接口
6. 服务端合并分片，生成最终文件
7. 返回文件信息
```

### 上传进度

- 实时显示上传进度百分比
- 显示上传速度和剩余时间
- 支持暂停和恢复上传
- 支持取消上传

### 上传限制

| 限制项 | 默认值 | 说明 |
|--------|--------|------|
| 单文件大小 | 500MB | 可按角色配置不同限制 |
| 分片大小 | 5MB | 可配置 |
| 并发上传数 | 3 | 同时上传的分片数量 |
| 文件类型 | 可配置 | 白名单/黑名单机制 |

## 5. 回收站

### 回收站功能

| 功能 | 说明 |
|------|------|
| 软删除 | 删除的文件进入回收站，不立即物理删除 |
| 恢复 | 将回收站中的文件恢复到原位置 |
| 批量恢复 | 选择多个文件批量恢复 |
| 永久删除 | 从回收站中永久删除文件（物理删除） |
| 清空回收站 | 一次性永久删除回收站中的所有文件 |

### 过期自动清理

- 回收站中的文件默认保留 30 天
- 超过保留期限的文件自动永久删除
- 保留期限可配置
- 自动清理任务定期执行

### 回收站信息

| 字段 | 说明 |
|------|------|
| 文件名 | 文件原始名称 |
| 文件大小 | 文件体积 |
| 原始位置 | 文件被删除前所在的路径 |
| 删除时间 | 文件被删除的时间 |
| 过期时间 | 文件将被永久删除的时间 |
| 删除者 | 执行删除操作的用户 |

## 8. 存储后端

### 支持的存储后端

| 后端 | 说明 | 适用场景 |
|------|------|----------|
| **本地存储** | 文件存储在服务器本地磁盘 | 开发/测试环境、单机部署 |
| **MinIO** | 自建 S3 兼容对象存储 | 私有云部署 |
| **阿里云 OSS** | 阿里云对象存储服务 | 公有云生产环境 |
| **腾讯云 COS** | 腾讯云对象存储服务 | 公有云备选方案 |

### 热切换

- 支持运行时切换存储后端，无需重启服务
- 切换后新文件写入新后端，旧文件仍从原后端读取
- 支持文件迁移任务，将文件从一个后端迁移到另一个

### 存储后端配置

| 配置项 | 说明 |
|--------|------|
| 驱动类型 | local / minio / oss / cos |
| 访问密钥 | Access Key ID / Secret |
| 存储桶名称 | Bucket Name |
| 区域 | Region（云存储适用） |
| 端点 | Endpoint（MinIO 适用） |
| 域名 | 自定义域名（CDN） |
| 是否默认 | 是否为默认存储后端 |

## 12. 路由引擎

### 基于标签的文件路由

路由引擎根据文件标签自动分配存储后端。

**路由规则示例：**

| 优先级 | 条件（标签） | 目标存储 |
|--------|-------------|----------|
| 1 | 标签包含 `video` | MinIO（大文件桶） |
| 2 | 标签包含 `image` | 阿里云 OSS（CDN 加速） |
| 3 | 标签包含 `document` | 本地存储 |
| 4 | 默认 | MinIO（默认桶） |

### 路由规则管理

- 创建/编辑/删除路由规则
- 设置规则优先级
- 配置匹配条件（标签、文件类型、文件大小等）
- 配置目标存储后端
- 规则测试（模拟文件路由结果）

| 文件类型 | 扩展名 |

## 14. 文件安全

### 扩展名白名单/黑名单

| 机制 | 说明 |
|------|------|
| 白名单 | 仅允许上传白名单中的文件类型 |
| 黑名单 | 禁止上传黑名单中的文件类型 |
| 优先级 | 白名单优先于黑名单 |

### Magic Bytes 交叉验证

- 上传时不仅检查扩展名，还检查文件头的 Magic Bytes
- 防止通过修改扩展名绕过文件类型检查
- 支持常见文件类型的 Magic Bytes 库

### 路径遍历防护

- 严格校验文件路径，防止 `../` 路径遍历攻击
- 文件名自动清理，移除特殊字符
- 存储路径自动生成，不直接使用用户输入

### 其他安全措施

| 措施 | 说明 |
|------|------|
| 文件大小限制 | 按角色/存储桶配置大小限制 |
| 病毒扫描 | 可集成病毒扫描服务（ClamAV） |
| 访问控制 | 文件访问需经过认证鉴权 |
| 日志记录 | 记录所有文件操作的审计日志 |
| 加密存储 | 敏感文件支持加密存储 |
