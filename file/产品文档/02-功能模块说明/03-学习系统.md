# 学习系统模块

> 本文档描述 DevKit 系统中学习系统相关的全部功能，包括题目浏览、练习、智能练习、练习结果、练习历史、错题本、收藏管理、笔记管理、分类绑定和练习分析。

---

## 1. 题目浏览

### 浏览方式

用户可通过多种方式浏览题目：

| 方式 | 说明 |
|------|------|
| 分类浏览 | 按 4 级考试分类逐级筛选 |
| 关键词搜索 | 按题干内容、知识点关键词搜索 |
| 按难度筛选 | 简单 / 中等 / 困难 |
| 按知识点筛选 | 选择特定知识点查看关联题目 |
| 按题型筛选 | 选择特定题型查看题目 |
| 按来源筛选 | 按题目来源（真题、模拟题等）筛选 |

### 题目展示

- 分页展示题目列表
- 支持切换列表视图和卡片视图
- 显示题型、难度、分类等标签
- 点击进入题目详情页

### 题目详情

- 完整题干内容（含富媒体）
- 答题区域（根据题型自动适配）
- 提交答案后显示正确答案和解析
- 支持收藏、纠错、记笔记等操作

## 2. 题目练习

### 练习模式

| 模式 | 说明 |
|------|------|
| 随机练习 | 从题库中随机抽取题目 |
| 分类练习 | 从指定分类中抽取题目 |
| 顺序练习 | 按题目编号顺序作答 |
| 收藏练习 | 从收藏夹中抽取题目 |
| 错题练习 | 从错题本中抽取题目 |

### 练习配置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 题目数量 | 本次练习的题目数量 | 10 题 |
| 题型筛选 | 限定题型范围 | 全部题型 |
| 难度筛选 | 限定难度范围 | 全部难度 |
| 分类范围 | 限定题目来源分类 | 当前分类 |
| 时间限制 | 是否开启计时模式 | 不限时 |

### 答题流程

1. 选择练习模式和配置
2. 系统根据配置抽取题目
3. 逐题作答（支持上一题/下一题切换）
4. 全部作答后提交
5. 查看练习结果

### 答题交互

- **选择题**：点击选项选中，再次点击取消
- **填空题**：输入框填写答案
- **判断题**：点击正确/错误按钮
- **简答题**：文本框输入答案
- 支持标记题目（稍后作答）
- 支持题目导航面板快速跳转

## 3. 智能练习

### 智能推荐逻辑

系统基于以下因素智能推荐题目：

| 因素 | 权重 | 说明 |
|------|------|------|
| 错题记录 | 高 | 错误次数越多，优先级越高 |
| 薄弱知识点 | 高 | 正确率低的知识点优先推荐 |
| 难度匹配 | 中 | 根据用户当前水平推荐合适难度 |
| 时间衰减 | 中 | 长时间未练习的题目优先 |
| 新题优先 | 低 | 未做过的题目适当增加曝光 |

### 智能练习流程

1. 系统分析用户历史练习数据
2. 识别薄弱知识点和高频错题
3. 按权重生成推荐题目列表
4. 用户进行练习
5. 练习完成后更新知识掌握模型

### 自适应难度

- 根据用户连续答对/答错自动调整难度
- 答对率 > 80%：逐步提升难度
- 答对率 < 40%：逐步降低难度
- 答对率 40%-80%：保持当前难度

## 4. 练习结果

### 结果统计

| 指标 | 说明 |
|------|------|
| 总题数 | 本次练习的题目总数 |
| 正确数 | 答对的题目数量 |
| 正确率 | 正确数 / 总题数 |
| 用时 | 本次练习的总用时 |
| 平均用时 | 每道题的平均用时 |
| 得分 | 根据题目分值计算的总分 |

### 结果详情

- 逐题查看作答情况
- 正确/错误标记
- 显示正确答案和用户答案
- 显示答案解析
- 错题自动加入错题本

### 结果提交

- 练习结果自动提交到后端保存
- 用于后续的学习分析和统计
- 支持离线练习，联网后自动同步

## 5. 练习历史

### 历史记录

| 字段 | 说明 |
|------|------|
| 练习时间 | 练习开始时间 |
| 练习模式 | 随机/分类/智能等 |
| 题目数量 | 本次练习的题目数 |

## 6. 错题本

### 6.1 自动记录

- 练习中答错的题目自动加入错题本
- 记录错误次数、最近错误时间
- 关联练习记录

### 6.2 手动添加

- 用户可手动将任意题目加入错题本
- 添加备注说明错误原因

### 6.3 错题管理

| 功能 | 说明 |
|------|------|
| 查看错题 | 列表展示所有错题，显示错误次数和最近错误时间 |
| 标记已掌握 | 将错题标记为已掌握，不再参与智能推荐 |
| 取消掌握 | 将已掌握的错题重新标记为未掌握 |
| 删除错题 | 从错题本中移除 |
| 批量操作 | 批量删除、批量标记已掌握 |

### 6.4 错题重做

- **顺序重做**：按错误时间顺序逐题重做
- **随机重做**：从错题本中随机抽取题目重做
- **指定数量**：设置重做的题目数量
- 重做结果更新错题状态

### 6.5 错题统计

| 统计项 | 说明 |
|--------|------|
| 错题总数 | 当前错题本中的题目总数 |
| 已掌握数 | 标记为已掌握的题目数 |
| 未掌握数 | 尚未掌握的题目数 |
| 按知识点分布 | 各知识点的错题数量 |
| 按题型分布 | 各题型的错题数量 |
| 错误趋势 | 按时间统计错误率变化 |

## 9. 分类绑定

### 功能说明

用户可绑定感兴趣的考试分类，系统据此推荐相关题目和内容。

| 功能 | 说明 |
|------|------|
| 绑定分类 | 选择感兴趣的考试分类进行绑定 |
| 设置主分类 | 将某个绑定的分类设为主分类 |
| 解绑分类 | 取消绑定的分类 |
| 分类推荐 | 基于绑定分类推荐题目和学习内容 |

### 绑定规则

- 最多绑定 5 个分类
- 必须设置 1 个主分类
- 主分类影响首页默认展示内容
- 绑定后可在「我的」页面查看

## 10. 练习分析

### 学习数据分析

| 分析维度 | 说明 |
|----------|------|
| 学习时长 | 每日/每周/每月的学习时长统计 |
| 练习数量 | 每日/每周/每月的练习题目数量 |
| 正确率趋势 | 正确率随时间的变化趋势 |
| 题型分布 | 各题型的练习数量和正确率 |
| 难度分布 | 各难度的练习数量和正确率 |

### 薄弱知识点分析

| 分析内容 | 说明 |
|----------|------|
| 低正确率知识点 | 正确率低于 60% 的知识点 |
| 高频错题知识点 | 错题数量最多的知识点 |
| 未覆盖知识点 | 尚未练习过的知识点 |
| 知识点掌握度 | 各知识点的掌握程度评分 |

### 分析展示

- 学习日历（打卡记录）
- 知识点雷达图
- 正确率折线图
- 题型正确率柱状图
- 学习建议（基于分析结果的个性化建议）
