# 系统概述

## 1. 系统定位

DevKit 是一款**面向教育考试领域的题库管理与在线学习平台**，旨在为教育机构、培训组织和个人学习者提供统一的题库管理、在线练习和学习分析服务。

系统解决的核心问题：

- 题库分散、格式不统一，难以高效管理
- 缺少多端支持，学员学习场景受限
- 练习数据缺乏沉淀，无法进行智能推荐
- 权限管理粗放，无法满足多角色协作需求

---

## 2. 核心价值

### 统一题库管理

- 支持 **27 种题型**，覆盖选择、填空、判断、简答、编程等主流题型
- 4 级考试分类体系（考试大类 → 具体考试 → 科目 → 章节分类）
- 完整的题目生命周期管理（草稿 → 待审核 → 已发布 → 已归档）
- 批量导入、版本管理、纠错反馈等配套功能

### 多端学习支持

- **Web 管理端**（frontend-admin）：管理员和出题人进行题库管理、用户管理、系统配置
- **移动端**（frontend-app）：学员随时随地进行题目浏览、练习、错题复习

### 智能练习与错题管理

- 基于错题本和薄弱知识点的智能题目推荐
- 自动记录错题，支持标记掌握程度和随机重做
- 学习数据分析，帮助学员发现薄弱环节

### 架构特点

- **前后端分离**：前端通过 RESTful API 与后端通信，WebSocket 用于实时消息推送
- **分层架构**：Handler（接收请求）→ Service（业务逻辑）→ Repository（数据访问）→ Model（数据模型）
- **统一响应格式**：所有 API 返回统一的 JSON 响应结构
- **中间件链**：认证、鉴权、限流、日志等通过 Gin 中间件实现

## 4. 用户角色

系统采用基于角色的访问控制（RBAC），定义了以下核心角色：

| 角色 | 说明 | 主要权限 |
|------|------|----------|
| **超级管理员** | 系统最高权限用户 | 所有功能权限，包括系统配置和用户管理 |
| **管理员** | 系统管理人员 | 用户管理、角色管理、系统设置、数据统计 |
| **出题人** | 题目创建和编辑人员 | 创建/编辑/提交题目、管理知识考点 |
| **审核员** | 题目审核人员 | 审核题目（通过/驳回）、管理已发布题目 |
| **普通用户/学员** | 系统终端用户 | 浏览题目、练习、错题管理、收藏、笔记 |

### 角色关系

```
超级管理员
    └── 管理员
            ├── 出题人
            ├── 审核员
            └── 普通用户/学员
```

- 角色支持层级继承，上级角色自动拥有下级角色的权限
- 用户可拥有多个角色，权限取并集
- 支持用户自主申请角色，管理员审批

## 6. 部署架构

系统采用**单体应用**架构，支持 **Docker 容器化部署**。

### 部署方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| **本地开发** | 直接运行 Go 二进制 + 前端 dev server | 开发调试 |
| **Docker Compose** | 一键启动 MySQL + Redis + MinIO + 后端 | 本地/测试环境 |
| **生产部署** | Nginx + Docker + 外部数据库 | 生产环境 |

### 目录结构

```
backend-server/
├── cmd/server/main.go      # 程序入口
├── config/                  # 配置文件
├── internal/                # 业务代码
│   ├── handler/             # 请求处理层
│   ├── service/             # 业务逻辑层
│   ├── repository/          # 数据访问层
│   ├── model/               # 数据模型
│   ├── middleware/           # 中间件
│   ├── router/              # 路由定义
│   └── ws/                  # WebSocket
├── pkg/                     # 公共包
├── migrations/              # 数据库迁移
└── docker-compose.yml       # Docker 编排
```

## 7. 系统特点

### RBAC 权限控制

- 基于角色的细粒度权限管理
- 支持用户 → 角色 → 权限码三级授权
- 分组层级继承，简化大规模用户管理
- 菜单和按钮级别的权限控制

### JWT 双令牌认证

- **Access Token**：API 认证令牌，默认 7 天过期
- **Refresh Token**：用于无感刷新 Access Token，默认 30 天过期
- **Token 轮换**：每次刷新时同时更新两个 Token，防止令牌泄露
- **Redis 黑名单**：登出时将 Token 加入黑名单，立即失效

### 多存储后端支持

- **本地存储**：适合单机部署，文件存储在本地磁盘
- **MinIO**：自建对象存储，适合私有云部署
- **阿里云 OSS**：公有云对象存储，适合生产环境
- **腾讯云 COS**：公有云对象存储，备选方案
- 支持运行时热切换存储后端，无需重启服务

### 5 种验证码类型

系统内置多种验证码实现，满足不同安全需求：

1. 数字验证码（numeric）
2. 滑块验证码（slider）
3. 拼图验证码（puzzle）
4. 旋转验证码（rotation）
5. 点选验证码（point）

### OAuth / 微信登录

- 支持 GitHub、Google 等第三方 OAuth 登录
- 支持微信小程序登录
- 支持微信公众号登录
- 支持微信网页扫码登录
- 账号绑定管理，一个用户可绑定多个第三方账号
