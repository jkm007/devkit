## 1. 敏感数据加密

### 1.1 加密算法选型

| 算法 | 用途 | 特性 |
|------|------|------|
| AES-256-GCM | 对称加密（身份证号、OAuth Token） | 认证加密，防篡改，防 Padding Oracle |
| SHA-256 | 哈希（身份证号唯一性查询、Token 黑名单） | 不可逆，抗碰撞 |
| bcrypt | 密码哈希 | 自带盐值，计算密集型，抗彩虹表 |

### 1.2 身份证号加密存储

身份证号采用双重存储策略：

| 存储字段 | 算法 | 用途 | 可逆性 |
|----------|------|------|--------|
| `id_card` | AES-256-GCM | 加密存储，需要时解密使用 | 可逆 |
| `id_card_hash` | SHA-256 | 唯一性查询，无需解密 | 不可逆 |

```go
// 存储时
encrypted, _ := crypto.Encrypt(idCard)
hash := sha256Hex(idCard)

user.IDCard = encrypted
user.IDCardHash = hash

// 查询唯一性时（无需解密）
hash := sha256Hex(inputIDCard)
db.Where("id_card_hash = ?", hash).First(&user)
```

**AES-256-GCM 加密实现**：

```go
// pkg/crypto/aes.go
// 密钥从 config.Crypto.AESKey 内部读取，无需外部传入
func Encrypt(plaintext string) (string, error) {
    key := []byte(config.Get().Crypto.AESKey)
    block, _ := aes.NewCipher(key)
    gcm, _ := cipher.NewGCM(block)

    // 随机 nonce（crypto/rand）
    nonce := make([]byte, gcm.NonceSize())
    io.ReadFull(rand.Reader, nonce)

    // AES-GCM 加密 + 认证标签
    ciphertext := gcm.Seal(nonce, nonce, []byte(plaintext), nil)
    return base64.StdEncoding.EncodeToString(ciphertext), nil
}

func Decrypt(encoded string) (string, error) {
    key := []byte(config.Get().Crypto.AESKey)
    data, _ := base64.StdEncoding.DecodeString(encoded)
    block, _ := aes.NewCipher(key)
    gcm, _ := cipher.NewGCM(block)

    // 提取 nonce
    nonce := data[:gcm.NonceSize()]
    ciphertext := data[gcm.NonceSize():]

    // 解密 + 验证认证标签
    plaintext, err := gcm.Open(nil, nonce, ciphertext, nil)
    return string(plaintext), err
}
```

**AES-GCM 安全特性**：
- 认证加密（AEAD）：同时提供机密性和完整性
- 随机 nonce：每次加密生成唯一 nonce，防止密文重放
- 认证标签：篡改密文会被检测到
- 密钥要求：必须恰好 16/24/32 字节

### 1.3 OAuth AccessToken 加密存储

第三方 OAuth 的 AccessToken 和 RefreshToken 使用 AES-GCM 加密后存储：

```
数据库表: sys_oauth_users
加密字段: access_token, refresh_token
非加密: provider, provider_user_id, expires_at
```

### 1.4 存储配置密钥加密

存储服务（S3/MinIO/OSS/COS）的 Secret Key 使用 AES-GCM 加密存储在 `sys_storage_configs` 表中。

### 1.5 密码哈希

密码使用 bcrypt 单向哈希，**不可逆**：

```
数据库字段: sys_users.password
算法:       bcrypt（cost factor = 10）
格式:       $2a$10$...（60 字符标准格式）
序列化:     json:"-"（永远不会出现在 API 响应中）
```

## 2. 配置安全

### 2.1 启动时密钥校验

服务器启动时强制校验敏感密钥不能为默认值：

```go
// cmd/server/main.go
func validateSecrets() {
    cfg := config.Get()

    secrets := []struct {
        name  string
        value string
    }{
        {"JWT_SECRET", cfg.JWT.Secret},
        {"AES_KEY", cfg.Crypto.AESKey},
        {"CAPTCHA_SECRET", cfg.Captcha.Secret},
    }

    for _, s := range secrets {
        if s.value == "" || s.value == "changeme" {
            log.Fatalf("%s 未设置或为默认值 'changeme'，请通过环境变量设置", s.name)
        }
    }
}
```

### 2.2 环境变量覆盖

系统使用 Viper 的 `AutomaticEnv()` 功能，支持通过环境变量覆盖配置文件中的任何值：

```go
// config/config.go
viper.AutomaticEnv()
viper.SetEnvKeyReplacer(strings.NewReplacer(".", "_"))
```

**必需的环境变量**：

| 环境变量 | 长度要求 | 配置路径 | 说明 |
|----------|----------|----------|------|
| `JWT_SECRET` | >= 64 字节 | `jwt.secret` | JWT 签名密钥 |
| `AES_KEY` | 恰好 32 字节 | `crypto.aes_key` | AES-256 加密密钥 |
| `CAPTCHA_SECRET` | 32 字节 | `captcha.secret` | 验证码加密密钥 |
| `MYSQL_PASSWORD` | - | `database.password` | 数据库密码 |
| `REDIS_PASSWORD` | - | `redis.password` | Redis 密码 |

### 2.3 配置文件中的敏感信息

`config.yaml` 中的敏感字段使用 `changeme` 占位符，**必须**通过环境变量覆盖：

```yaml
jwt:
  secret: "changeme"          # 必须通过 JWT_SECRET 环境变量设置

crypto:
  aes_key: "changeme"         # 必须通过 AES_KEY 环境变量设置

captcha:
  secret: "changeme"          # 必须通过 CAPTCHA_SECRET 环境变量设置

database:
  password: "changeme"        # 必须通过 MYSQL_PASSWORD 环境变量设置

redis:
  password: "changeme"        # 必须通过 REDIS_PASSWORD 环境变量设置
```

## 3. 输入验证

### 3.1 SQL 注入防护

**GORM 参数化查询**：系统使用 GORM ORM，默认对所有查询使用参数化语句，从根本上防止 SQL 注入。

```go
// 安全 - 参数化查询
db.Where("username = ?", username).First(&user)
db.Where("id = ?", id).Delete(&user)

// LIKE 查询转义
// internal/repository/escape.go
func escapeLike(s string) string {
    s = strings.ReplaceAll(s, `\`, `\\`)
    s = strings.ReplaceAll(s, `%`, `\%`)
    s = strings.ReplaceAll(s, `_`, `\_`)
    return s
}

// 使用时
escaped := escapeLike(keyword)
db.Where("name LIKE ?", "%"+escaped+"%").Find(&users)
```

### 3.2 XSS 防护

多层防护机制：

| 层次 | 措施 |
|------|------|
| 输出编码 | 框架自动 HTML 转义 |
| CSP 头 | `Content-Security-Policy: default-src 'self'; script-src 'self'` |
| XSS 过滤器 | `X-XSS-Protection: 1; mode=block` |
| Cookie 属性 | 敏感 Cookie 设置 `HttpOnly`（CSRF Cookie 除外，JS 需要读取） |

### 3.3 路径遍历防护

文件服务中对对象 Key 进行严格校验：

```go
// validateObjectKey
func validateObjectKey(key string) error {
    // 拒绝路径遍历
    if strings.Contains(key, "..") {
        return errors.New("invalid key: contains '..'")
    }
    // 拒绝绝对路径
    if strings.HasPrefix(key, "/") {
        return errors.New("invalid key: absolute path")
    }
    // 校验完整路径在允许范围内
    if !isValidFullPath(key) {
        return errors.New("invalid key: out of allowed scope")
    }
    return nil
}
```

### 3.4 文件名清理

上传文件时清理文件名，移除路径信息和危险字符：

```go
// SanitizeFileName
func SanitizeFileName(name string) string {
    // 移除路径分隔符
    name = filepath.Base(name)
    // 移除空字节
    name = strings.ReplaceAll(name, "\x00", "")
    return name
}
```

使用 `go-playground/validator/v10` 进行请求参数验证：

## 4. 隐私保护

### 4.1 用户隐私设置

系统提供用户级别的隐私可见性控制：

```go
// model/user_privacy.go
type UserPrivacy struct {
    UserID         uint   // 用户 ID
    ProfileVisible int    // 1=所有人可见, 2=仅班级可见, 3=仅自己可见
    RealnameVisible int   // 真实姓名可见性
    EmailVisible    int   // 邮箱可见性
    StatsVisible    int   // 统计数据可见性
    ClassVisible    int   // 班级信息可见性
}
```

### 4.2 日志 IP 脱敏

安全日志中 IP 地址进行脱敏处理：

```go
// captcha_guard.go - maskIP()
func maskIP(ip string) string {
    // IPv4: 192.168.1.100 -> 192.168.1.***
    if strings.Contains(ip, ".") {
        parts := strings.Split(ip, ".")
        if len(parts) == 4 {
            parts[3] = "***"
            return strings.Join(parts, ".")
        }
    }

    // IPv6: 2001:db8::1 -> 2001:db8::****
    if strings.Contains(ip, ":") {
        parts := strings.Split(ip, ":")
        if len(parts) > 1 {
            parts[len(parts)-1] = "****"
            return strings.Join(parts, ":")
        }
    }

    return ip
}
```

**脱敏示例**：

| 原始 IP | 脱敏后 |
|---------|--------|
| `192.168.1.100` | `192.168.1.***` |
| `10.0.0.1` | `10.0.0.***` |
| `2001:0db8:85a3::8a2e:0370:7334` | `2001:0db8:85a3::8a2e:0370:****` |

### 4.3 错误信息脱敏

系统区分用户输入错误和系统内部错误，不向用户暴露内部细节：

```go
// 用户输入错误 - 返回具体提示
if err := bcrypt.CompareHashAndPassword(...); err != nil {
    return nil, errors.New("用户名或密码错误")  // 不提示"密码错误"
}

// 系统内部错误 - 返回通用提示
if err := db.Create(&user).Error; err != nil {
    logger.Error("创建用户失败", zap.Error(err))
    return nil, errors.New("操作失败，请稍后重试")  // 不暴露数据库错误
}
```

### 4.4 密码字段排除

User 模型中密码字段使用 `json:"-"` 标签，确保永远不会出现在 API 响应中：

```go
type User struct {
    ID       uint   `json:"id"`
    Username string `json:"username"`
    Password string `json:"-"`  // 永不序列化
    IDCard   string `json:"-"`  // 永不序列化
    // ...
}
```

## 5. CSRF 防护

### 5.1 Double Submit Cookie 模式

```
客户端                                    服务端
  |                                         |
  |--- GET /page --------------------------->|
  |<-- Set-Cookie: csrf_token=abc123 --------|
  |                                         |
  |--- POST /api/data ---------------------->|
  |    Cookie: csrf_token=abc123            |
  |    Header: X-CSRF-Token: abc123         |
  |                                         |
  |    比较 Cookie == Header                 |
  |    +-- 匹配 --> 放行                     |
  |    +-- 不匹配 --> 拒绝 (403)             |
```

### 5.2 配置参数

| 参数 | 值 | 说明 |
|------|-----|------|
| Cookie 名 | `csrf_token` | - |
| Header 名 | `X-CSRF-Token` | - |
| Token 长度 | 32 字节 = 64 十六进制字符 | `crypto/rand` 生成 |
| SameSite | `Lax` | 阻止跨站 POST 提交 |
| HttpOnly | `false` | 前端 JS 需要读取 |
| MaxAge | 86400（24 小时） | - |

### 5.3 安全方法豁免

安全方法（GET、HEAD、OPTIONS）不验证 CSRF Token，仅设置 Cookie：

```go
// csrf.go
var safeMethods = []string{"GET", "HEAD", "OPTIONS"}

func isSafeMethod(method string) bool {
    for _, m := range safeMethods {
        if method == m {
            return true
        }
    }
    return false
}
```

### 5.4 豁免路径

以下路径不进行 CSRF 验证（有自己的认证机制）：

| 路径 | 原因 |
|------|------|
| `/api/v1/auth/login` | 登录接口，用户尚未认证 |
| `/api/v1/auth/register` | 注册接口 |
| `/api/v1/auth/reset-password` | 密码重置 |
| `/api/v1/auth/send-code` | 发送验证码 |
| `/api/v1/auth/verify-code` | 验证验证码 |
| `/api/v1/auth/send-sms-code` | 发送短信验证码 |
| `/api/v1/auth/refresh` | Token 刷新 |
| `/api/v1/auth/wechat/*` | 微信 OAuth |
| `/api/v1/share/*` | 公开分享 |
| `/api/v1/files/batch-public-url` | 批量公开链接 |

### 5.5 移动端豁免

移动端应用（APP/H5/小程序）通过 Bearer Token 认证，不受 CSRF 攻击（无 Cookie），因此豁免 CSRF 验证。

**豁免条件（必须同时满足）**：

```go
// csrf.go - isAuthorizationTokenMode()
func isAuthorizationTokenMode(c *gin.Context) bool {
    // 条件 1: X-Mobile-Token-Mode 头为 "true"
    if c.GetHeader("X-Mobile-Token-Mode") != "true" {
        return false
    }

    // 条件 2: X-Client-Type 为 h5/app/miniapp
    clientType := c.GetHeader("X-Client-Type")
    validTypes := map[string]bool{"h5": true, "app": true, "miniapp": true}
    if !validTypes[clientType] {
        return false
    }

    // 条件 3: 存在有效的 Bearer Token
    auth := c.GetHeader("Authorization")
    if !strings.HasPrefix(auth, "Bearer ") {
        return false
    }

    return true
}
```

**安全设计**：仅设置 `X-Client-Type` 不足以绕过 CSRF，必须同时提供有效的 Bearer Token。

### 5.6 常量时间比较

CSRF Token 比较使用常量时间算法，防止时序攻击：

```go
// csrf.go - secureCompare()
func secureCompare(a, b string) bool {
    if len(a) != len(b) {
        return false
    }
    var result byte
    for i := 0; i < len(a); i++ {
        result |= a[i] ^ b[i]  // XOR + OR，不短路
    }
    return result == 0
}
```

## 6. 文件上传安全

### 6.1 三层验证机制

```
文件上传
  |
  v
[第 1 层] 扩展名白名单检查
  |
  +-- 不在白名单 --> 拒绝
  |
  +-- 在白名单 --> [第 2 层] 危险扩展名黑名单检查
                      |
                      +-- 在黑名单 --> 拒绝
                      |
                      +-- 不在黑名单 --> [第 3 层] Magic Bytes 交叉验证
                                           |
                                           +-- 不匹配 --> 拒绝
                                           |
                                           +-- 匹配 --> 允许上传
```

### 6.2 扩展名白名单

支持 130+ 种安全的文件扩展名，按类别组织：

| 类别 | 示例扩展名 |
|------|------------|
| 图片 | .jpg, .jpeg, .png, .gif, .webp, .svg, .bmp, .ico, .tiff |
| 视频 | .mp4, .avi, .mov, .wmv, .flv, .webm, .mkv |
| 音频 | .mp3, .wav, .flac, .aac, .ogg, .wma |
| 文档 | .pdf, .doc, .docx, .xls, .xlsx, .ppt, .pptx, .txt, .csv |
| 压缩包 | .zip, .rar, .7z, .tar, .gz, .bz2 |
| 代码 | .js, .ts, .py, .go, .java, .html, .css, .json, .xml, .yaml |
| 字体 | .ttf, .otf, .woff, .woff2, .eot |
| 3D/设计 | .psd, .ai, .sketch, .fig |

### 6.3 危险扩展名黑名单

30+ 种服务端可执行类型的扩展名被禁止上传：

```
.php, .php3, .php4, .php5, .phtml, .pht    -- PHP
.jsp, .jspx, .jsw, .jsv                    -- Java Server Pages
.asp, .aspx, .asa, .asax, .ascx, .ashx     -- ASP.NET

.sh, .bash, .csh, .ksh                     -- Shell 脚本
.vbs, .vbe, .wsf, .wsc                     -- VBScript
.ps1, .psm1, .psd1                         -- PowerShell
.py, .pyc, .pyo                            -- Python（编译后）
.rb                                         -- Ruby
.pl, .pm                                   -- Perl
```

### 6.4 Magic Bytes 交叉验证

使用 `http.DetectContentType` 检测文件头部的 Magic Bytes，与扩展名对应的 MIME 类型交叉验证：

```go
// fileutil/validator.go
func ValidateMagicBytes(data []byte, ext string) bool {
    // 检测实际 MIME 类型
    detected := http.DetectContentType(data)

    // 获取扩展名对应的期望 MIME 类型
    expected := getExpectedMIME(ext)

    // 交叉验证
    return isCompatible(detected, expected)
}
```

**特殊处理**：
- Office Open XML（.docx, .xlsx, .pptx）基于 ZIP 格式，需要额外解析内部结构
- `text/*` 类型兼容性较高，放宽验证

### 6.5 ClamAV 病毒扫描

可选的病毒扫描功能，通过 ClamAV 进行：

```yaml
# config.yaml
clamav:
  enabled: false                    # 默认关闭
  socket: "/var/run/clamav/clamd.ctl"
  timeout: 60                       # 扫描超时（秒）
```

启用后，所有上传文件在保存前经过 ClamAV 扫描，发现病毒时拒绝上传。
