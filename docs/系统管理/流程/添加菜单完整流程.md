# 添加菜单完整流程

## 第一步：后端添加菜单数据

**方式一：菜单管理页面添加**
```
登录系统 → 系统管理 → 菜单管理 → 新增按钮 → 填写表单 → 保存
```

**方式二：数据库直接插入**
```sql
INSERT INTO menu (id, pid, name, path, component, type, status, authCode, meta)
VALUES ('201', '1', 'SystemConfig', '/system/config', '/system/config/list', 'menu', 1, 'System:Config:List', '{"title":"系统配置","icon":"mdi:cog"}');
```

## 菜单数据库字段说明

### 必填字段

```
id          → 菜单唯一ID，如 "201"
name        → 路由名称，如 "SystemConfig"（全局唯一）
path        → URL路径，如 "/system/config"
type        → 菜单类型，见下方说明
meta.title  → 菜单标题，如 "系统配置"
```

---

### 菜单类型（type）说明

```
catalog  → 目录（一级分类，无实际页面）
           不需要 component 字段

menu     → 菜单（普通页面）
           需要 component 字段，如 "/system/config/list"

embedded → 内嵌（iframe 嵌入）
           需要 meta.iframeSrc 字段，如 "https://doc.example.com"

link     → 外链（新窗口打开）
           需要 meta.link 字段，如 "https://github.com"

button   → 按钮（页面内按钮权限）
           不需要 component，需要 authCode
```

---

### 条件必填字段

```
type = menu      → 必填 component: "/xxx/xxx/list"
type = embedded  → 必填 meta.iframeSrc: "https://xxx.com"
type = link      → 必填 meta.link: "https://xxx.com"
type = button    → 必填 authCode: "System:Config:Create"
```

---

### 推荐填写字段

```
pid        → 父级菜单ID（顶级菜单填 "0" 或不填）
meta.icon  → 图标，如 "mdi:cog"
meta.order → 排序（数字越小越靠前）
status     → 状态：1=启用，0=禁用
authCode   → 权限标识，如 "System:Config:List"
```

---

### 可选字段

```
meta.keepAlive       → 缓存页面（切换不重新加载）
meta.affixTab        → 固定在标签栏
meta.hideInMenu      → 隐藏菜单
meta.hideInTab       → 隐藏标签
meta.hideChildrenInMenu → 隐藏子菜单
meta.badge           → 徽章文字，如 "new"
meta.badgeType       → "dot"（点）或 "normal"（文字）
```

## 路径概念说明

### path 与 component 区别

| 字段 | 示例 | 作用 |
|------|------|------|
| `path` | `/system/config` | 浏览器 URL 地址 |
| `component` | `/system/config/list` | Vue 文件路径 |

**转换规则：**
```
component: "/system/config/list"
      ↓ 去掉开头 /
      ↓ 加上 .vue
文件: src/views/system/config/list.vue
```

---

## 前端文件作用

| 文件 | 做什么 |
|------|--------|
| **list.vue** | 渲染表格、绑定 API、处理按钮点击 |
| **data.ts** | 定义表格有哪些列、表单有哪些字段 |
| **form.vue** | 弹窗里的表单，用于新增/编辑 |
