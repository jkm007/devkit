# 用户管理接口文档

## 接口概览

| 接口 | 方法 | 用途 |
|------|------|------|
| `/system/user/list` | GET | 获取用户列表（分页） |
| `/system/user/:id` | GET | 获取用户详情 |
| `/system/user` | POST | 创建用户 |
| `/system/user/:id` | PUT | 更新用户 |
| `/system/user/:id` | DELETE | 删除用户 |
| `/system/user/:id/reset-password` | PUT | 重置用户密码 |

---

## 1. 获取用户列表

### 接口信息

- **路径：** `GET /system/user/list`
- **用途：** 获取用户列表数据，支持分页和筛选
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `page` | number | 否 | 页码，默认 1 |
| `pageSize` | number | 否 | 每页条数，默认 20 |
| `name` | string | 否 | 用户名（模糊搜索） |
| `nickname` | string | 否 | 昵称（模糊搜索） |
| `email` | string | 否 | 邮箱（模糊搜索） |
| `phone` | string | 否 | 手机号（模糊搜索） |
| `status` | string | 否 | 状态：0=禁用, 1=启用 |
| `groupId` | string | 否 | 分组 ID |
| `isReal` | number | 否 | 是否已实名：0=否, 1=是 |
| `registerSource` | string | 否 | 注册来源：web/h5/miniapp/app |
| `startTime` | string | 否 | 创建时间起始 |
| `endTime` | string | 否 | 创建时间结束 |

### 返回格式

```json
{
  "code": 0,
  "data": {
    "items": [
      {
        "id": 1,
        "name": "vben",
        "nickname": "Vben",
        "email": "vben@example.com",
        "phone": "13800138000",
        "avatar": "https://example.com/avatar.jpg",
        "gender": 1,
        "status": 1,
        "groupId": 1,
        "groupName": "技术组",
        "isReal": 1,
        "registerSource": "web",
        "lastLoginAt": "2026-06-04 10:30:00",
        "lastLoginIp": "192.168.1.100",
        "loginFailCount": 0,
        "remark": "超级管理员",
        "createdAt": "2026-01-15 10:30:00"
      }
    ],
    "total": 100
  },
  "error": null,
  "message": "ok"
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | number | 用户 ID |
| `name` | string | 用户名 |
| `nickname` | string | 昵称 |
| `email` | string | 邮箱 |
| `phone` | string | 手机号 |
| `avatar` | string | 头像 URL |
| `gender` | number | 性别：0=未知, 1=男, 2=女 |
| `status` | number | 状态：1=启用, 0=禁用 |
| `groupId` | number | 所属分组 ID |
| `groupName` | string | 所属分组名称 |
| `isReal` | number | 是否已实名：0=否, 1=是 |
| `registerSource` | string | 注册来源 |
| `lastLoginAt` | string | 最后登录时间 |
| `lastLoginIp` | string | 最后登录 IP |
| `loginFailCount` | number | 连续登录失败次数 |
| `remark` | string | 备注 |
| `createdAt` | string | 创建时间 |

## 3. 创建用户

### 接口信息

- **路径：** `POST /system/user`
- **用途：** 创建新用户
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求体

```json
{
  "name": "zhangsan",
  "nickname": "张三",
  "password": "123456",
  "email": "zhangsan@example.com",
  "phone": "13900139000",
  "gender": 1,
  "status": 1,
  "groupId": 1,
  "remark": "普通用户"
}
```

### 请求字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 用户名（登录用，唯一） |
| `nickname` | string | 否 | 昵称 |
| `password` | string | 是 | 密码（前端传输建议加密） |
| `email` | string | 否 | 邮箱 |
| `phone` | string | 否 | 手机号 |
| `avatar` | string | 否 | 头像 URL |
| `gender` | number | 否 | 性别：0=未知, 1=男, 2=女，默认 0 |
| `birthday` | string | 否 | 生日，格式 YYYY-MM-DD |
| `bio` | string | 否 | 个人简介 |
| `status` | number | 是 | 状态：1=启用, 0=禁用 |
| `groupId` | number | 否 | 所属分组 ID |
| `remark` | string | 否 | 备注 |

### 返回格式

```json
{
  "code": 0,
  "data": { "id": 1 },
  "error": null,
  "message": "ok"
}
```

## 4. 更新用户

### 接口信息

- **路径：** `PUT /system/user/:id`
- **用途：** 更新指定用户信息
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求体

所有字段均可部分更新（不含 password，密码修改走专门接口）：

```json
{
  "nickname": "张三丰",
  "email": "zhangsanfeng@example.com",
  "phone": "13900139001",
  "avatar": "https://example.com/new-avatar.jpg",
  "gender": 1,
  "birthday": "1995-06-15",
  "bio": "后端开发工程师",
  "status": 1,
  "groupId": 2,
  "remark": "技术组成员"
}
```

### 返回格式

```json
{
  "code": 0,
  "data": null,
  "error": null,
  "message": "ok"
}
```

```json
  "data": null,

```

## 6. 重置用户密码

### 接口信息

- **路径：** `PUT /system/user/:id/reset-password`
- **用途：** 管理员重置指定用户的密码
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求体

```json
{
  "newPassword": "654321"
}
```

### 请求字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `newPassword` | string | 是 | 新密码 |

### 返回格式

```json
{
  "code": 0,
  "data": null,
  "error": null,
  "message": "ok"
}
```

### 副作用

- 旧密码存入 `sys_password_history` 表
- 更新 `password_changed_at` 字段
- 重置 `login_fail_count` 为 0
- 清除 `lock_until`

---

## 统一响应格式

所有接口统一使用以下响应格式：

```json
{
  "code": 0,       // 0=成功, -1=失败
  "data": {},      // 业务数据
  "error": null,   // 错误信息
  "message": "ok"  // 提示消息
}
```

### 分页响应格式

```json
{
  "code": 0,
  "data": {
    "items": [],   // 数据列表
    "total": 100   // 总条数
  },
  "error": null,
  "message": "ok"
}
```

---

## 错误码说明

| HTTP Status | code | 说明 |
|-------------|------|------|
| 200 | 0 | 成功 |
| 400 | -1 | 请求参数错误 |
| 401 | -1 | 未授权（token 无效或过期） |
| 409 | -1 | 用户名/邮箱/手机号已存在 |

## 前端调用示例

```typescript
import {
  getUserList,
  getUserDetail,
  createUser,
  updateUser,
  deleteUser,
  resetUserPassword,
} from '#/api/system/user';

// 获取用户列表
const userList = await getUserList({ page: 1, pageSize: 20, status: '1' });

// 获取用户详情
const user = await getUserDetail(1);

// 创建用户
await createUser({
  name: 'zhangsan',
  nickname: '张三',
  password: '123456',
  email: 'zhangsan@example.com',
  phone: '13900139000',
  status: 1,
  groupId: 1,
});

// 更新用户
await updateUser(1, { nickname: '张三丰', email: 'new@example.com' });

// 重置密码
await resetUserPassword(1, { newPassword: '654321' });

// 删除用户
await deleteUser(1);
```
