# 菜单管理接口文档

## 接口概览

| 接口 | 方法 | 用途 |
|------|------|------|
| `/menu/all` | GET | 获取用户菜单（侧边栏渲染） |
| `/system/menu/list` | GET | 获取所有菜单列表（CRUD 管理） |
| `/system/menu/name-exists` | GET | 检查菜单名称是否存在 |
| `/system/menu/path-exists` | GET | 检查菜单路径是否存在 |
| `/system/menu` | POST | 创建菜单 |
| `/system/menu/:id` | PUT | 更新菜单 |
| `/system/menu/:id` | DELETE | 删除菜单 |

---

## 1. 获取用户菜单

### 接口信息

- **路径：** `GET /menu/all`
- **用途：** 登录后获取当前用户可访问的菜单树，用于渲染侧边栏导航
- **认证：** 需要 `Authorization: Bearer <token>`

### 返回格式

```json
{
  "code": 0,
  "data": [
    {
      "name": "System",
      "path": "/system",
      "component": "BasicLayout",
      "redirect": "/system/user",
      "meta": {
        "icon": "ion:settings-outline",
        "order": 9997,
        "title": "system.title"
      },
      "children": [
        {
          "name": "SystemUser",
          "path": "/system/user",
          "component": "/system/user/list",
          "meta": {
            "icon": "mdi:user",
            "title": "system.user.title"
          }
        }
      ]
    }
  ],
  "error": null,
  "message": "ok"
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 路由名称，全局唯一 |
| `path` | string | 是 | 路由路径 |
| `component` | string | 是 | 组件路径，一级菜单用 `BasicLayout`，子菜单用页面路径如 `/system/user/list` |
| `redirect` | string | 否 | 重定向路径 |
| `meta.icon` | string | 否 | 菜单图标 |
| `meta.title` | string | 是 | 菜单标题（支持国际化 key） |
| `meta.order` | number | 否 | 排序权重 |
| `meta.hideInMenu` | boolean | 否 | 是否在菜单中隐藏 |
| `meta.keepAlive` | boolean | 否 | 是否缓存页面 |
| `meta.affixTab` | boolean | 否 | 是否固定在标签栏 |
| `children` | array | 否 | 子菜单列表 |

## 2. 获取菜单列表

### 接口信息

- **路径：** `GET /system/menu/list`
- **用途：** 获取所有菜单列表，用于菜单管理页面的 CRUD 操作
- **认证：** 需要 `Authorization: Bearer <token>`

### 返回格式

```json
{
  "code": 0,
  "data": [
    {
      "id": "1",
      "pid": null,
      "name": "Workspace",
      "path": "/workspace",
      "component": "/dashboard/workspace/index",
      "type": "menu",
      "status": 1,
      "icon": "mdi:dashboard",
      "authCode": "",
      "meta": {
        "icon": "carbon:workspace",
        "title": "page.dashboard.workspace",
        "affixTab": true,
        "order": 0
      },
      "children": [
        {
          "id": "101",
          "pid": "1",
          "name": "SubMenu",
          "path": "/workspace/sub",
          "component": "/workspace/sub/index",
          "type": "menu",
          "status": 1,
          "meta": {
            "title": "子菜单"
          }
        }
      ]
    }
  ],
  "error": null,
  "message": "ok"
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 菜单唯一标识 |
| `pid` | string | 否 | 父级菜单 ID，顶级菜单为 null |
| `name` | string | 是 | 路由名称，全局唯一 |
| `path` | string | 是 | 路由路径 |
| `component` | string | 否 | 页面组件路径 |
| `type` | string | 是 | 菜单类型，见下方说明 |
| `status` | number | 是 | 状态：1=启用, 0=禁用 |
| `authCode` | string | 否 | 权限标识，用于按钮级权限控制 |
| `icon` | string | 否 | 菜单图标（旧字段，建议用 meta.icon） |
| `meta` | object | 否 | 菜单元数据 |

### 菜单类型 (type)

| 类型 | 说明 | 使用场景 |
|------|------|---------|
| `catalog` | 目录 | 一级菜单分类，不对应具体页面 |
| `menu` | 菜单 | 普通菜单项，对应具体页面 |
| `embedded` | 内嵌 | 内嵌 iframe 页面 |
| `link` | 外链 | 外部链接，新窗口打开 |
| `button` | 按钮 | 页面内的按钮级权限控制 |

## 3. 检查菜单名称是否存在

### 接口信息

- **路径：** `GET /system/menu/name-exists`
- **用途：** 创建/编辑菜单时校验名称唯一性
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 菜单名称 |
| `id` | string | 否 | 编辑时传入当前菜单 ID，排除自身 |

### 返回格式

```json
{
  "code": 0,
  "data": true,
  "error": null,
  "message": "ok"
}
```

- `data: true` - 名称已存在
- `data: false` - 名称不存在，可使用

## 5. 创建菜单

### 接口信息

- **路径：** `POST /system/menu`
- **用途：** 创建新菜单
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求体

```json
{
  "name": "SystemConfig",
  "path": "/system/config",
  "component": "/system/config/list",
  "type": "menu",
  "status": 1,
  "pid": "2",
  "authCode": "System:Config:List",
  "meta": {
    "icon": "mdi:cog",
    "title": "系统配置",
    "order": 100
  }
}
```

### 请求字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 路由名称，全局唯一 |
| `path` | string | 是 | 路由路径，全局唯一 |
| `component` | string | 条件 | 页面组件路径，type=menu 时必填 |
| `type` | string | 是 | 菜单类型：catalog/menu/embedded/link/button |
| `status` | number | 是 | 状态：1=启用, 0=禁用 |
| `pid` | string | 否 | 父级菜单 ID，顶级菜单不传 |
| `authCode` | string | 否 | 权限标识 |
| `meta.icon` | string | 否 | 菜单图标 |
| `meta.title` | string | 是 | 菜单标题 |
| `meta.order` | number | 否 | 排序权重 |
| `meta.iframeSrc` | string | 条件 | iframe 地址，type=embedded 时必填 |
| `meta.link` | string | 条件 | 外链地址，type=link 时必填 |

### 返回格式

```json
{
  "code": 0,
  "data": null,
  "error": null,
  "message": "ok"
}
```

## 统一响应格式

所有接口统一使用以下响应格式：

```json
{
  "code": 0,       // 0=成功, -1=失败
  "data": {},      // 业务数据
  "error": null,   // 错误信息
  "message": "ok"  // 提示消息
}
```

### 错误响应示例

```json
{
  "code": -1,
  "data": null,
  "error": "菜单名称已存在",
  "message": "菜单名称已存在"
}
```

## 权限控制说明

### 页面级权限

通过 `authCode` 字段控制页面访问权限，用户必须拥有对应的权限码才能访问。

### 按钮级权限

type=button 的菜单项用于页面内按钮级权限控制：

```json
{
  "id": "20101",
  "pid": "201",
  "name": "SystemMenuCreate",
  "type": "button",
  "authCode": "System:Menu:Create",
  "meta": {
    "title": "创建菜单"
  }
}
```

前端通过 `v-access` 指令控制按钮显示：

```vue
<a-button v-access:code="['System:Menu:Create']">创建</a-button>
```

## 前端路由配置参考

前端静态路由配置（routes/modules/system.ts）示例：

```typescript
const routes: RouteRecordRaw[] = [
  {
    meta: {
      icon: 'ion:settings-outline',
      order: 9997,
      title: $t('system.title'),
    },
    name: 'System',
    path: '/system',
    children: [
      {
        path: '/system/user',
        name: 'SystemUser',
        meta: {
          icon: 'mdi:user',
          title: $t('system.user.title'),
        },
        component: () => import('#/views/system/user/list.vue'),
      },
    ],
  },
];
```

后端菜单数据需要与前端路由配置保持一致，确保 `name`、`path`、`component` 字段匹配。
