# 系统设置接口文档

> 对应表：`sys_system_settings`
> 说明：管理系统运行时配置，支持分组读取和更新，敏感字段加密存储。

## 接口概览

| 接口 | 方法 | 用途 | 权限 |
|------|------|------|------|
| `/system/settings/public` | GET | 获取公开配置 | 不需要认证 |
| `/system/settings` | GET | 获取所有配置（按分组） | `system:setting:list` |
| `/system/settings/:group` | GET | 获取指定分组配置 | `system:setting:list` |
| `/system/settings` | PUT | 批量更新配置 | `system:setting:edit` |
| `/system/settings/:group` | PUT | 更新指定分组配置 | `system:setting:edit` |
| `/system/settings/test-email` | POST | 测试邮件发送 | `system:setting:edit` |
| `/system/settings/test-sms` | POST | 测试短信发送 | `system:setting:edit` |

> **路由说明**：`/system/settings/public`、`/system/settings/test-email`、`/system/settings/test-sms` 为固定路径，优先级高于 `:group` 参数路由。后端注册路由时需将固定路径放在参数路由之前。

## 1. 获取公开配置

### 接口信息

- **路径：** `GET /system/settings/public`
- **用途：** 获取前端需要的公开配置（无需登录）
- **认证：** 不需要

### 返回格式

```json
{
  "code": 0,
  "data": {
    "basic": {
      "site_name": "管理系统",
      "site_logo": "https://example.com/logo.png",
      "site_description": "在线题库管理平台",
      "copyright": "© 2026 Example",
      "watermark_enabled": true,
      "watermark_content": "",
      "default_theme": "auto",
      "default_lang": "zh-CN"
    },
    "captcha": {
      "captcha_enabled": true,
      "captcha_type": "slider"
    }
  },
  "error": null,
  "message": "ok"
}
```

### 说明

- 仅返回 `is_public = 1` 的配置项
- 前端在登录页、注册页等场景调用，获取站点名称、主题、语言、验证码开关
- 无需认证，任何人均可访问
- 返回的是 key-value 对象（非数组），方便前端直接取值

### 接口信息

- **路径：** `GET /system/settings/:group`
- **用途：** 获取单个分组的配置
- **认证：** 需要 `Authorization: Bearer <token>`
- **权限：** `system:setting:list`

### 路径参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `group` | string | 分组标识：basic/email/sms/captcha/storage/wechat/security |

### 返回格式

```json
{
  "code": 0,
  "data": [
    {
      "key": "smtp_enabled",
      "value": false,
      "label": "启用邮件服务",
      "type": "boolean",
      "options": null,
      "tip": "开启后可发送验证邮件和通知邮件",
      "sort": 1,
      "isPublic": false,
      "isSensitive": false
    },
    {
      "key": "smtp_password",
      "value": "******",
      "label": "SMTP 密码",
      "type": "string",
      "options": null,
      "tip": "登录邮箱密码或授权码",
      "sort": 5,
      "isPublic": false,
      "isSensitive": true
    }
  ],
  "error": null,
  "message": "ok"

```

```json
// 无效的分组名

  "data": null,

  "message": "Invalid settings group"
}
```

## 4. 批量更新配置

### 接口信息

- **路径：** `PUT /system/settings`
- **用途：** 一次性更新多个分组的配置
- **认证：** 需要 `Authorization: Bearer <token>`
- **权限：** `system:setting:edit`

### 请求体

```json
{
  "settings": {
    "basic": {
      "site_name": "题小助管理系统",
      "site_logo": "https://example.com/logo.png",
      "site_description": "在线题库管理平台",
      "watermark_enabled": true
    },
    "email": {
      "smtp_enabled": true,
      "smtp_host": "smtp.qq.com",
      "smtp_port": 465,
      "smtp_username": "noreply@example.com",
      "smtp_password": "your-auth-code",
      "smtp_from": "noreply@example.com",
      "smtp_from_name": "题小助"
    },
    "captcha": {
      "captcha_enabled": true,
      "captcha_type": "slider"
    }
  }
}
```

### 请求字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `settings` | object | 是 | 按分组组织的配置键值对 |
| `settings.{group}` | object | 否 | 分组内的配置项，只传需要修改的字段 |
| `settings.{group}.{key}` | any | 否 | 配置值，类型与 type 字段对应 |

### 敏感字段提交规则

| 提交值 | 行为 |
|--------|------|
| `"******"` 或不传 | 跳过，不更新该字段 |
| `""` | 清空该字段 |
| `"new-value"` | 更新为新值 |

### 事务与回滚

- 同一请求内的所有更新在**同一个数据库事务**中执行
- 任意一项更新失败，**全部回滚**，不会出现部分更新的情况
- 返回错误时 `data.updated = 0`

### 返回格式

**成功：**

```json
{
  "code": 0,
  "data": {
    "updated": 7,
    "restartRequired": false,
    "restartItems": []
  },
  "error": null,
  "message": "ok"
}
```

**需要重启：**

```json
{
  "code": 0,
  "data": {
    "updated": 3,
    "restartRequired": true,
    "restartItems": ["server"]
  },
  "error": null,
  "message": "ok"
}
```

### 返回字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `updated` | number | 实际更新的配置项数量 |
| `restartRequired` | boolean | 是否需要重启服务 |
| `restartItems` | string[] | 需要重启的模块列表 |

### 副作用

- 更新 `updated_by` 为当前操作用户 ID
- 更新后的配置同步刷新到内存（`config.Get()` 返回的单例）
- 大部分配置修改后**立即生效**，无需重启

## 5. 更新指定分组配置

### 接口信息

- **路径：** `PUT /system/settings/:group`
- **用途：** 更新单个分组的配置
- **认证：** 需要 `Authorization: Bearer <token>`
- **权限：** `system:setting:edit`

### 路径参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `group` | string | 分组标识 |

### 请求体

```json
{
  "settings": {
    "smtp_enabled": true,
    "smtp_host": "smtp.qq.com",
    "smtp_port": 465,
    "smtp_username": "noreply@example.com",
    "smtp_password": "your-auth-code",
    "smtp_from": "noreply@example.com"
  }
}
```

### 返回格式

```json
{
  "code": 0,
  "data": {
    "updated": 6,
    "restartRequired": false,
    "restartItems": []
  },
  "error": null,
  "message": "ok"
}
```

### 错误响应

```json
// 无效的分组名
{
  "code": -1,
  "data": null,
  "error": "Invalid settings group: xxx",
  "message": "Invalid settings group"
}

// 分组内存在无效的 key
{
  "code": -1,
  "data": null,
  "error": "Invalid settings keys in group email: smtp_xxx",
  "message": "Invalid settings keys"
}
```

## 6. 测试邮件发送

### 接口信息

- **路径：** `POST /system/settings/test-email`
- **用途：** 测试当前邮件配置是否正确，发送一封测试邮件
- **认证：** 需要 `Authorization: Bearer <token>`
- **权限：** `system:setting:edit`

### 请求体

```json
{
  "to": "test@example.com"
}
```

### 请求字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `to` | string | 是 | 收件人邮箱 |

### 返回格式

```json
{
  "code": 0,
  "data": { "sent": true },
  "error": null,
  "message": "ok"
}
```

### 错误响应

```json
// 邮件服务未启用
{
  "code": -1,
  "data": null,
  "error": "Email service is not enabled.",
  "message": "Email service is not enabled."
}

// SMTP 配置不完整
{
  "code": -1,
  "data": null,
  "error": "SMTP configuration is incomplete, please check host/port/username/password.",
  "message": "SMTP configuration is incomplete"
}

// 发送失败
{
  "code": -1,
  "data": null,
  "error": "Failed to send email: authentication failed",
  "message": "Failed to send email"
}
```

## 配置分组一览

| 分组 | 配置项数 | 配置项 |
|------|---------|--------|
| **basic** | 8 | site_name, site_logo, site_description, copyright, watermark_enabled, watermark_content, default_theme, default_lang |
| **email** | 7 | smtp_enabled, smtp_host, smtp_port, smtp_username, smtp_password🔒, smtp_from, smtp_from_name |
| **sms** | 6 | sms_enabled, sms_driver, sms_access_key, sms_secret_key🔒, sms_sign_name, sms_template_code |
| **captcha** | 5 | captcha_enabled, captcha_type, captcha_expire, captcha_max_fail, captcha_login_trigger |
| **storage** | 16 | storage_driver, storage_max_size, storage_allowed_ext, minio_*(5), oss_*(5), cos_*(4) |
| **wechat** | 7 | wechat_miniapp_enabled/appid/secret🔒, wechat_official_enabled/appid/secret🔒, wechat_oauth_enabled |
| **security** | 7 | login_fail_lock, login_fail_max, login_lock_duration, password_min_length, password_history_count, session_timeout, allow_multi_device |
| **合计** | **56** | 🔒 = 敏感字段（返回脱敏） |

## 前端调用示例

```typescript
import {
  getPublicSettings,
  getAllSettings,
  getSettingsByGroup,
  updateSettings,
  updateSettingsByGroup,
  testEmail,
  testSms,
} from '#/api/system/settings';

// 登录页获取公开配置（无需登录）
const publicConfig = await getPublicSettings();
document.title = publicConfig.basic.site_name;
applyTheme(publicConfig.basic.default_theme);

// 系统设置页面获取所有配置
const allSettings = await getAllSettings();

// 获取邮箱配置
const emailSettings = await getSettingsByGroup('email');

// 批量更新
const result = await updateSettings({
  settings: {
    basic: { site_name: '新名称', watermark_enabled: true },
    captcha: { captcha_type: 'puzzle' },
  },
});
if (result.restartRequired) {
  message.warning(`以下模块需要重启: ${result.restartItems.join(', ')}`);
}

// 更新单个分组
await updateSettingsByGroup('email', {
  settings: {
    smtp_enabled: true,
    smtp_host: 'smtp.qq.com',
    smtp_port: 465,
    smtp_password: 'auth-code',
  },
});

// 测试邮件
await testEmail({ to: 'test@example.com' });

// 测试短信
await testSms({ phone: '13800138000' });
```
