# 系统管理模块

## 模块概述

系统管理模块负责用户、角色、菜单、分组等基础数据的管理，以及系统配置的运行时管理，是后台管理系统的核心模块。

---

## 接口列表

| 接口文档 | 说明 |
|---------|------|
| [菜单管理](接口/菜单管理.md) | 菜单 CRUD、侧边栏渲染、权限标识管理 |
| [用户管理](接口/用户管理.md) | 用户 CRUD、分页查询、状态管理 |
| [角色管理](接口/角色管理.md) | 角色 CRUD、权限菜单分配 |
| [分组管理](接口/分组管理.md) | 分组树形结构 CRUD |
| [系统设置](接口/系统设置.md) | 系统配置管理（邮箱/短信/验证码/存储/微信/安全策略） |

## 统一响应格式

所有接口统一使用以下响应格式：

```json
{
  "code": 0,       // 0=成功, -1=失败
  "data": {},      // 业务数据
  "error": null,   // 错误信息
  "message": "ok"  // 提示消息
}
```

### 分页响应格式

列表接口使用分页响应格式：

```json
{
  "code": 0,
  "data": {
    "items": [],   // 数据列表
    "total": 100   // 总条数
  },
  "error": null,
  "message": "ok"
}
```

## 认证说明

所有接口均需要在请求头中携带 Token：

```
Authorization: Bearer <token>
```

Token 通过 [登录认证接口](../_common/接口/登录认证.md) 获取。
