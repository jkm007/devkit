## 新增模块指南

新增业务模块时，按以下结构创建：

```
docs/新模块名/
├── README.md        ← 模块概览、接口列表
├── 接口/
│   ├── xxx.md
│   └── yyy.md
└── 流程/
    └── xxx流程.md
```

然后在本文件的「快速导航」中添加链接。
