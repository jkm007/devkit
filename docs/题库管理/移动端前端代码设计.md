### 2.2 API 层设计

#### 2.2.1 RequestClient（请求客户端）

**核心职责**：
- 统一请求入口（GET/POST/PUT/DELETE）
- 自动注入 JWT Token（Bearer 认证）
- 自动注入设备信息（X-Client-Type / X-Device-ID）
- 401 自动刷新 Token + 重试
- 网络错误自动入队离线队列

**401 刷新流程**：
```
请求 → 401 → TokenManager.refreshToken()
  → 成功：用新 Token 重试原请求 → 返回数据
  → 失败：清除 Token → reLaunch 到登录页
```

**并发安全**：多个请求同时 401 时，`TokenManager` 确保只刷新一次：
```typescript
if (this.refreshing && this.refreshPromise) {
  return this.refreshPromise; // 共享同一个 Promise
}
```

#### 2.2.2 TokenManager（单例模式）

| 方法 | 说明 |
|------|------|
| `getInstance()` | 获取全局唯一实例 |
| `getAccessToken()` | 从 storage 读取 Access Token |
| `getRefreshToken()` | 从 storage 读取 Refresh Token |
| `setTokens(access, refresh)` | 保存 Token 并通知订阅者 |
| `clearTokens()` | 清除 Token 并跳转登录 |
| `refreshToken()` | 调用 `/auth/refresh` 刷新 Token |
| `onTokenChange(callback)` | 订阅 Token 变化 |

#### 2.2.3 接口清单

| 模块 | 接口 | 方法 | 说明 |

### 2.4 工具层设计

#### 2.4.1 API 缓存（cache.ts）

**双缓存架构**：
```
读取：内存缓存 → 本地持久化 → 无缓存
写入：内存缓存 + (可选) 本地持久化
```

| 函数 | 说明 |
|------|------|
| `getCache(key)` | 读取缓存，自动检查 TTL 过期 |
| `setCache(key, data, ttl, persist)` | 写入缓存，可选持久化 |
| `deleteCache(key)` | 删除缓存（内存+本地） |
| `clearExpiredCache()` | 清理所有过期缓存 |
| `cachedRequest(key, fetcher, ttl)` | 带缓存的请求包装器 |

#### 2.4.2 离线策略（offline.ts）

**两种策略**：
- **Cache First**：先返回缓存 → 同时发起真实请求 → 更新缓存（适用于题库列表）
- **Network First**：先发起真实请求 → 失败时返回缓存（适用于个人中心）

**离线队列**：
```
网络断开 → POST/PUT/DELETE 请求入队 → 存储到 storage
网络恢复 → flushQueue() → 重放队列 → 最多重试 3 次
```

#### 2.4.3 平台适配（platform.ts）

提供跨平台统一接口，内部使用 `#ifdef` 条件编译：

| 函数 | H5 | 微信小程序 | App |
|------|----|-----------|-----|
| `copyToClipboard()` | navigator.clipboard | uni.setClipboardData | uni.setClipboardData |
| `share()` | navigator.share | 提示右上角分享 | uni.share |
| `saveImageToAlbum()` | 提示长按保存 | uni.saveImageToPhotosAlbum | uni.saveImageToPhotosAlbum |
| `getStatusBarHeight()` | 0 | systemInfo.statusBarHeight | systemInfo.statusBarHeight |

## 三、数据流

### 3.1 完整请求链路

```
用户操作
  → Vue 组件触发事件
    → 调用 API 函数 (auth.ts / file.ts)
      → RequestClient.request()
        → 构建 URL + 注入 Token + 注入设备信息
        → uni.request()
          → 后端响应
            → code === 0 → resolve(data)
            → code === 401 → TokenManager.refreshToken() → 重试
            → 其他错误 → reject(error)
          → 失败 → 网络错误入队离线队列
    → 组件拿到数据 → Vue 响应式更新 UI
    → (可选) setCache() 缓存数据
```

### 3.2 登录流程

```
输入账号密码 → loginWithPassword()
  → 获取验证码 (如果需要)
  → POST /auth/login
    → 成功：保存 access_token + refresh_token → 设置 userInfo → 跳转首页
    → 失败：显示错误信息
```

### 3.3 Token 刷新流程

```
请求 A → 401 ─┐
请求 B → 401 ─┼→ TokenManager.refreshToken() (只执行一次)
请求 C → 401 ─┘
  → 成功：POST /auth/refresh → 新 Token → A/B/C 用新 Token 重试
  → 失败：清除 Token → reLaunch('/pages/login/index')
```

### 3.4 练习数据流

```
练习配置页 → 选择模式/数量/难度/题型 → navigateTo session
  → session 页 onMounted → 初始化题目列表（当前为 Mock）
  → 用户选择答案 → selectAnswer() → uni.setStorageSync('practice_answers')
  → 定时器每秒更新 elapsed
  → 点击提交 → clearInterval → navigateTo result
  → result 页 onMounted → 读取 URL 参数解析结果 → 清除本地缓存
```

## 五、设计模式

| 模式 | 应用位置 | 说明 |
|------|----------|------|
| **单例模式** | `TokenManager` | 全局唯一实例，`getInstance()` 获取 |
| **观察者模式** | `TokenManager.subscribers` | Token 变化时通知所有订阅者 |
| **策略模式** | `offline.ts` | `cacheFirst` / `networkFirst` 两种缓存策略 |
| **工厂模式** | `platform.ts` | `getPlatform()` 根据环境返回平台标识 |
| **拦截器模式** | `routeInterceptor.ts` | 重写 `uni.navigateTo` 等方法，跳转前检查登录 |
| **队列模式** | `offline.ts` | 离线请求入队，网络恢复后批量重放 |
| **包装器模式** | `cachedRequest()` | 包装原始请求函数，自动缓存结果 |

## 六、安全设计

### 6.1 认证安全
- JWT Access Token（7 天有效期）
- JWT Refresh Token（30 天有效期）
- 401 自动刷新，失败强制登出
- Token 存储在 `uni.setStorageSync`（本地加密存储）

### 6.2 请求安全
- 所有请求自动携带 Bearer Token
- 设备信息注入（X-Client-Type / X-Device-ID）
- 敏感操作需要验证码

### 6.3 数据安全
- API 响应统一校验 `code === 0`
- 错误信息不暴露敏感数据
- 离线队列限制最大重试 3 次

## 七、性能设计

### 7.1 缓存策略
- **内存缓存**：快速读取，页面切换不丢失
- **本地持久化**：应用重启后仍可用
- **TTL 过期**：避免缓存无限增长

### 7.2 懒加载
- 图片使用 `lazy-load` 属性
- LazyImage 组件支持骨架占位

### 7.3 骨架屏
- 数据加载时显示骨架而非 loading 文字
- 7 种预设类型覆盖常见场景

### 7.4 离线支持
- 网络断开时返回缓存数据
- POST/PUT/DELETE 请求入队，网络恢复后重放
