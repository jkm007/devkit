本目录文档以当前 DevKit 系统已有能力为基础设计，重点说明：

- 题型设计：面向所有考试练习场景，覆盖单选、多选、不定项、判断、填空、完形填空、简答、论述、作文、材料题、案例分析、阅读理解、匹配题、排序题、分类题、听力题、口语题、视频题、文档材料题、计算题、证明题、操作题、编程题、SQL 题、代码阅读题、调试改错题等。
- 富媒体内容：题干、题目内容、选项、答案解析、材料都支持文字中间插入图片、音频、视频、公式、代码、表格、文档引用。
- 多形态解析：解析不只是文字，可以同时包含文字解析、步骤解析、视频讲解、音频讲解、图片解析、文档讲义、考点解析、错因解析、方法解析和关联题解析。
- 分类体系：按考试大类、具体考试、科目/模块、章节分类、知识点/考点、标签、来源分层管理，支持面向不同考试场景组织题库。
- 文件管理复用：导入源文件和题目附件统一进入文件管理，题库只保存 `fileId` 关联。
- 发布解析：题目发布后生成版本快照，用户端命中可见范围且满足答案/解析可见策略后才能查看解析。
- 分组可见：当前“班级”能力先使用系统分组 `sys_groups` 承载。
- 命名规范：题库业务表统一使用 `qb_` 前缀，接口统一使用 `/api/v1` 前缀。
- 菜单规划：题库管理第一版直接全部落地 8 个二级菜单：题目管理、题目导入、分类科目、知识考点、审核发布、题目分享、来源标签、题库统计。
- 关键修正：补充题目查重、组合题父子结构、操作日志、编辑态/发布态边界、答案解析可见策略、回收站恢复、来源关系、唯一约束、安全校验。
- v2 补充：越权防护规则、版本表快照字段、管理端/用户端权限隔离、文件删除与附件冲突处理、组合题发布事务、分享码安全、分享审计、实施优先级统一、富媒体 HTML 净化方案、JSON 大小约束、批量操作返回格式、审核人与提交人分离。
- v3 补充：时间字段 DEFAULT 定义、INT UNSIGNED 统一、表级 COMMENT、幂等性设计（重复发布/审核/导入）、分页/错误响应格式统一、导入模板字段补充（难度/策略/附件占位符）、导出题目功能、回收站自动清理、富媒体块 Vue 组件架构、文件上传预览流程、审核对比视图、导入进度 WebSocket 推送、导入超时处理、版本表归档策略、存储空间预估、sys_group_members 前置依赖、通知场景复用。
