## 1. 题目管理

> 核心模块，题目 CRUD、富媒体内容、版本快照、发布流程。

### 1.1 题目 CRUD
- **状态**: ✅ 已设计
- **接口**: `GET/POST/PUT/DELETE /api/v1/questions`
- **数据表**: `qb_questions`
- **详情**: [题库管理系统设计.md — 题目表](题库管理系统设计.md)

### 1.2 富媒体题干与解析
- **状态**: ✅ 已设计
- **内容块类型**: text / image / video / audio / document / formula / table / code / quote / divider
- **解析类型**: 文字解析、步骤解析、视频讲解、音频讲解、图片解析、文档讲义、考点解析、错因解析、方法解析、关联题解析
- **详情**: [题库管理系统设计.md — 富媒体内容](题库管理系统设计.md) | [设计修正v3.md — 富媒体块组件](设计修正v3.md)

### 1.3 版本快照
- **状态**: ✅ 已设计
- **接口**: `POST /api/v1/questions/:id/publish`
- **数据表**: `qb_question_versions`（含 14 个快照字段）
- **策略**: 保留最近 5 个版本 + 当前活跃版本，历史归档
- **详情**: [题库管理系统设计.md — 版本表](题库管理系统设计.md) | [设计修正v2.md — 版本表快照字段](设计修正v2.md)

### 1.4 发布与下架
- **状态**: ✅ 已设计
- **接口**: `POST /api/v1/questions/:id/publish`、`POST /api/v1/questions/:id/archive`
- **状态流转**: `draft → pending → published → archived`
- **幂等性**: SELECT FOR UPDATE 防重复发布
- **详情**: [设计修正v3.md — 幂等性设计](设计修正v3.md)

### 1.5 复制题目
- **状态**: ✅ 已设计
- **接口**: `POST /api/v1/questions/:id/copy`
- **详情**: [题库管理系统设计.md — 接口列表](题库管理系统设计.md)

### 1.6 草稿自动保存
- **状态**: ✅ 已设计
- **机制**: 每 30 秒自动保存，手动保存覆盖
- **详情**: [设计修正v2.md — 草稿自动保存](设计修正v2.md)

### 1.7 题目查重 🔶
- **状态**: 🔶 预留
- **接口**: `POST /api/v1/questions/check-duplicate`、`GET /api/v1/questions/:id/duplicates`
- **数据表**: `qb_question_duplicates`
- **指纹**: `stem_hash`、`content_hash`、`answer_hash`
- **详情**: [设计补充与修正.md — 题目查重](设计补充与修正.md)

### 1.8 回收站 🔶
- **状态**: 🔶 预留
- **接口**: `GET /api/v1/questions/recycle/list`、`POST /api/v1/questions/recycle/:id/restore`、`DELETE /api/v1/questions/recycle/:id`
- **数据表**: `qb_questions`（软删除字段 `deleted_at`、`recycle_expire_at`）
- **策略**: 30 天过期自动清理 + 定时任务
- **详情**: [设计修正v3.md — 回收站清理](设计修正v3.md)

### 1.9 组合题（父子结构）
- **状态**: ✅ 已设计
- **字段**: `parent_id`、`is_group`、`sub_index`
- **发布**: 数据库事务保证父子版本一致性
- **详情**: [设计补充与修正.md — 组合题](设计补充与修正.md) | [设计修正v2.md — 组合题事务](设计修正v2.md)

### 1.10 答案/解析可见策略

- **策略**: `always` / `after_answer` / `after_exam_end` / `never`
- **详情**: [题库管理系统设计.md — 可见策略](题库管理系统设计.md)

## 2. 题目导入

> 从 Excel/Word/PDF/附件包导入题目，支持解析、错误报告、确认入库。

### 2.1 Excel 导入
- **状态**: ✅ 已设计
- **接口**: `POST /api/v1/questions/import/tasks` → `parse` → `confirm`
- **数据表**: `qb_question_import_tasks`、`qb_question_import_items`
- **详情**: [菜单详细设计/02-题目导入.md](菜单详细设计/02-题目导入.md)

### 2.2 Word/PDF 导入 ⬜
- **状态**: ⬜ 预留
- **说明**: 解析 Word/PDF 中的题目，抽取图片和材料
- **依赖**: 文档解析服务

### 2.3 附件包导入 ⬜
- **状态**: ⬜ 预留
- **说明**: 上传 ZIP 附件包，自动匹配题目中的图片/音频/视频

### 2.4 导入任务管理
- **状态**: ✅ 已设计
- **状态机**: `uploaded → parsing → parsed → confirmed → published`
- **进度推送**: WebSocket Hub 推送 `import_progress` 消息
- **详情**: [菜单详细设计/02-题目导入.md](菜单详细设计/02-题目导入.md) | [设计修正v3.md — 导入进度推送](设计修正v3.md)

### 2.5 错误报告
- **状态**: ✅ 已设计
- **接口**: `GET /api/v1/questions/import/tasks/:id/error-report`
- **错误码**: `parse_error` / `format_error` / `missing_field` / `duplicate`
- **详情**: [菜单详细设计/02-题目导入.md](菜单详细设计/02-题目导入.md) | [设计修正v2.md — 导入错误码](设计修正v2.md)

### 2.6 导入取消/重试
- **状态**: ✅ 已设计
- **接口**: `POST /api/v1/questions/import/tasks/:id/cancel`、`retry`
- **超时处理**: 30 分钟超时 + 定时任务标记
- **详情**: [菜单详细设计/02-题目导入.md](菜单详细设计/02-题目导入.md) | [设计修正v3.md — 导入超时处理](设计修正v3.md)

### 2.7 导入模板
- **状态**: ✅ 已设计
- **字段**: 题号、题型、题干、选项、答案、解析、考试、科目、分类、知识点、标签、难度、答案解析可见策略、来源
- **附件占位符**: `[stem:xxx]` / `[content:xxx]` / `[analysis:xxx]` / `[material:xxx]`
- **详情**: [设计修正v3.md — 导入模板字段](设计修正v3.md)
