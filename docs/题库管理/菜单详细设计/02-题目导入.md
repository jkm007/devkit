# 02-题目导入

## 1. 菜单定位

题目导入用于把 Excel、Word、PDF、附件包等源文件导入为题目草稿，并保留导入源文件、解析明细、错误报告和批量发布能力。

- 菜单名称：题目导入
- 路由：`/question/import`
- 组件建议：`/question/import/index`
- 菜单权限：`question:import`
- 关联主表：`qb_question_import_tasks`、`qb_question_import_items`
- 关联已有模块：文件管理、媒体元数据、分组管理、题目管理。

## 2. 页面功能

### 2.1 导入任务列表

| 字段 | 说明 |
|---|---|
| 任务ID | `qb_question_import_tasks.id` |
| 源文件 | `file_id` 关联 `sys_file_entries` |
| 文件类型 | Excel、Word、PDF、ZIP |
| 状态 | uploaded/parsing/parsed/partial_failed/failed/confirmed/published/cancelled |
| 总题数 | `total_count` |
| 成功数 | `success_count` |
| 失败数 | `failed_count` |
| 目标考试/科目/分类 | 导入时选择 |
| 创建人 | `sys_users` |
| 创建时间 | `created_at` |

### 2.2 导入流程

```text
选择/上传源文件
  ↓
文件进入 sys_file_entries
  ↓
创建 qb_question_import_tasks
  ↓
解析文件，抽取图片/音频/视频/文档到文件管理
  ↓
生成 qb_question_import_items
  ↓
预览解析结果和错误报告
  ↓
确认入库，生成 qb_questions 草稿
  ↓
批量发布或提交审核
```

### 2.3 导入源文件保存规则

| 文件 | 保存位置 | 说明 |
|---|---|---|
| Excel 模板 | 文件管理 `/题库/导入文件/Excel/` | 原文件保留 |
| Word 文档 | 文件管理 `/题库/导入文件/Word/` | 可抽取图片和材料 |
| PDF 文档 | 文件管理 `/题库/导入文件/PDF/` | 可作为文档材料题来源 |
| 附件包 | 文件管理 `/题库/导入文件/附件包/` | 解压后的文件也进入文件管理 |
| 解析失败报告 | 文件管理 `/题库/导出文件/` | 可导出 Excel 错误报告 |

## 3. 关联已有系统功能

| 当前系统功能 | 关联方式 |
|---|---|
| 文件上传 | 复用 `/api/v1/files/upload/check/init/part/complete` |
| 文件管理 | 导入源文件、附件包、解析错误报告均写入 `sys_file_entries` |
| 媒体能力 | Word/附件包中抽取的音视频写入 `sys_media_assets` |
| 题目管理 | 确认入库后生成 `qb_questions` 草稿 |
| 分类科目 | 导入任务可预设考试、科目、章节分类 |
| 知识考点 | 导入模板可带知识点列，自动绑定 |
| 来源标签 | 导入任务可生成 `qb_question_sources`，可自动打标签 |

## 4. 接口设计

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| POST | `/api/v1/questions/import/tasks` | `question:import` | 基于 fileId 创建导入任务 |
| GET | `/api/v1/questions/import/tasks` | `question:import` | 导入任务列表 |
| GET | `/api/v1/questions/import/tasks/:id` | `question:import` | 导入任务详情 |
| POST | `/api/v1/questions/import/tasks/:id/parse` | `question:import:parse` | 开始解析 |
| POST | `/api/v1/questions/import/tasks/:id/confirm` | `question:import:confirm` | 确认入库生成题目草稿 |
| POST | `/api/v1/questions/import/tasks/:id/publish` | `question:import:publish` | 导入题目批量发布 |
| POST | `/api/v1/questions/import/tasks/:id/submit-audit` | `question:audit:submit` | 导入题目提交审核 |
| GET | `/api/v1/questions/import/tasks/:id/items` | `question:import` | 解析明细列表 |
| GET | `/api/v1/questions/import/tasks/:id/error-report` | `question:import` | 获取错误报告 |
| POST | `/api/v1/questions/import/templates/download` | `question:import` | 下载导入模板 |
| DELETE | `/api/v1/questions/import/tasks/:id` | `question:import:delete` | 删除导入任务记录 |
| POST | `/api/v1/questions/import/tasks/:id/cancel` | `question:import` | 取消解析中的导入任务 |
| POST | `/api/v1/questions/import/tasks/:id/retry` | `question:import:parse` | 重新解析失败的任务 |

## 5. 按钮权限

| 按钮 | 权限码 | 说明 |
|---|---|---|
| 上传文件 | `file:upload` | 调用文件上传能力 |
| 创建导入任务 | `question:import` | 选择 fileId 后创建任务 |
| 开始解析 | `question:import:parse` | 触发解析 |
| 重新解析 | `question:import:parse` | 修正配置后重新解析 |
| 查看错误 | `question:import` | 查看错误明细 |
| 下载错误报告 | `question:import` | 导出错误报告文件 |
| 确认入库 | `question:import:confirm` | 生成题目草稿 |
| 批量发布 | `question:import:publish` | 入库后直接发布 |
| 提交审核 | `question:audit:submit` | 入库后提交公共审核 |
| 删除任务 | `question:import:delete` | 删除任务记录，不删除源文件 |

## 6. 导入模板建议

| 列 | 说明 |
|---|---|
| 题号 | 同一题多行选项使用相同题号 |
| 题型 | `single_choice` 等题型标识 |
| 题干 | 支持文本和附件占位符 |
| 选项 | A/B/C/D 或 JSON 结构 |
| 答案 | 标准答案 |
| 解析 | 可写文字解析，也可引用附件 |
| 考试 | 对应 `qb_exams` |
| 科目 | 对应 `qb_subjects` |
| 分类 | 对应 `qb_categories` 路径 |
| 知识点 | 多个用分隔符 |
| 标签 | 高频、易错、真题等 |
| 来源 | 年份、地区、试卷名、题号 |
| 附件 | 图片/音频/视频/文档文件名 |

## 7. 首版必须实现

- 上传源文件进入文件管理。
- 创建导入任务。
- Excel 基础解析。
- 错误报告。
- 确认入库。
- 批量发布/提交审核。
- 附件抽取或附件包匹配的基础能力。
