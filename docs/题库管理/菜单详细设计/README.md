## 统一规范

- 接口路径统一使用 `/api/v1` 前缀。
- 题库业务表统一使用 `qb_` 前缀。
- 系统已有表继续使用 `sys_` 前缀，例如 `sys_users`、`sys_groups`、`sys_file_entries`、`sys_tag`。
- 菜单权限码统一使用 `question:*`。
- 文件上传、预览、播放、下载不在题库重复实现，复用文件管理 `/api/v1/files/*`。
- 班级/学习组能力第一版复用系统分组 `sys_groups`。
