# 05-审核发布

## 1. 菜单定位

审核发布是内容管理员的工作台，用于处理公共题库题目的审核、驳回、发布、下架和发布记录追踪。

- 菜单名称：审核发布
- 路由：`/question/audit`
- 组件建议：`/question/audit/index`
- 菜单权限：`question:audit:view`
- 关联表：`qb_questions`、`qb_question_versions`、`qb_question_visibility_scopes`
- 关联已有模块：用户管理、角色权限、安全日志/操作日志。

## 2. 页面功能

### 2.1 审核队列

| 字段 | 说明 |
|---|---|
| 题目ID | `qb_questions.id` |
| 标题/摘要 | 题目标题和题干摘要 |
| 题型 | `question_type` |
| 考试/科目/分类 | 题目归属 |
| 提交人 | `created_by` |
| 提交时间 | 状态变为 `pending` 的时间 |
| 来源 | 真题/模拟/导入/人工录入 |
| 附件数量 | 题干、解析、材料附件数量 |
| 审核状态 | 待审核、已通过、已驳回 |

### 2.2 审核详情

审核详情需要展示：

1. 题干、选项、材料、答案、解析完整内容。
2. 图片、音频、视频、文档附件预览。
3. 题目所属考试、科目、章节、知识点、标签、来源。
4. 提交人和历史修改记录。
5. 审核意见输入框。

### 2.3 审核动作

| 动作 | 结果 |
|---|---|
| 审核通过并发布 | 生成 `qb_question_versions`，写入公共/分组可见范围 |
| 审核通过但不发布 | 状态可回到草稿或保持审核通过待发布，首版建议直接发布 |
| 审核驳回 | 状态变为 `rejected`，写入 `reject_reason` |
| 批量审核通过 | 多题生成发布版本 |
| 批量驳回 | 多题写入统一驳回原因 |
| 下架 | 已发布题变为 `archived` |

## 3. 关联已有系统功能

| 当前系统功能 | 关联方式 |
|---|---|
| 用户管理 | 审核人、提交人来自 `sys_users` |
| 角色权限 | 内容管理员/管理员拥有审核权限 |
| 文件管理 | 审核时预览题目中的图片/音频/视频/文档 |
| 分组管理 | 审核通过时可指定发布到公共或某个分组 |
| 安全日志/操作日志 | 审核、驳回、发布、下架建议记录操作日志 |

## 4. 接口设计

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| GET | `/api/v1/questions/audit/queue` | `question:audit:view` | 待审核列表 |
| GET | `/api/v1/questions/audit/history` | `question:audit:view` | 审核历史 |
| GET | `/api/v1/questions/:id/audit-detail` | `question:audit:view` | 审核详情 |
| POST | `/api/v1/questions/:id/submit-audit` | `question:audit:submit` | 提交审核 |
| POST | `/api/v1/questions/:id/audit/approve` | `question:audit:approve` | 审核通过并发布 |
| POST | `/api/v1/questions/:id/audit/reject` | `question:audit:reject` | 审核驳回 |
| POST | `/api/v1/questions/audit/batch-approve` | `question:audit:approve` | 批量通过 |
| POST | `/api/v1/questions/audit/batch-reject` | `question:audit:reject` | 批量驳回 |
| POST | `/api/v1/questions/:id/archive` | `question:archive` | 下架题目 |
| GET | `/api/v1/questions/:id/versions` | `question:view` | 发布版本列表 |

## 5. 按钮权限

| 按钮 | 权限码 | 说明 |
|---|---|---|
| 查看审核 | `question:audit:view` | 查看队列和详情 |
| 提交审核 | `question:audit:submit` | 创建人提交公共审核 |
| 审核通过 | `question:audit:approve` | 通过并发布 |
| 审核驳回 | `question:audit:reject` | 驳回并填写原因 |
| 批量通过 | `question:audit:approve` | 批量审核通过 |
| 批量驳回 | `question:audit:reject` | 批量驳回 |
| 下架题目 | `question:archive` | 停止使用已发布题 |
| 查看版本 | `question:view` | 查看发布版本 |

## 6. 状态流转

```text
draft → pending → published
              └→ rejected → draft
published → archived
archived → published
```

## 7. 首版必须实现

- 审核队列。
- 审核详情富媒体预览。
- 通过、驳回、批量通过、批量驳回。
- 审核通过生成版本快照。
- 下架和恢复发布。
