# 04-知识考点

## 1. 菜单定位

知识考点用于维护细粒度知识点/考点树，并把题目与多个知识点关联。它解决“这道题考什么”的问题，服务于专项练习、智能推荐、统计分析和错题归因。

- 菜单名称：知识考点
- 路由：`/question/knowledge`
- 组件建议：`/question/knowledge/index`
- 菜单权限：`question:knowledge`
- 关联表：`qb_knowledge_points`、`qb_question_knowledge_points`
- 关联已有模块：题目管理、分类科目、用户管理。

## 2. 页面功能

### 2.1 知识点树

支持按以下维度筛选：

```text
考试 → 科目 → 章节分类 → 知识点树
```

知识点支持树形结构：

```text
软件架构设计
├── 架构风格
│   ├── 分层架构
│   ├── 管道过滤器
│   └── 事件驱动
├── 微服务
│   ├── 服务拆分
│   ├── 服务治理
│   └── 分布式事务
└── DDD
    ├── 实体
    ├── 值对象
    └── 聚合根
```

### 2.2 知识点字段

| 字段 | 说明 |
|---|---|
| 名称 | 知识点/考点名称 |
| 编码 | 可选，用于导入映射 |
| 所属考试 | `exam_id` |
| 所属科目 | `subject_id` |
| 所属章节 | `category_id` |
| 父级知识点 | `parent_id` |
| 重要程度 | 1-5 星 |
| 描述 | 考点说明 |
| 题目数量 | 关联题目数 |
| 正确率 | 后续统计扩展 |

### 2.3 题目绑定

一题可以绑定多个知识点：

```text
题目：JWT Refresh Token 的作用是什么？
知识点：
- JWT
- Access Token
- Refresh Token
- 登录认证
```

## 3. 关联已有系统功能

| 当前系统功能 | 关联方式 |
|---|---|
| 分类科目 | 知识点可归属考试、科目、章节分类 |
| 题目管理 | 题目编辑页可选择多个知识点 |
| 导入任务 | 导入模板知识点列可自动创建或匹配知识点 |
| 统计分析 | 题库统计按知识点统计题量、正确率、错题率 |
| 用户练习 | 用户端后续可按知识点专项练习 |

## 4. 接口设计

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| GET | `/api/v1/question-knowledge/tree` | `question:knowledge` | 获取知识点树 |
| GET | `/api/v1/question-knowledge` | `question:knowledge` | 知识点列表 |
| POST | `/api/v1/question-knowledge` | `question:knowledge:add` | 创建知识点 |
| PUT | `/api/v1/question-knowledge/:id` | `question:knowledge:edit` | 更新知识点 |
| DELETE | `/api/v1/question-knowledge/:id` | `question:knowledge:delete` | 删除知识点 |
| POST | `/api/v1/question-knowledge/:id/move` | `question:knowledge:edit` | 移动知识点 |
| GET | `/api/v1/question-knowledge/:id/statistics` | `question:knowledge` | 知识点统计 |
| GET | `/api/v1/questions/:id/knowledge` | `question:view` | 获取题目知识点 |
| PUT | `/api/v1/questions/:id/knowledge` | `question:knowledge:bind` | 绑定题目知识点 |
| POST | `/api/v1/questions/batch-knowledge` | `question:knowledge:bind` | 批量绑定知识点 |

## 5. 按钮权限

| 按钮 | 权限码 | 说明 |
|---|---|---|
| 新增知识点 | `question:knowledge:add` | 当前节点下新增 |
| 编辑知识点 | `question:knowledge:edit` | 修改名称、重要程度、描述 |
| 删除知识点 | `question:knowledge:delete` | 删除前检查题目引用 |
| 移动知识点 | `question:knowledge:edit` | 调整父级或排序 |
| 批量导入知识点 | `question:knowledge:add` | 从 Excel 导入知识点树 |
| 绑定题目 | `question:knowledge:bind` | 给题目绑定知识点 |
| 批量绑定题目 | `question:knowledge:bind` | 批量给题目绑定知识点 |
| 查看统计 | `question:knowledge` | 查看题量/正确率 |

## 6. 删除保护

- 有子知识点时禁止删除，需先删除或移动子节点。
- 有题目关联时默认禁止删除，可先解除绑定或合并到目标知识点。
- 已用于用户练习统计的知识点不建议物理删除，只软删除。
