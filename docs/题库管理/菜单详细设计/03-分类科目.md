# 03-分类科目

## 1. 菜单定位

分类科目用于维护题库的结构化目录：考试大类、具体考试、科目/模块、章节分类。它解决“题属于哪类考试、哪个科目、哪个章节”的问题。

- 菜单名称：分类科目
- 路由：`/question/category`
- 组件建议：`/question/category/index`
- 菜单权限：`question:category`
- 关联表：`qb_exam_categories`、`qb_exams`、`qb_subjects`、`qb_categories`
- 关联已有模块：分组管理、用户管理、权限管理。

## 2. 页面结构

建议页面分为四栏或 Tab：

```text
考试大类 → 具体考试 → 科目/模块 → 章节分类树
```

### 2.1 考试大类

例如：

```text
公职考试
职业资格考试
学历考试
语言考试
医学考试
财会考试
IT/编程考试
职业技能考试
```

### 2.2 具体考试

例如：

```text
软考
├── 系统架构设计师
├── 软件设计师
└── 网络工程师

语言考试
├── 大学英语四级
├── 大学英语六级
└── 雅思
```

### 2.3 科目/模块

例如系统架构设计师：

```text
综合知识
案例分析
论文
```

### 2.4 章节分类

例如综合知识：

```text
计算机组成与体系结构
├── CPU
├── 存储系统
└── 总线
软件架构设计
├── 架构风格
├── 微服务
└── DDD
```

## 3. 关联已有系统功能

| 当前系统功能 | 关联方式 |
|---|---|
| 分组管理 | 支持某些考试/分类仅给指定 `sys_groups` 维护或使用 |
| 用户管理 | 创建人、维护人来自 `sys_users` |
| 权限管理 | 分类科目维护按钮受 `question:category:*`、`question:exam:manage`、`question:subject:manage` 控制 |
| 题目管理 | `qb_questions.exam_id/subject_id/category_id` 引用分类科目数据 |
| 导入任务 | 导入时预设目标考试、科目、分类 |

## 4. 接口设计

### 4.1 考试大类接口

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| GET | `/api/v1/question-exam-categories/tree` | `question:category` | 获取考试大类树 |
| POST | `/api/v1/question-exam-categories` | `question:exam:manage` | 创建考试大类 |
| PUT | `/api/v1/question-exam-categories/:id` | `question:exam:manage` | 更新考试大类 |
| DELETE | `/api/v1/question-exam-categories/:id` | `question:exam:manage` | 删除考试大类 |
| POST | `/api/v1/question-exam-categories/:id/move` | `question:exam:manage` | 移动排序/父级 |

### 4.2 具体考试接口

| 方法 | 路径 | 权限码 | 说明 |

| PUT | `/api/v1/question-exams/:id` | `question:exam:manage` | 更新考试 |
| DELETE | `/api/v1/question-exams/:id` | `question:exam:manage` | 删除考试 |

### 4.3 科目接口

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| GET | `/api/v1/question-subjects` | `question:category` | 科目列表 |
| POST | `/api/v1/question-subjects` | `question:subject:manage` | 创建科目 |
| PUT | `/api/v1/question-subjects/:id` | `question:subject:manage` | 更新科目 |
| DELETE | `/api/v1/question-subjects/:id` | `question:subject:manage` | 删除科目 |

### 4.4 章节分类接口

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| GET | `/api/v1/question-categories/tree` | `question:category` | 获取章节分类树 |
| POST | `/api/v1/question-categories` | `question:category:add` | 创建章节分类 |

## 5. 按钮权限

| 按钮 | 权限码 | 说明 |
|---|---|---|
| 新增考试大类 | `question:exam:manage` | 创建一级/子级考试大类 |
| 编辑考试大类 | `question:exam:manage` | 修改名称、编码、排序 |
| 删除考试大类 | `question:exam:manage` | 删除前检查是否有关联考试 |
| 新增考试 | `question:exam:manage` | 创建具体考试 |
| 新增科目 | `question:subject:manage` | 创建考试科目/模块 |
| 新增章节分类 | `question:category:add` | 创建章节节点 |
| 编辑章节分类 | `question:category:edit` | 修改分类名称/父级/排序 |
| 删除章节分类 | `question:category:delete` | 删除前检查子分类和题目引用 |
| 合并分类 | `question:category:edit` | 将分类题目迁移到目标分类 |
| 查看统计 | `question:category` | 查看分类下题目数量 |

## 6. 删除保护

| 对象 | 删除条件 |
|---|---|
| 考试大类 | 没有关联具体考试和子大类 |
| 具体考试 | 没有关联科目、题目、来源 |
| 科目 | 没有关联章节、题目、知识点 |
| 章节分类 | 没有子分类、题目、知识点，或先合并迁移 |
