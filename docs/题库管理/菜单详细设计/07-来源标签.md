# 07-来源标签

## 1. 菜单定位

来源标签用于维护题目来源和标签体系，支持真题年份、地区、试卷名称、题号、导入来源、模拟题、自建题、AI生成题等追溯信息。

- 菜单名称：来源标签
- 路由：`/question/source`
- 组件建议：`/question/source/index`
- 菜单权限：`question:source:view`
- 关联表：`qb_question_sources`、`qb_question_tags`、`sys_tag`
- 关联已有模块：标签管理、题目管理、导入任务。

## 2. 页面功能

### 2.1 来源管理

| 字段 | 说明 |
|---|---|
| 来源类型 | real_exam/mock_exam/chapter_practice/daily_practice/manual/import/ai_generated/user_created |
| 来源名称 | 如 2024 年上半年系统架构设计师真题 |
| 所属考试 | `qb_exams.id` |
| 所属科目 | `qb_subjects.id` |
| 年份 | `year` |
| 地区 | `region` |
| 试卷名称 | `paper_name` |
| 原题号 | `question_no` |
| 导入任务 | `import_task_id` |
| 版权说明 | `copyright` |

### 2.2 标签管理

题库标签复用当前系统 `sys_tag`，题目与标签关系写入 `qb_question_tags`。

常见标签：

```text
真题
模拟题
高频
易错
重点
基础
拔高
压轴
收藏
AI生成
人工校验
```

### 2.3 来源与题目的关系

- 题目主表 `qb_questions.source_id` 指向主来源。
- `qb_question_sources.import_task_id` 可追溯导入任务。
- 标签是多对多，写入 `qb_question_tags`。

## 3. 关联已有系统功能

| 当前系统功能 | 关联方式 |
|---|---|
| 系统标签 | 复用 `sys_tag` 的标签定义、颜色、图标 |
| 文件管理 | 来源可关联导入源文件和错误报告文件 |
| 题目导入 | 导入任务可自动创建来源 |
| 题目管理 | 题目列表可按来源和标签筛选 |
| 题库统计 | 按来源和标签统计题量、正确率、错题率 |

## 4. 接口设计

### 4.1 来源接口

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| GET | `/api/v1/question-sources` | `question:source:view` | 来源列表 |
| POST | `/api/v1/question-sources` | `question:source:manage` | 创建来源 |
| GET | `/api/v1/question-sources/:id` | `question:source:view` | 来源详情 |
| PUT | `/api/v1/question-sources/:id` | `question:source:manage` | 更新来源 |
| DELETE | `/api/v1/question-sources/:id` | `question:source:manage` | 删除来源 |
| GET | `/api/v1/question-sources/:id/questions` | `question:view` | 来源下题目 |

### 4.2 标签接口

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| GET | `/api/v1/question-tags` | `question:tag:view` | 题库标签列表 |
| POST | `/api/v1/question-tags` | `question:tag:manage` | 创建题库标签，底层写 `sys_tag` |
| PUT | `/api/v1/question-tags/:id` | `question:tag:manage` | 更新标签 |
| DELETE | `/api/v1/question-tags/:id` | `question:tag:manage` | 删除标签 |
| GET | `/api/v1/questions/:id/tags` | `question:view` | 获取题目标签 |
| PUT | `/api/v1/questions/:id/tags` | `question:tag:bind` | 更新题目标签 |
| POST | `/api/v1/questions/batch-tags` | `question:tag:bind` | 批量打标签 |

## 5. 按钮权限

| 按钮 | 权限码 | 说明 |
|---|---|---|
| 新增来源 | `question:source:manage` | 创建来源 |
| 编辑来源 | `question:source:manage` | 修改来源信息 |
| 删除来源 | `question:source:manage` | 删除前检查题目引用 |
| 查看来源题目 | `question:view` | 跳转题目列表 |
| 新增标签 | `question:tag:manage` | 创建标签 |
| 编辑标签 | `question:tag:manage` | 修改标签名、颜色、图标 |
| 删除标签 | `question:tag:manage` | 删除前检查题目引用 |
| 批量打标签 | `question:tag:bind` | 给题目批量绑定标签 |
