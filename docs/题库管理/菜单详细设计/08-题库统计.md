# 08-题库统计

## 1. 菜单定位

题库统计用于查看题库建设质量和使用情况，包括题量、题型、难度、考试科目、章节分类、知识点覆盖、来源标签、正确率、错题率和使用次数。

- 菜单名称：题库统计
- 路由：`/question/statistics`
- 组件建议：`/question/statistics/index`
- 菜单权限：`question:statistics:view`
- 关联表：`qb_questions`、`qb_question_versions`、`qb_knowledge_points`、`qb_question_sources`
- 关联已有模块：用户、分组、文件、后续练习/考试记录。

## 2. 页面功能

### 2.1 总览卡片

| 指标 | 说明 |
|---|---|
| 总题量 | 全部未删除题目数 |
| 已发布题量 | `status=published` |
| 草稿题量 | `status=draft` |
| 待审核题量 | `status=pending` |
| 今日新增 | 当日新增题目 |
| 附件题量 | 有图片/音频/视频/文档附件的题目数 |
| 解析覆盖率 | 有解析的题目 / 总题量 |
| 知识点绑定率 | 已绑定知识点题目 / 总题量 |

### 2.2 图表统计

| 图表 | 维度 |
|---|---|
| 题型分布 | `question_type` |
| 难度分布 | `difficulty` |
| 状态分布 | `status` |
| 考试题量排行 | `exam_id` |
| 科目题量排行 | `subject_id` |
| 分类题量树 | `category_id` |
| 知识点覆盖 | `qb_question_knowledge_points` |
| 来源分布 | `source_id/source_type` |
| 标签分布 | `qb_question_tags` |
| 附件类型分布 | 图片/音频/视频/文档 |

### 2.3 使用统计

第一版可以先统计题库建设数据。若练习/考试模块已有或后续接入，再增加：

| 指标 | 说明 |
|---|---|
| 练习次数 | 题目被练习次数 |
| 正确率 | 正确次数 / 作答次数 |
| 错题率 | 错误次数 / 作答次数 |
| 收藏数 | 被收藏次数 |
| 分享访问数 | `qb_question_shares.access_count` |
| 热门题目 | 使用次数排行 |
| 高错题目 | 错题率排行 |

## 3. 关联已有系统功能

| 当前系统功能 | 关联方式 |
|---|---|
| 文件管理 | 统计题目附件类型和附件数量 |
| 分组管理 | 按分组可见范围统计分组题库题量 |
| 用户管理 | 按创建人统计题量 |
| 标签管理 | 按 `sys_tag` 统计题目标签 |
| 题目分享 | 统计分享访问次数 |
| 后续练习/考试 | 接入答题记录后统计正确率、错题率 |
