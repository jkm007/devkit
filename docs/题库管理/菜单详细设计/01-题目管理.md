# 01-题目管理

## 1. 菜单定位

题目管理是题库管理的核心二级菜单，用于维护所有题目的编辑态、发布态、附件、解析、可见范围和批量操作。

- 菜单名称：题目管理
- 路由：`/question/list`
- 组件建议：`/question/list/index`
- 菜单权限：`question:view`
- 关联主表：`qb_questions`
- 关联已有模块：文件管理、分组管理、用户管理、角色权限、标签管理。

## 2. 页面功能

### 2.1 列表筛选

| 筛选项 | 字段/来源 | 说明 |
|---|---|---|
| 关键词 | `title`、题干文本 | 搜索题目标题、题干摘要、题号 |
| 题型 | `question_type` | 单选、多选、判断、填空、材料题、编程题等 |
| 状态 | `status` | 草稿、待审核、已发布、已下架、已驳回 |
| 考试 | `exam_id` | 来源 `qb_exams` |
| 科目 | `subject_id` | 来源 `qb_subjects` |
| 章节分类 | `category_id` | 来源 `qb_categories`，支持包含子分类 |
| 知识点 | `knowledge_point_id` | 来源 `qb_knowledge_points` |
| 标签 | `tag_id` | 来源 `sys_tag` + `qb_question_tags` |
| 来源 | `source_id` | 来源 `qb_question_sources` |
| 难度 | `difficulty` | 1简单、2中等、3困难 |
| 创建人 | `created_by` | 来源 `sys_users` |
| 创建时间 | `created_at` | 时间范围 |

### 2.2 列表字段

| 字段 | 说明 |
|---|---|
| 题目ID | `qb_questions.id` |
| 标题/题干摘要 | 展示标题和题干前若干字符 |
| 题型 | `question_type` 转中文 |
| 考试/科目/分类 | 展示完整路径 |
| 知识点 | 多个知识点 Tag 展示 |
| 难度 | 简单/中等/困难 |
| 状态 | 草稿/待审核/已发布/已下架 |
| 发布版本 | `current_version_id` 和版本号 |
| 附件数量 | 来自 `qb_question_attachments` |
| 创建人 | `sys_users` |
| 更新人 | `updated_by`（最后修改人） |
| 更新时间 | `updated_at` |

### 2.3 新增/编辑题目

题目编辑器按题型动态渲染，统一包含以下区域：

1. 基础信息：题型、考试、科目、章节分类、难度、来源、标签、知识点。
2. 题干 `stem`：富媒体内容块，支持文字中间插入图片、视频、音频、公式、代码、表格、文档。
3. 题目内容 `content`：选项、填空、子题、排序项、匹配项等。
4. 答案 `answer`：结构化答案或参考答案。
5. 解析 `analysis`：文字解析、步骤解析、视频讲解、音频讲解、图片解析、文档讲义、考点解析、错因解析。
6. 材料 `materials`：材料题、听力题、视频题、文档题使用。
7. 判分规则 `score_rule`：自动判分、部分得分、人工评分、AI辅助评分、在线判题。

## 3. 关联已有系统功能

| 当前系统功能 | 关联方式 |
|---|---|
| 文件管理 | 题干、选项、解析、材料中的图片/音频/视频/文档先上传到 `sys_file_entries`，题库只保存 `fileId` |
| 媒体能力 | 音频/视频播放、HLS、预览 URL 复用 `/api/v1/files/:id/preview-url`、`/api/v1/files/:id/hls` |
| 分组管理 | 发布或分享时可选择 `sys_groups` 作为可见范围 |
| 用户管理 | 创建人、审核人、指定用户可见范围来自 `sys_users` |
| 角色权限 | 管理按钮和数据范围受 `question:*` 权限控制 |
| 标签管理 | 题目标签复用 `sys_tag`，关系写入 `qb_question_tags` |

## 4. 接口设计

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| GET | `/api/v1/questions` | `question:view` | 题目分页列表 |
| POST | `/api/v1/questions` | `question:create` | 创建题目草稿 |
| GET | `/api/v1/questions/:id` | `question:view` | 题目详情 |
| PUT | `/api/v1/questions/:id` | `question:edit` | 更新题目编辑态 |
| DELETE | `/api/v1/questions/:id` | `question:delete` | 软删除题目 |
| POST | `/api/v1/questions/:id/publish` | `question:publish` | 发布题目，生成版本快照 |
| POST | `/api/v1/questions/:id/archive` | `question:archive` | 下架题目 |
| POST | `/api/v1/questions/:id/copy` | `question:create` | 复制题目为新草稿 |
| POST | `/api/v1/questions/batch-delete` | `question:delete` | 批量软删除 |
| POST | `/api/v1/questions/batch-publish` | `question:publish` | 批量发布 |
| POST | `/api/v1/questions/batch-archive` | `question:archive` | 批量下架 |
| POST | `/api/v1/questions/batch-category` | `question:edit` | 批量修改分类 |
| POST | `/api/v1/questions/:id/attachments` | `question:attachment` | 关联文件附件 |
| GET | `/api/v1/questions/:id/attachments` | `question:view` | 查看附件列表 |
| DELETE | `/api/v1/questions/:id/attachments/:attachmentId` | `question:attachment` | 解除附件关联 |

## 5. 按钮权限

| 按钮 | 权限码 | 说明 |
|---|---|---|
| 新增题目 | `question:create` | 打开题目编辑器 |
| 编辑 | `question:edit` | 编辑草稿或已发布题的编辑态 |
| 复制 | `question:create` | 复制为新题 |
| 删除 | `question:delete` | 软删除 |
| 发布 | `question:publish` | 生成发布版本 |
| 下架 | `question:archive` | 已发布题停止使用 |
| 提交审核 | `question:audit:submit` | 提交公共题库审核 |
| 附件管理 | `question:attachment` | 关联/解除附件 |
| 批量发布 | `question:publish` | 批量生成版本 |
| 批量修改分类 | `question:edit` | 批量调整分类/科目 |

## 6. 数据表关系

```text
qb_questions
├── qb_question_versions
├── qb_question_attachments -> sys_file_entries -> sys_file_assets
├── qb_question_visibility_scopes -> sys_groups/sys_users/sys_roles
├── qb_question_knowledge_points -> qb_knowledge_points
├── qb_question_tags -> sys_tag
└── qb_question_sources
```
