# 06-题目分享

## 1. 菜单定位

题目分享用于管理题目发布后的可见范围和分享记录，包括分享到分组、用户、角色和公开链接。

- 菜单名称：题目分享
- 路由：`/question/share`
- 组件建议：`/question/share/index`
- 菜单权限：`question:share:view`
- 关联表：`qb_question_shares`、`qb_question_visibility_scopes`
- 关联已有模块：分组管理、用户管理、角色管理、文件分享设计。

## 2. 页面功能

### 2.1 分享列表

| 字段 | 说明 |
|---|---|
| 分享ID | `qb_question_shares.id` |
| 题目 | 题目标题和版本 |
| 分享类型 | link/group/user/role |
| 目标对象 | 分组、用户、角色或链接 |
| 有效期 | `expire_at` |
| 最大访问次数 | `max_access` |
| 已访问次数 | `access_count` |
| 状态 | 有效、已过期、已禁用 |
| 创建人 | `created_by` |
| 创建时间 | `created_at` |

### 2.2 分享类型

| 类型 | 说明 | 权限校验 |
|---|---|---|
| 分组分享 | 分享给 `sys_groups` | 用户属于该分组或子分组 |
| 用户分享 | 分享给指定 `sys_users` | 用户ID匹配 |
| 角色分享 | 分享给指定 `sys_roles` | 用户拥有该角色 |
| 链接分享 | 生成分享码 | 校验分享码、有效期、访问次数，可配置是否需要登录 |

### 2.3 可见范围关系

- `qb_question_visibility_scopes` 决定正式练习/考试/解析可见范围。
- `qb_question_shares` 记录分享行为、链接码、有效期和访问统计。
- 分组/用户/角色分享通常同时写入 visibility scope。
- 链接分享不一定写入 visibility scope，可按 share_code 临时访问。

## 3. 关联已有系统功能

| 当前系统功能 | 关联方式 |
|---|---|
| 分组管理 | 分享到班级/学习组使用 `sys_groups` |
| 用户管理 | 指定用户分享使用 `sys_users` |
| 角色管理 | 按角色分享使用 `sys_roles` |
| 文件分享 | 分享有效期、访问次数、禁用启用逻辑参考文件分享 |
| 文件管理 | 分享访问时题目附件仍按文件预览权限生成临时 URL |

## 4. 接口设计

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| GET | `/api/v1/questions/shares` | `question:share:view` | 分享列表 |
| POST | `/api/v1/questions/:id/share` | `question:share:create` | 创建分享 |
| GET | `/api/v1/questions/:id/shares` | `question:share:view` | 某题分享记录 |
| PUT | `/api/v1/questions/shares/:id` | `question:share:edit` | 修改有效期/访问次数 |
| PUT | `/api/v1/questions/shares/:id/disable` | `question:share:disable` | 禁用分享 |
| PUT | `/api/v1/questions/shares/:id/enable` | `question:share:enable` | 启用分享 |
| DELETE | `/api/v1/questions/shares/:id` | `question:share:delete` | 删除分享 |
| GET | `/api/v1/question-share/:code` | 无或登录态 | 通过分享码查看题目 |
| GET | `/api/v1/question-share/:code/analysis` | 无或登录态 | 通过分享码查看解析 |

## 5. 按钮权限

| 按钮 | 权限码 | 说明 |
|---|---|---|
| 创建分享 | `question:share:create` | 给题目创建分享 |
| 分享给分组 | `question:share:create` | 目标为 `sys_groups` |
| 分享给用户 | `question:share:create` | 目标为 `sys_users` |
| 分享给角色 | `question:share:create` | 目标为 `sys_roles` |
| 生成链接 | `question:share:create` | 生成 share_code |
| 修改有效期 | `question:share:edit` | 更新 `expire_at` |
| 禁用分享 | `question:share:disable` | 状态改为禁用 |
| 启用分享 | `question:share:enable` | 状态改为有效 |
| 删除分享 | `question:share:delete` | 删除分享记录 |
| 查看访问统计 | `question:share:view` | 查看访问次数和最后访问时间 |

## 6. 首版必须实现

- 分组分享。
- 用户分享。
- 链接分享。
- 有效期和访问次数。
- 禁用/启用。
- 分享访问题目和解析。
