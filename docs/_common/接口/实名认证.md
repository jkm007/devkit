# 实名认证接口文档

> 对应表：`sys_user_real_names`

## 接口概览

| 接口 | 方法 | 用途 | 认证 |
|------|------|------|------|
| `/user/real-name` | GET | 获取当前用户的实名认证状态 | 需要 |
| `/user/real-name` | POST | 提交实名认证申请 | 需要 |
| `/system/real-name/list` | GET | 获取实名认证申请列表（管理员） | 需要 |
| `/system/real-name/:id/approve` | PUT | 审核通过实名认证（管理员） | 需要 |
| `/system/real-name/:id/reject` | PUT | 审核拒绝实名认证（管理员） | 需要 |

---

## 1. 获取实名认证状态

### 接口信息

- **路径：** `GET /user/real-name`
- **用途：** 获取当前用户的实名认证状态
- **认证：** 需要 `Authorization: Bearer <token>`

### 返回格式

```json
{
  "code": 0,
  "data": {
    "status": 1,
    "realName": "张三",
    "idCard": "110***********1234",
    "rejectReason": null,
    "submittedAt": "2026-05-01 10:00:00",
    "reviewedAt": "2026-05-02 09:00:00"
  },
  "error": null,
  "message": "ok"
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `status` | number | 状态：0=未认证, 1=已认证, 2=待审核, 3=认证失败 |
| `realName` | string | 真实姓名（已认证时返回） |
| `idCard` | string | 身份证号（脱敏，已认证时返回） |
| `rejectReason` | string | 拒绝原因（认证失败时返回） |
| `submittedAt` | string | 提交时间 |
| `reviewedAt` | string | 审核时间 |

---

## 2. 提交实名认证

### 接口信息

- **路径：** `POST /user/real-name`
- **用途：** 提交实名认证申请
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求体

```json
{
  "realName": "张三",
  "idCard": "110101199506151234"
}
```

### 请求字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `realName` | string | 是 | 真实姓名 |
| `idCard` | string | 是 | 身份证号（18 位） |

### 返回格式

```json
{
  "code": 0,
  "data": null,
  "error": null,
  "message": "ok"
}
```

### 副作用

- 身份证号 AES 加密存储到 `id_card` 字段
- 身份证号 SHA256 哈希存储到 `id_card_hash` 字段（用于查重）
- 设置 `status = 0`（待审核）
- 记录 `submitted_at` 时间

### 错误响应

```json
// 已认证
{
  "code": -1,
  "data": null,
  "error": "Real name already verified.",
  "message": "Real name already verified."
}

// 待审核中
{
  "code": -1,
  "data": null,
  "error": "Verification pending review.",
  "message": "Verification pending review."
}

// 身份证号已被使用
{
  "code": -1,
  "data": null,
  "error": "This ID card is already registered.",
  "message": "This ID card is already registered."
}
```

## 3. 获取实名认证申请列表（管理员）

### 接口信息

- **路径：** `GET /system/real-name/list`
- **用途：** 管理员查看实名认证申请列表
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `page` | number | 否 | 页码，默认 1 |
| `pageSize` | number | 否 | 每页条数，默认 20 |
| `status` | number | 否 | 状态：0=待审, 1=已认证, 2=认证失败 |
| `userId` | number | 否 | 用户 ID |
| `realName` | string | 否 | 真实姓名（模糊搜索） |

### 返回格式

```json
{
  "code": 0,
  "data": {
    "items": [
      {
        "id": 1,
        "userId": 5,
        "username": "zhangsan",
        "realName": "张三",
        "idCard": "110***********1234",
        "status": 0,
        "submittedAt": "2026-06-01 10:00:00"
      }
    ],
    "total": 20
  },
  "error": null,
  "message": "ok"
}
```

## 4. 审核通过（管理员）

### 接口信息

- **路径：** `PUT /system/real-name/:id/approve`
- **用途：** 审核通过用户的实名认证
- **认证：** 需要 `Authorization: Bearer <token>`

### 返回格式

```json
{
  "code": 0,
  "data": null,
  "error": null,
  "message": "ok"
}
```

### 副作用

- 更新 `sys_user_real_names` 表：`status = 1`，记录 `reviewed_by` 和 `reviewed_at`
- 更新 `sys_users` 表：`real_name`、`id_card`、`is_real = 1`

---

## 5. 审核拒绝（管理员）

### 接口信息

- **路径：** `PUT /system/real-name/:id/reject`
- **用途：** 拒绝用户的实名认证申请
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求体

```json
{
  "reason": "身份证照片不清晰，请重新上传"
}
```

### 请求字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `reason` | string | 是 | 拒绝原因 |

### 返回格式

```json
{
  "code": 0,
  "data": null,
  "error": null,
  "message": "ok"
}
```

### 副作用

- 更新 `sys_user_real_names` 表：`status = 2`，记录 `reject_reason`、`reviewed_by`、`reviewed_at`

---

## 认证状态流转

```
未认证 ──提交申请──> 待审核 ──审核通过──> 已认证
                      │
                      └──审核拒绝──> 认证失败 ──重新提交──> 待审核
```

---

## 前端调用示例

```typescript
import {
  getRealNameStatus,
  submitRealName,
  getRealNameList,
  approveRealName,
  rejectRealName,
} from '#/api/user';

// 获取认证状态
const status = await getRealNameStatus();

// 提交认证
await submitRealName({ realName: '张三', idCard: '110101199506151234' });

// 管理员：获取申请列表
const list = await getRealNameList({ page: 1, status: 0 });

// 管理员：审核通过
await approveRealName(1);

// 管理员：审核拒绝
await rejectRealName(2, { reason: '照片不清晰' });
```
