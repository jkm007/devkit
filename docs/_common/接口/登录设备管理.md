# 登录设备管理接口文档

> 对应表：`sys_login_devices`

## 接口概览

| 接口 | 方法 | 用途 | 认证 |
|------|------|------|------|
| `/auth/devices` | GET | 获取当前用户的登录设备列表 | 需要 |
| `/auth/devices/:id` | DELETE | 踢出指定设备 | 需要 |
| `/auth/devices` | DELETE | 踢出除当前设备外的所有设备 | 需要 |

---

## 1. 获取登录设备列表

### 接口信息

- **路径：** `GET /auth/devices`
- **用途：** 获取当前用户所有已登录设备，用于"登录设备管理"页面
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求参数

无

### 返回格式

```json
{
  "code": 0,
  "data": [
    {
      "id": 1,
      "deviceId": "web-abc123",
      "deviceType": "web",
      "deviceName": "Chrome 120",
      "browser": "Chrome 120.0.6099",
      "os": "Windows 10",
      "ip": "192.168.1.100",
      "location": "广东省深圳市",
      "lastActiveAt": "2026-06-04 10:30:00",
      "isCurrent": true,
      "createdAt": "2026-06-04 09:00:00"
    },
    {
      "id": 2,
      "deviceId": "ios-def456",
      "deviceType": "ios",
      "deviceName": "iPhone 15",
      "browser": "Safari 17",
      "os": "iOS 17.4",
      "ip": "192.168.1.101",
      "location": "广东省深圳市",
      "lastActiveAt": "2026-06-04 08:00:00",
      "isCurrent": false,
      "createdAt": "2026-06-03 14:00:00"
    }
  ],
  "error": null,
  "message": "ok"
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | number | 设备记录 ID |
| `deviceId` | string | 设备唯一标识 |
| `deviceType` | string | 设备类型：web/ios/android/miniapp |
| `deviceName` | string | 设备名称 |
| `browser` | string | 浏览器信息 |
| `os` | string | 操作系统 |
| `ip` | string | IP 地址 |
| `location` | string | 登录地点 |
| `lastActiveAt` | string | 最后活跃时间 |
| `isCurrent` | boolean | 是否当前设备 |
| `createdAt` | string | 首次登录时间 |

## 2. 踢出指定设备

### 接口信息

- **路径：** `DELETE /auth/devices/:id`
- **用途：** 将指定设备踢下线（使其 Token 失效）
- **认证：** 需要 `Authorization: Bearer <token>`

### 返回格式

```json
{
  "code": 0,
  "data": null,
  "error": null,
  "message": "ok"
}
```

### 说明

- 不能踢出当前设备（请使用登出接口）
- 被踢出的设备下次请求时会收到 401

### 错误响应

```json
// 不能踢出当前设备
{
  "code": -1,
  "data": null,
  "error": "Cannot kick current device, use logout instead.",
  "message": "Cannot kick current device, use logout instead."
}
```

---

## 3. 踢出所有其他设备

### 接口信息

- **路径：** `DELETE /auth/devices`
- **用途：** 踢出除当前设备外的所有设备
- **认证：** 需要 `Authorization: Bearer <token>`

### 返回格式

```json
{
  "code": 0,
  "data": { "kickedCount": 3 },
  "error": null,
  "message": "ok"
}
```

### 返回字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `kickedCount` | number | 被踢出的设备数量 |

---

## 前端调用示例

```typescript
import {
  getLoginDevices,
  kickDevice,
  kickAllOtherDevices,
} from '#/api/auth';

// 获取设备列表
const devices = await getLoginDevices();

// 踢出指定设备
await kickDevice(2);

// 踢出所有其他设备
const result = await kickAllOtherDevices();
console.log(`已踢出 ${result.kickedCount} 台设备`);
```
