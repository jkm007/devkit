# 登录设备管理接口文档

> 对应表：`sys_login_devices`

## 接口概览

| 接口 | 方法 | 用途 | 认证 |
|------|------|------|------|
| `/auth/devices` | GET | 获取当前用户的登录设备列表，支持按设备类型筛选 | 需要 |
| `/auth/devices/:id` | DELETE | 踢出指定设备 | 需要 |
| `/auth/devices/kick-all` | DELETE | 踢出除当前设备外的所有设备 | 需要 |

---

## 1. 获取登录设备列表

### 接口信息

- **路径：** `GET /auth/devices`
- **用途：** 获取当前用户所有已登录设备，用于“登录设备管理”页面
- **认证：** 需要 `Authorization: Bearer <token>`

### Query 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `deviceType` | string | 否 | 设备类型筛选：`web` / `h5` / `app` / `miniapp` |

### 请求示例

```http
GET /api/v1/auth/devices?deviceType=h5
Authorization: Bearer <accessToken>
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | number | 设备记录 ID |
| `deviceId` | string | 设备唯一标识，对应请求头 `X-Device-ID`；未传时后端用 User-Agent + IP 生成 |
| `deviceType` | string | 设备类型：`web` / `h5` / `app` / `miniapp` |
| `deviceName` | string | 设备名称，后端根据 User-Agent 解析 |
| `browser` | string | 浏览器信息 |
| `os` | string | 操作系统 |
| `ip` | string | IP 地址 |
| `location` | string | 登录地点，当前预留 |
| `appVersion` | string | App/H5/小程序版本，对应请求头 `X-App-Version` |
| `systemVersion` | string | 系统版本，对应请求头 `X-System-Version` |
| `deviceModel` | string | 设备型号，对应请求头 `X-Device-Model` |
| `platform` | string | 平台：`web` / `h5` / `ios` / `android` / `miniapp` 等，对应请求头 `X-Platform` |
| `channel` | string | 渠道，对应请求头 `X-Channel` |
| `lastActiveAt` | string | 最后活跃时间 |
| `isCurrent` | number | 是否当前设备：`1` 是，`0` 否 |
| `createdAt` | string | 首次登录时间 |

### 移动端设备信息上报

H5/App/小程序登录时建议携带以下 Header：

```http
X-Client-Type: app
X-Device-ID: device-uuid
X-App-Version: 1.2.3
X-System-Version: iOS 17.5
X-Device-Model: iPhone 15 Pro
X-Platform: ios
X-Channel: appstore
```

后端会做白名单归一化：

- `X-Client-Type` 只允许 `web` / `h5` / `app` / `miniapp`，非法或为空默认 `web`。
- `X-Platform` 只允许 `web` / `h5` / `ios` / `android` / `miniapp` / `windows` / `macos` / `linux`，非法或为空时回退到 `X-Client-Type`。

## 2. 踢出指定设备

### 接口信息

- **路径：** `DELETE /auth/devices/:id`
- **用途：** 将指定设备踢下线（使其 Token 失效）
- **认证：** 需要 `Authorization: Bearer <token>`

### 返回格式

```json
{
  "code": 0,
  "data": null,
  "error": null,
  "message": "ok"
}
```

### 说明

- 不能踢出当前设备（请使用登出接口）。
- 被踢出的设备 ID 会写入 Redis：`kicked_device:{userID}:{deviceID}`。
- 被踢出的设备下次请求时会收到 401。

### 错误响应

```json
{
  "code": -1,
  "data": null,
  "error": "Cannot kick current device, use logout instead.",
  "message": "Cannot kick current device, use logout instead."
}
```

## 3. 踢出所有其他设备

### 接口信息

- **路径：** `DELETE /auth/devices/kick-all`
- **用途：** 踢出除当前设备外的所有设备
- **认证：** 需要 `Authorization: Bearer <token>`

### 返回格式

```json
{
  "code": 0,
  "data": { "kickedCount": 3 },
  "error": null,
  "message": "ok"
}
```

### 返回字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `kickedCount` | number | 被踢出的设备数量 |

---

## 前端调用示例

```typescript
import {
  getLoginDevices,
  kickAllOtherDevices,
  kickDevice,
} from '#/api/account';

// 获取全部设备
const devices = await getLoginDevices();

// 只获取 H5 设备
const h5Devices = await getLoginDevices({ deviceType: 'h5' });

// 踢出指定设备
await kickDevice(2);

// 踢出所有其他设备
const result = await kickAllOtherDevices();
console.log(`已踢出 ${result.kickedCount} 台设备`);
```
