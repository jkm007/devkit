# 登录认证接口文档

## 接口概览

| 接口 | 方法 | 用途 | 认证 |
|------|------|------|------|
| `/auth/login` | POST | 用户登录 | 不需要 |
| `/auth/logout` | POST | 用户登出 | 需要 |
| `/auth/refresh` | POST | 刷新 AccessToken | 不需要（Cookie） |
| `/auth/codes` | GET | 获取权限码 | 需要 |
| `/auth/change-password` | PUT | 修改密码 | 需要 |
| `/user/info` | GET | 获取当前用户信息 | 需要 |
| `/user/info` | PUT | 更新当前用户资料 | 需要 |
| `/user/avatar` | PUT | 更新头像 | 需要 |

---

## 1. 用户登录

### 接口信息

- **路径：** `POST /auth/login`
- **用途：** 用户名密码登录，返回 AccessToken 和用户信息
- **认证：** 不需要

### 请求体

```json
{
  "username": "vben",
  "password": "123456"
}
```

### 请求字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `username` | string | 是 | 用户名 |
| `password` | string | 是 | 密码 |

### 返回格式

**成功（200）：**

```json
{
  "code": 0,
  "data": {
    "id": 1,
    "username": "vben",
    "nickname": "Vben",
    "realName": "Vben",
    "email": "vben@example.com",
    "phone": "13800138000",
    "avatar": "https://example.com/avatar.jpg",
    "gender": 1,
    "roles": ["super"],
    "homePath": null,
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  },
  "error": null,
  "message": "ok"
}
```

**失败 - 参数缺失（400）：**

```json
{
  "code": -1,
  "data": null,
  "error": "Username and password are required",
  "message": "BadRequestException"
}
```

**失败 - 账号密码错误（403）：**

```json
{
  "code": -1,
  "data": null,
  "error": "Username or password is incorrect.",
  "message": "Username or password is incorrect."
}
```

**失败 - 账号被锁定（403）：**

```json
{
  "code": -1,
  "data": null,
  "error": "Account is locked, please try again later.",
  "message": "Account is locked, please try again later."
}
```

**失败 - 账号已禁用（403）：**

```json
{
  "code": -1,
  "data": null,
  "error": "Account is disabled.",
  "message": "Account is disabled."
}
```

### 返回字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | number | 用户 ID |
| `username` | string | 用户名 |
| `nickname` | string | 昵称 |
| `realName` | string | 真实姓名 |
| `email` | string | 邮箱 |
| `phone` | string | 手机号 |
| `avatar` | string | 头像 URL |
| `gender` | number | 性别：0=未知, 1=男, 2=女 |
| `roles` | string[] | 角色列表 |
| `homePath` | string \| null | 首页路径 |
| `accessToken` | string | JWT AccessToken |

### 副作用

- 登录成功后，服务端通过 `Set-Cookie` 写入 `jwt` 字段，存储 RefreshToken（HttpOnly，有效期 30 天）
- 更新 `sys_users` 表的 `last_login_at`、`last_login_ip`、`last_login_device`
- 重置 `login_fail_count` 为 0
- 在 `sys_login_devices` 表记录设备信息
- 在 `sys_security_logs` 表记录登录事件

### 登录失败处理

- 密码错误时 `login_fail_count` +1
- 连续失败 5 次后，账号锁定 30 分钟（设置 `lock_until`）
- 在 `sys_security_logs` 表记录登录失败事件

### 测试账号

| 用户名 | 密码 | 角色 | 首页 |
|--------|------|------|------|
| `vben` | `123456` | super | 默认 |
| `admin` | `123456` | admin | `/workspace` |
| `jack` | `123456` | user | `/analytics` |

## 2. 用户登出

### 接口信息

- **路径：** `POST /auth/logout`
- **用途：** 清除登录状态
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求参数

无

### 返回格式

```json
{
  "code": 0,
  "data": "",
  "error": null,
  "message": "ok"
}
```

### 副作用

- 服务端清除 `jwt` Cookie（RefreshToken）
- 将当前 AccessToken 的 JTI 加入 Redis 黑名单
- 更新 `sys_login_devices` 表中当前设备的状态
- 在 `sys_security_logs` 表记录登出事件

---

## 3. 刷新 AccessToken

### 接口信息

- **路径：** `POST /auth/refresh`
- **用途：** 使用 RefreshToken 获取新的 AccessToken
- **认证：** 通过 Cookie 中的 `jwt` 字段验证

### 请求参数

无（RefreshToken 从 Cookie 自动获取）

### 返回格式

**成功（200）：**

直接返回新的 AccessToken 字符串：

```
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

**失败 - 无 RefreshToken（403）：**

```json
{
  "code": -1,
  "data": null,
  "error": "Forbidden Exception",
  "message": "Forbidden Exception"
}
```

### 说明

- RefreshToken 存储在 HttpOnly Cookie 中，前端无法直接读取
- RefreshToken 有效期 30 天
- 刷新成功后会重新设置 Cookie

## 5. 修改密码

### 接口信息

- **路径：** `PUT /auth/change-password`
- **用途：** 当前用户修改自己的密码
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求体

```json
{
  "oldPassword": "123456",
  "newPassword": "654321",
  "confirmPassword": "654321"
}
```

### 请求字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `oldPassword` | string | 是 | 当前密码 |
| `newPassword` | string | 是 | 新密码 |
| `confirmPassword` | string | 是 | 确认新密码 |

### 返回格式

```json
{
  "code": 0,
  "data": null,
  "error": null,
  "message": "ok"
}
```

### 副作用

- 验证旧密码是否正确
- 检查新密码是否与最近 5 次密码重复（查 `sys_password_history`）
- 旧密码存入 `sys_password_history` 表
- 更新 `password_changed_at` 字段
- 重置 `login_fail_count` 为 0
- 在 `sys_security_logs` 表记录密码修改事件

### 错误响应

```json
// 旧密码错误
{
  "code": -1,
  "data": null,
  "error": "Old password is incorrect.",
  "message": "Old password is incorrect."
}

// 新密码与旧密码相同
{
  "code": -1,
  "data": null,
  "error": "New password cannot be the same as the old password.",
  "message": "New password cannot be the same as the old password."
}

// 新密码与最近5次密码重复
{
  "code": -1,
  "data": null,
  "error": "New password cannot be the same as the last 5 passwords.",
  "message": "New password cannot be the same as the last 5 passwords."
}
```

|------|------|------|

## 统一响应格式

所有接口统一使用以下响应格式：

```json
{
  "code": 0,       // 0=成功, -1=失败
  "data": {},      // 业务数据
  "error": null,   // 错误信息
  "message": "ok"  // 提示消息
}
```

---

## 错误码说明

| HTTP Status | code | 说明 |
|-------------|------|------|
| 200 | 0 | 成功 |
| 400 | -1 | 请求参数错误 |
| 401 | -1 | 未授权（Token 无效或过期） |
| 403 | -1 | 禁止（账号密码错误 / 账号被锁定 / 账号已禁用） |

---

## 认证机制说明

### 双 Token 机制

| Token | 存储位置 | 有效期 | 用途 |
|-------|----------|--------|------|
| AccessToken | 响应体 `data.accessToken` | 7 天 | 请求头 `Authorization: Bearer <token>` |
| RefreshToken | HttpOnly Cookie `jwt` | 30 天 | 自动续期 AccessToken |

### 请求头格式

```
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 前端调用示例

```typescript
import { useAuthStore } from '#/store';

const authStore = useAuthStore();

// 登录
await authStore.authLogin({ username: 'vben', password: '123456' });

// 登出
await authStore.logout();

// 修改密码
await authStore.changePassword({
  oldPassword: '123456',
  newPassword: '654321',
  confirmPassword: '654321',
});

// Token 过期时自动调用刷新接口
// 前端 RequestClient 会自动处理 401 并调用 /auth/refresh
```
