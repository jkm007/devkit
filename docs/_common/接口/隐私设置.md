# 用户隐私设置接口文档

> 对应表：`sys_user_privacy`

## 接口概览

| 接口 | 方法 | 用途 | 认证 |
|------|------|------|------|
| `/user/privacy` | GET | 获取当前用户的隐私设置 | 需要 |
| `/user/privacy` | PUT | 更新当前用户的隐私设置 | 需要 |

---

## 1. 获取隐私设置

### 接口信息

- **路径：** `GET /user/privacy`
- **用途：** 获取当前用户的隐私设置
- **认证：** 需要 `Authorization: Bearer <token>`

### 返回格式

```json
{
  "code": 0,
  "data": {
    "profileVisible": 1,
    "realnameVisible": 2,
    "emailVisible": 1,
    "statsVisible": 1,
    "classVisible": 3
  },
  "error": null,
  "message": "ok"
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `profileVisible` | number | 个人资料可见性 |
| `realnameVisible` | number | 真实姓名可见性 |
| `emailVisible` | number | 邮箱可见性 |
| `statsVisible` | number | 统计数据可见性 |
| `classVisible` | number | 班级信息可见性 |

### 可见性值

| 值 | 说明 |
|----|------|
| 1 | 全部可见 |
| 2 | 仅班级成员可见 |
| 3 | 仅自己可见 |

---

## 2. 更新隐私设置

### 接口信息

- **路径：** `PUT /user/privacy`
- **用途：** 更新当前用户的隐私设置
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求体

```json
{
  "profileVisible": 1,
  "realnameVisible": 3,
  "emailVisible": 3,
  "statsVisible": 2,
  "classVisible": 1
}
```

### 请求字段说明

所有字段均可部分更新：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `profileVisible` | number | 否 | 个人资料可见性：1全部 2仅班级 3仅自己 |
| `realnameVisible` | number | 否 | 真实姓名可见性 |
| `emailVisible` | number | 否 | 邮箱可见性 |
| `statsVisible` | number | 否 | 统计数据可见性 |
| `classVisible` | number | 否 | 班级信息可见性 |

### 返回格式

```json
{
  "code": 0,
  "data": null,
  "error": null,
  "message": "ok"
}
```

### 说明

- 如果用户首次设置，自动创建记录
- 未设置过的用户使用默认值（全部 = 1）

---

## 前端调用示例

```typescript
import { getUserPrivacy, updateUserPrivacy } from '#/api/user';

// 获取隐私设置
const privacy = await getUserPrivacy();

// 更新隐私设置
await updateUserPrivacy({
  realnameVisible: 3,  // 真实姓名仅自己可见
  emailVisible: 3,     // 邮箱仅自己可见
});
```
