# 验证码使用文档

## 验证码类型概览

| 组件 | 说明 | 验证方式 | 适用场景 |
|------|------|----------|----------|
| `SliderCaptcha` | 滑块验证码 | 拖动滑块到最右端 | 登录、注册 |
| `SliderRotateCaptcha` | 旋转验证码 | 拖动滑块旋转图片到正确角度 | 登录、敏感操作 |
| `SliderTranslateCaptcha` | 拼图验证码 | 拖动滑块将拼图块移到正确位置 | 登录、敏感操作 |
| `PointSelectionCaptcha` | 点选验证码 | 按提示依次点击图片中的文字 | 登录、注册 |
| `NumericCaptcha` | 数字验证码 | 输入图片中显示的数字 | 登录、表单 |

---

## 1. SliderCaptcha 滑块验证码

### 使用方式

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { SliderCaptcha } from '@vben/common-ui';

const captchaValue = ref(false);

function handleSuccess({ isPassing, time }) {
  console.log(`验证通过，耗时 ${time}s`);
}
</script>

<template>
  <SliderCaptcha
    v-model="captchaValue"
    text="请按住滑块拖动到最右端"
    success-text="验证通过"
    @success="handleSuccess"
  />
</template>
```

### Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `v-model` | boolean | false | 验证是否通过 |
| `text` | string | `请按住滑块拖动` | 提示文字 |
| `successText` | string | `验证通过` | 验证成功提示 |
| `isSlot` | boolean | false | 是否作为插槽模式（供旋转/拼图组件内部使用） |
| `wrapperStyle` | CSSProperties | {} | 组件容器样式 |
| `barStyle` | CSSProperties | {} | 滑块条样式 |
| `contentStyle` | CSSProperties | {} | 内容区样式 |
| `actionStyle` | CSSProperties | {} | 滑块按钮样式 |

### Events

| 事件 | 参数 | 说明 |
|------|------|------|
| `success` | `{ isPassing: boolean, time: string }` | 验证通过时触发 |
| `start` | `MouseEvent \| TouchEvent` | 开始拖动时触发 |
| `move` | `{ event, moveDistance, moveX }` | 拖动过程中触发 |
| `end` | `MouseEvent \| TouchEvent` | 结束拖动时触发 |

## 4. PointSelectionCaptcha 点选验证码

### 使用方式

```vue
<script setup lang="ts">
import type { CaptchaPoint } from '@vben/common-ui';
import { ref } from 'vue';
import { PointSelectionCaptcha } from '@vben/common-ui';

const captchaImage = ref('data:image/png;base64,...'); // 含文字的验证码图片
const hintText = ref('你好世界'); // 需要依次点击的文字

function handleClick(point: CaptchaPoint) {
  console.log('点击坐标:', point.x, point.y);
}

function handleConfirm(points: CaptchaPoint[], clear: () => void) {
  // 将点击坐标发送到后端验证
  console.log('所有点击:', points);
  // 验证失败时调用 clear() 清除点位
}
</script>

<template>
  <PointSelectionCaptcha
    :captcha-image="captchaImage"
    :hint-text="hintText"
    :show-confirm="true"
    @click="handleClick"
    @confirm="handleConfirm"
    @refresh="() => console.log('刷新验证码')"
  />
</template>
```

### Props

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `captchaImage` | string | - | 验证码图片（必填） |
| `hintImage` | string | - | 提示图片（与 hintText 二选一） |
| `hintText` | string | - | 提示文字（与 hintImage 二选一） |
| `showConfirm` | boolean | false | 是否显示确认按钮 |
| `title` | string | `请依次点击` | 标题文字 |
| `width` | string | 300px | 组件宽度 |
| `height` | string | 220px | 组件高度 |

### Events

| 事件 | 参数 | 说明 |
|------|------|------|
| `click` | `{ x, y, i, t }` | 每次点击时触发，返回坐标、索引、时间戳 |
| `confirm` | `[points, clear]` | 点击确认按钮时触发，传入所有点位和清除函数 |
| `refresh` | - | 点击刷新按钮时触发 |

## 前后端验证方案

### 方案一：纯前端验证（滑块/数字验证码）

适用于不需要严格安全校验的场景，验证逻辑全部在前端完成。

```vue
<!-- 登录页面示例 -->
<script setup lang="ts">
import { SliderCaptcha } from '@vben/common-ui';

const captchaPassed = ref(false);

async function handleLogin(values) {
  if (!captchaPassed.value) {
    message.error('请先完成验证码');
    return;
  }
  await authStore.authLogin(values);
}
</script>

<template>
  <SliderCaptcha v-model="captchaPassed" />
  <Button @click="handleLogin">登录</Button>
</template>
```

**特点：**
- 前端自行验证，不依赖后端
- 适合内部系统、低安全要求场景
- 无法防止自动化工具绕过

---

### 方案二：后端验证（滑块验证码 + Token）

后端生成验证 Token，前端验证通过后将 Token 一起提交，后端校验 Token 有效性。

#### 流程图

```
┌──────────┐          ┌──────────┐          ┌──────────┐
│  前端     │          │  后端     │          │  验证服务  │
└────┬─────┘          └────┬─────┘          └────┬─────┘
     │  1. 获取验证码       │                     │
     │─────────────────────>│                     │
     │                      │  2. 生成 captchaId   │
     │                      │     + 滑块位置       │
     │                      │─────────────────────>│
     │  3. 返回 captchaId   │                     │
     │     + 背景图         │<─────────────────────│
     │<─────────────────────│                     │
     │                      │                     │
     │  4. 用户滑动验证      │                     │
     │  5. 提交登录请求      │                     │
     │  (username, password, │                     │
     │   captchaId, offset) │                     │
     │─────────────────────>│                     │
     │                      │  6. 校验滑动位置     │
     │                      │─────────────────────>│
     │                      │  7. 返回校验结果     │
     │                      │<─────────────────────│
     │  8. 返回登录结果      │                     │
     │<─────────────────────│                     │
```

#### 后端接口设计

**获取验证码：**

```
GET /api/captcha/slider

Response:
{
  "code": 0,
  "data": {
    "captchaId": "uuid-xxx",
    "bgImage": "base64...",      // 背景图片
    "sliderImage": "base64...",  // 滑块图片
    "y": 120                     // 滑块 Y 轴位置
  }
}
```

**登录时验证：**

```
POST /api/auth/login

Request:
{
  "username": "vben",
  "password": "123456",
  "captchaId": "uuid-xxx",
  "offset": 285                  // 滑动距离
}

Response (验证失败):
{
  "code": -1,
  "message": "验证码错误"
}
```

#### 前端实现

```typescript
// api/captcha.ts
export function getSliderCaptcha() {
  return requestClient.get('/captcha/slider');
}

// api/auth.ts
export function login(data: {
  username: string;
  password: string;
  captchaId: string;
  offset: number;
}) {
  return requestClient.post('/auth/login', data);
}
```

```vue
<!-- login.vue -->
<script setup lang="ts">
import { SliderCaptcha } from '@vben/common-ui';
import { getSliderCaptcha, login } from '#/api';

const captchaData = ref(null);
const captchaId = ref('');
const sliderOffset = ref(0);

// 获取验证码
async function fetchCaptcha() {
  const res = await getSliderCaptcha();
  captchaData.value = res.data;
  captchaId.value = res.data.captchaId;
}

onMounted(fetchCaptcha);

// 滑块移动时记录偏移量
function handleSliderMove({ moveX }) {
  sliderOffset.value = moveX;
}

// 登录
async function handleLogin(values) {
  const res = await login({
    username: values.username,
    password: values.password,
    captchaId: captchaId.value,
    offset: sliderOffset.value,
  });

  if (res.code === -1) {
    // 验证码错误，刷新验证码
    fetchCaptcha();
    return;
  }
  // 登录成功...
}
</script>
```

### 方案三：后端验证（拼图/旋转验证码 + 签名）

适合高安全要求场景，后端生成带签名的验证数据，前端验证后提交签名。

#### 后端接口设计

**获取验证码：**

```
GET /api/captcha/puzzle

Response:
{
  "code": 0,
  "data": {
    "captchaId": "uuid-xxx",
    "bgImage": "base64...",       // 拼图背景
    "sliderImage": "base64...",   // 拼图块
    "token": "signed-token...",   // 签名 Token
    "expireAt": 1717392000000     // 过期时间
  }
}
```

**验证：**

```
POST /api/captcha/verify

Request:
{
  "captchaId": "uuid-xxx",
  "token": "signed-token...",
  "point": { "x": 285, "y": 120 }
}

Response:
{
  "code": 0,
  "data": {
    "verified": true,
    "verifyToken": "verify-token-xxx"  // 验证通过后的凭证
  }
}
```

**登录时携带验证凭证：**

```
POST /api/auth/login

Request:
{
  "username": "vben",
  "password": "123456",
  "verifyToken": "verify-token-xxx"
}
```

### 方案四：后端验证（点选验证码）

点选验证码需要后端生成带文字位置信息的图片，前端记录点击坐标，后端校验坐标是否在正确区域。

#### 后端接口设计

**获取验证码：**

```
GET /api/captcha/point

Response:
{
  "code": 0,
  "data": {
    "captchaId": "uuid-xxx",
    "image": "base64...",           // 含文字的图片
    "hintText": "你好世界",          // 提示文字
    "token": "signed-token..."
  }
}
```

**验证：**

```
POST /api/captcha/verify

Request:
{
  "captchaId": "uuid-xxx",
  "token": "signed-token...",
  "points": [
    { "x": 45, "y": 80, "t": 1717392000001 },
    { "x": 120, "y": 80, "t": 1717392000002 },
    { "x": 200, "y": 80, "t": 1717392000003 },
    { "x": 280, "y": 80, "t": 1717392000004 }
  ]
}
```

#### 前端实现

```vue
<script setup lang="ts">
import type { CaptchaPoint } from '@vben/common-ui';
import { PointSelectionCaptcha } from '@vben/common-ui';
import { getCaptchaPoint, verifyCaptcha } from '#/api/captcha';

const captchaData = ref(null);
const clickPoints = ref<CaptchaPoint[]>([]);

async function fetchCaptcha() {
  const res = await getCaptchaPoint();
  captchaData.value = res.data;
}

function handleClick(point: CaptchaPoint) {
  clickPoints.value.push(point);
}

async function handleConfirm(points: CaptchaPoint[], clear: () => void) {
  const res = await verifyCaptcha({
    captchaId: captchaData.value.captchaId,
    token: captchaData.value.token,
    points: points.map(p => ({ x: p.x, y: p.y, t: p.t })),
  });

  if (!res.data.verified) {
    clear();        // 清除点位
    fetchCaptcha(); // 刷新验证码
    message.error('验证失败，请重试');
  }
}

onMounted(fetchCaptcha);
</script>

<template>
  <PointSelectionCaptcha
    v-if="captchaData"
    :captcha-image="captchaData.image"
    :hint-text="captchaData.hintText"
    :show-confirm="true"
    @click="handleClick"
    @confirm="handleConfirm"
    @refresh="fetchCaptcha"
  />
</template>
```

### 方案五：后端验证（数字验证码 + Session）

最简单的后端验证方案，后端生成验证码图片和答案，存入 Session，前端输入后提交验证。

#### 后端接口设计

**获取验证码：**

```
GET /api/captcha/numeric

Response:
{
  "code": 0,
  "data": {
    "captchaId": "uuid-xxx",
    "image": "base64..."    // 验证码图片
  }
}
// 同时 Set-Cookie: captcha_session=xxx
```

**登录时验证：**

```
POST /api/auth/login

Request:
{
  "username": "vben",
  "password": "123456",
  "captchaId": "uuid-xxx",
  "captchaCode": "4829"
}
// Cookie: captcha_session=xxx
```

#### 前端实现

```vue
<script setup lang="ts">
import { NumericCaptcha } from '@vben/common-ui';
import { getNumericCaptcha } from '#/api/captcha';

const captchaImage = ref('');
const captchaId = ref('');

async function fetchCaptcha() {
  const res = await getNumericCaptcha();
  captchaImage.value = res.data.image;
  captchaId.value = res.data.captchaId;
}

async function handleLogin(values) {
  await login({
    username: values.username,
    password: values.password,
    captchaId: captchaId.value,
    captchaCode: captchaCode.value,
  });
}

onMounted(fetchCaptcha);
</script>

<template>
  <!-- 自定义数字验证码展示 -->
  <div class="flex items-center gap-2">
    <img :src="captchaImage" @click="fetchCaptcha" class="cursor-pointer" />
    <input v-model="captchaCode" maxlength="4" placeholder="请输入验证码" />
  </div>
</template>
```

## 安全建议

| 安全等级 | 推荐方案 | 说明 |
|----------|----------|------|
| 低 | 纯前端滑块/数字 | 仅防误触，不防自动化 |
| 中 | 后端滑块 + Token | 需后端生成和校验 |
| 高 | 后端拼图/点选 + 签名 | 坐标校验 + 时间戳 + 签名防重放 |
| 极高 | 行为分析 + 多种验证组合 | 鼠标轨迹、点击频率等行为特征分析 |

### 通用注意事项

1. **验证码有效期**：建议设置 60-120 秒过期
2. **失败重试**：验证失败后自动刷新验证码，限制重试次数（建议 3-5 次）
3. **防重放**：每个 captchaId 只能使用一次
4. **传输安全**：验证码数据走 HTTPS，敏感参数加密传输
5. **前端加密**：坐标类验证码建议前端加密后再传输
