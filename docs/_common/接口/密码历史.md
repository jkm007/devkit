# 密码历史接口文档

> 对应表：`sys_password_history`
> 说明：密码历史主要用于修改密码时的校验，通常不单独对外暴露接口。

## 接口概览

| 接口 | 方法 | 用途 | 认证 |
|------|------|------|------|
| `/auth/password-history/check` | POST | 检查新密码是否与历史密码重复 | 需要 |

> 注：密码历史的写入在「修改密码」和「重置密码」接口中自动完成，无需单独调用。

---

## 1. 检查密码是否重复

### 接口信息

- **路径：** `POST /auth/password-history/check`
- **用途：** 修改密码前，前端实时校验新密码是否与最近 N 次密码重复
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求体

```json
{
  "newPassword": "654321"
}
```

### 请求字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `newPassword` | string | 是 | 待检查的新密码 |

### 返回格式

```json
{
  "code": 0,
  "data": {
    "isRepeated": false
  },
  "error": null,
  "message": "ok"
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `isRepeated` | boolean | 是否与最近 5 次密码重复 |

---

## 密码历史规则

| 规则 | 说明 |
|------|------|
| 记录数量 | 最近 5 次 |
| 校验时机 | 修改密码、管理员重置密码 |
| 清理策略 | 定期清理超过 6 个月的历史记录 |
| 存储方式 | bcrypt 加密存储 |

---

## 前端调用示例

```typescript
import { checkPasswordHistory } from '#/api/auth';

// 修改密码前实时校验
async function onNewPasswordChange(newPassword: string) {
  if (newPassword.length < 6) return;
  const { isRepeated } = await checkPasswordHistory({ newPassword });
  if (isRepeated) {
    message.warning('新密码不能与最近 5 次密码相同');
  }
}
```

---

## 关联接口

密码历史的写入发生在以下接口中：

| 接口 | 说明 |
|------|------|
| `PUT /auth/change-password` | 用户修改密码 → 旧密码存入历史 |
| `PUT /system/user/:id/reset-password` | 管理员重置密码 → 旧密码存入历史 |
