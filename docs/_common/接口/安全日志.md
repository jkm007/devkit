# 安全日志接口文档

> 对应表：`sys_security_logs`

## 接口概览

| 接口 | 方法 | 用途 | 认证 |
|------|------|------|------|
| `/auth/security-logs` | GET | 获取当前用户的安全日志 | 需要 |
| `/system/security-logs` | GET | 获取所有用户的安全日志（管理员） | 需要 |

---

## 1. 获取当前用户安全日志

### 接口信息

- **路径：** `GET /auth/security-logs`
- **用途：** 当前用户查看自己的安全操作记录
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `page` | number | 否 | 页码，默认 1 |
| `pageSize` | number | 否 | 每页条数，默认 20 |
| `eventType` | string | 否 | 事件类型筛选 |

### 返回格式

```json
{
  "code": 0,
  "data": {
    "items": [
      {
        "id": 1,
        "eventType": "login",
        "eventDetail": "登录成功",
        "ip": "192.168.1.100",
        "userAgent": "Mozilla/5.0 Chrome/120.0",
        "status": 1,
        "createdAt": "2026-06-04 10:30:00"
      },
      {
        "id": 2,
        "eventType": "login_fail",
        "eventDetail": "密码错误",
        "ip": "192.168.1.200",
        "userAgent": "Mozilla/5.0 Chrome/120.0",
        "status": 0,
        "createdAt": "2026-06-04 09:15:00"
      },
      {
        "id": 3,
        "eventType": "password_change",
        "eventDetail": "修改密码",
        "ip": "192.168.1.100",
        "userAgent": "Mozilla/5.0 Chrome/120.0",
        "status": 1,
        "createdAt": "2026-06-03 16:00:00"
      }
    ],
    "total": 50
  },
  "error": null,
  "message": "ok"
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | number | 日志 ID |
| `eventType` | string | 事件类型 |
| `eventDetail` | string | 事件详情 |
| `ip` | string | IP 地址 |
| `userAgent` | string | User-Agent |
| `status` | number | 状态：0=失败, 1=成功 |
| `createdAt` | string | 发生时间 |

## 2. 获取所有用户安全日志（管理员）

### 接口信息

- **路径：** `GET /system/security-logs`
- **用途：** 管理员查看所有用户的安全日志，用于安全审计
- **认证：** 需要 `Authorization: Bearer <token>`

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `page` | number | 否 | 页码，默认 1 |
| `pageSize` | number | 否 | 每页条数，默认 20 |
| `userId` | number | 否 | 用户 ID |
| `eventType` | string | 否 | 事件类型筛选 |
| `status` | number | 否 | 状态：0=失败, 1=成功 |
| `ip` | string | 否 | IP 地址 |
| `startTime` | string | 否 | 开始时间 |
| `endTime` | string | 否 | 结束时间 |

### 返回格式

```json
{
  "code": 0,
  "data": {
    "items": [
      {
        "id": 1,
        "userId": 1,
        "username": "vben",
        "eventType": "login",
        "eventDetail": "登录成功",
        "ip": "192.168.1.100",
        "userAgent": "Mozilla/5.0 Chrome/120.0",
        "status": 1,
        "createdAt": "2026-06-04 10:30:00"
      }
    ],
    "total": 500
  },
  "error": null,
  "message": "ok"
}
```

---

## 事件类型枚举

| eventType | 说明 | 触发时机 |
|-----------|------|---------|
| `login` | 登录成功 | 用户登录成功时 |
| `logout` | 登出 | 用户主动登出时 |
| `login_fail` | 登录失败 | 密码错误、账号不存在等 |
| `password_change` | 修改密码 | 用户修改密码成功时 |
| `password_reset` | 重置密码 | 管理员重置密码时 |
| `bind_oauth` | 绑定第三方 | 绑定微信/GitHub 等 |
| `unbind_oauth` | 解绑第三方 | 解绑第三方账号 |
| `account_lock` | 账号锁定 | 连续登录失败触发锁定 |
| `account_deactivate` | 账号注销 | 用户申请注销账号 |

## 前端调用示例

```typescript
import {
  getMySecurityLogs,
  getSystemSecurityLogs,
} from '#/api/auth';

// 获取自己的安全日志
const myLogs = await getMySecurityLogs({ page: 1, pageSize: 20 });

// 管理员获取所有日志
const allLogs = await getSystemSecurityLogs({
  page: 1,
  pageSize: 20,
  eventType: 'login_fail',
  startTime: '2026-06-01',
  endTime: '2026-06-04',
});
```
