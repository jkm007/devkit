# 当前表结构分析与升级方案

## 一、现状总览

当前系统共有 **13 张表**，覆盖了 RBAC 权限管理 + 用户认证模块：

```
sys_users              用户表（23 个业务字段，已升级）
sys_roles              角色表（4 个业务字段）
sys_user_roles         用户角色关联表
sys_menus              菜单表
sys_groups             分组表
sys_group_roles        分组角色关联表
sys_security_logs      安全日志表
sys_login_devices      登录设备表
sys_oauth_users        第三方登录绑定表
sys_user_privacy       用户隐私设置表
sys_password_history   密码历史表
sys_user_real_names    实名认证表
sys_role_applications  角色申请表
```

## 二、逐表分析

### 2.1 sys_users — 用户表

**当前字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| name | VARCHAR(50) | 用户名 |
| password | VARCHAR(255) | 密码 |
| status | TINYINT | 状态 |
| group_id | BIGINT | 所属组 |
| remark | VARCHAR(500) | 备注 |

**问题**：

| # | 问题 | 影响 | 优先级 |
|---|------|------|--------|
| 1 | **缺少个人信息字段** — 没有 nickname、email、phone、avatar、gender、birthday、bio | 无法支撑用户资料页、头像展示、手机号登录 | 🔴 高 |
| 2 | **缺少登录安全字段** — 没有 last_login_at、last_login_ip、login_fail_count、lock_until | 无法实现登录失败锁定、登录记录审计 | 🔴 高 |
| 3 | **缺少实名认证字段** — 没有 real_name、id_card、is_real | 无法支撑实名认证场景 | 🟡 中 |
| 4 | **缺少注册来源字段** — 没有 register_source | 无法统计用户来源渠道 | 🟡 中 |
| 5 | **缺少密码管理字段** — 没有 password_changed_at | 无法提醒用户定期修改密码 | 🟢 低 |
| 6 | **缺少注销字段** — 没有 logout_at | 无法支撑账号注销流程 | 🟢 低 |
| 7 | **name 字段命名不明确** — 建议改为 username | 与 API 文档中的 username 一致 | 🟢 低 |

### 2.2 sys_roles — 角色表

**当前字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| name | VARCHAR(50) | 角色名称 |
| status | TINYINT | 状态 |
| permissions | TEXT | 权限码(JSON数组) |
| remark | VARCHAR(500) | 备注 |

**评估**：当前设计基本可用。permissions 使用 JSON 数组存储菜单 ID，查询时需要应用层解析，但在数据量不大的情况下可以接受。

**可优化项**：

| # | 问题 | 优先级 |
|---|------|--------|
| 1 | 缺少 `code` 字段（角色编码，如 super/admin/user），目前用 name 充当编码 | 🟡 中 |
| 2 | 缺少 `sort` 排序字段 | 🟢 低 |

### 2.3 sys_user_roles — 用户角色关联表

**评估**：✅ 设计合理，无明显问题。

### 2.4 sys_menus — 菜单表

**评估**：✅ 设计合理，字段完整，支持目录/菜单/按钮多种类型。

### 2.5 sys_groups — 分组表

**评估**：✅ 设计合理，支持树形结构。

### 2.6 sys_group_roles — 分组角色关联表

**评估**：✅ 设计合理。
